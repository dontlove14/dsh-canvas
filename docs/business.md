Wan 3.0 / Prime可选择Model Link、Aliyun；MiniMax官方支持H3 / Highspeed / Lite / Max，Model Link仅支持MiniMax-H3。四渠道均填API Key，无EP。旧Model Link变体保留记录 / 密钥 / 历史但隐藏配置和生成候选，新生成拒绝，不自动改节点或重提任务。无素材文生、接入素材默认参考、首尾帧手选、清空素材回文生；H3首尾帧比例自动，退出该模式切回合法比例，Lite参考和所有H3文生不显示自动比例。H3无音频开关，Wan保留同步音频开关；参考校验按各系列能力，不自动走Seedance预审。新任务沿用原ID恢复查询 / 保存。见[ADR-0067](adr/0067-wan-and-minimax-native-video-protocols.md)。

画布空白处右键可选择图片 / 视频 / 语音生成，新节点位于点击处；右键拖动继续平移。已有素材输出端点拉到空白后显示“引用该节点生成”，选择兼容类型会在松手处新建并自动连接该素材，不自动生成；TTS不接受输入，不兼容类型直接隐藏，没有可连接类型时不显示菜单或临时线。历史堆叠需展开后从具体结果端点拉出，引用实际结果而非后来主图。取消 / 平移 / 隐藏或来源失效不会创建；底部添加栏和两个快捷入口使用同一注册，新增类型须三个入口同步维护，见[ADR-0066](adr/0066-shared-node-creation-entrances.md)。

Seedance预审为独立异步任务，不使用生成 / 媒体Loading覆盖节点；按用户要求在名称旁显示“审核中”，只有Active显示青蓝盾牌勾，明确失败为红叉，结果不明为待确认。两家状态独立；单批次只送当前主图，多次历史逐输出可送，空节点无目标。虚拟素材使用画布AIGC组，真人选择官方已认证人物组。审核通过的当前供应商 / 项目素材，下次视频生成用Asset ID；未送审 / 未通过继续URL生成，接受后的来源不变。配置与具体恢复见[ADR-0059](adr/0059-seedance-asset-review-and-frozen-generation-references.md)。

0.2.55未配置预审时隐藏全部媒体节点的预审入口，不建组、没有Group ID；至少保存一家配置后，新画布与已有画布均可显示入口，新画布后台建组、旧画布首次送审补组。配置未读到 / 读取失败也隐藏，重新激活 / 设置保存后刷新。折叠历史的预审、下载和展开处于同排，按钮区域的触控板捏合 / 修饰键滚轮缩放画布，不缩放浏览器，普通点击和节点拖动保护保持。

0.2.56补齐操作栏上的普通双指平移：横向 / 纵向移动、反向与惯性都平移画布且不改变倍率；捏合 / 修饰键滚轮继续缩放。覆盖黑色生成 / 历史按钮、图标与资源顶部操作栏，不接管编辑器内部滚动，不误触按钮。

0.2.57同素材两供应商均审核通过后隐藏送审入口，保留名称旁各自的结果标记；换主图 / 历史素材时按实际asset重新判定。供应商已送审或未配置则禁用，悬停分别显示“当前素材已送审” / “当前供应商送审未配置”。默认选首个已配置未送审供应商，无可用项时不假选或自动提交；失败 / 待确认另保留指向原任务的明确重试或查询。弹窗收紧，移除重复标题 / 文件名、通过详情与底部说明，仅展示失败原因。

素材路径旁的圆圈问号解释两种分组：AI虚拟人物、动物、场景等使用本画布素材组；已完成官方真人认证的素材需选择对应人物组，选择选项不会自动认证。说明仅在悬停 / 聚焦 / 点击问号时展示，虚拟素材下方不再常驻重复说明。

所有节点任务执行和媒体加载使用整节点Beam / 中央Thinking Orb，动画直接来自依赖；不同阶段采用不同依赖样式，节点不显示状态文字，语义状态仅供屏幕阅读器。成功后继续等待图片解码 / 视频首帧 / 音频元数据和波形请求完成，避免图片未就绪时的原生图标 / 文件名；完成且文件就绪才撤Loading。待确认 / 保存失败为静态警告，终态媒体错误停止等待。配色跟随Harness，隐藏 / 离屏 / 减少动态效果暂停，不拦截画布拖动和连线。后续新增或替换Loading须询问用户是否沿用这套依赖；见[ADR-0046](adr/0046-dependency-backed-whole-node-loading.md)。

## 产品范围与工作区

画布用于把图片 / 视频生成步骤与媒体素材放在同一工作区中。用户逐节点提交生成；连线表达参考输入，不会触发下游生成或执行整条工作流。

每张画布就是一个项目，插件自己管理画布目录，支持一级文件夹、画布新建 / 改名 / 移动 / 删除。Harness 会话工作区不是画布目录。模型与对象存储设置全局共享。非空文件夹不能删除，未结束任务或接收中的上传会阻止删除画布。

画布 / 文件夹新建与重命名统一通过Harness命名弹窗输入；提交名称去空白并NFC规范化，1–160字符。取消不写入，保存失败保留草稿并显示原因，保存过程中阻止重复命令和关闭弹窗。

新建画布前必须配置对象存储；缺失时提示“请前往设置页面设置对象存储”并提供设置入口。列表和设置可在无配置时打开；服务端同步拒绝创建 / 新上传 / 新生成，云端网络失败单独报错。

首次进入插件、刷新页面或新开标签，先显示“画布项目”列表，不自动打开第一张或上次使用的画布。新建画布后仍停留在列表，点击项目进入编辑器。列表左侧选择文件夹，项目操作菜单提供改名 / 移动 / 删除；移动时明确选择目标文件夹。文件夹操作在当前文件夹菜单中。

Harness对话右侧“开始页 → 无限画布”可打开画布标签，与左侧全页入口访问同一份目录、模型、媒体和任务。标签在切换文件 / 终端、折叠、切换对话时保留当前项目和草稿；隐藏时暂停音视频播放与状态轮询、关闭弹窗，自动保存继续。重新显示不会自动重播或替换草稿；新开或关闭后再打开标签回列表。窄面板按自身宽度调整文件夹、页头和工具栏。会话不自动绑定画布，同时编辑同一画布继续执行既有保存冲突保护；见[侧栏ADR](adr/0034-conversation-sidebar-canvas.md)。

编辑器顶部显示当前画布名称、返回项目列表、保存状态、任务与设置。返回前等待当前图保存成功，失败或冲突时留在编辑器；文件接收或生成请求提交中暂不能返回。载入失败时可以返回列表。当前页面内返回保留文件夹筛选，不提供项目深链或跨次打开记忆。导航决策见 [ADR-0018](adr/0018-project-list-before-canvas-editor.md)。

图片“生成”提交GPT Image 2.5、Nano Banana或Seedream真实任务，各模型与渠道独立密钥：GPT为Model Link / OpenAI，Banana为Model Link / Gemini；Seedream标准版为Model Link / ByteDance，Dola（NSFW）为独立BytePlus配置。Seedream官方需Key和对应型号EP，Model Link只填Key。视频接入Doubao / Dreamina Seedance 2.0 / mini / fast / 2.5，标准版Model Link / ByteDance，NSFW版独立BytePlus，同样官方EP、Model Link ID。画布 / 任务中心显示型号名称 / ID，EP仅用于设置和请求。画布只显示完整配置组合；无当前类型可用模型时直接显示“请前往设置页面配置模型”，不提供Mock后备项。新节点优先选择已配置Model Link，已有节点不自动改写。TTS使用独立配置的FishTTS服务。所有任务由Host后台异步执行，离开页面不取消。媒体保存在对象存储；结构数据仍在本机，不提供跨电脑同步或多人协作权限。

## 节点与交互

画布普通展示文字默认不能拖选，覆盖节点、操作栏、编辑卡片及其模型 / 参数 / 候选菜单。提示词、TTS文字、节点名称及其他输入框可正常选择 / 复制；历史记录只读提示词与参数值保留复制。节点框选、多选、拖动和连线保持。新增组件仅为需要复制的最小区域显式开放，范围与接入规则见[ADR-0060](adr/0060-canvas-text-selection-opt-in.md)。

模型设置按供应商身份展示卡片，同供应商不同协议地址归一；不显示Base URL。卡片显示配置数量和已保存型号，每项可直接编辑独立Key / EP。Key / EP默认脱敏，右侧眼睛逐项显示或隐藏完整值；编辑固定组合身份，Key留空保留，只查看不改变草稿，取消无写入，失败保留草稿。FishTTS与OSS两项密钥使用同一控件；关闭 / 切换 / 页面隐藏清除预览。未配置供应商卡片可新增支持型号，缺EP的已存Key配置仍可完善。设置配置入口与画布菜单资格分开，菜单只显示完整配置组合，见[卡片ADR](adr/0057-provider-cards-and-direct-model-editing.md)与[脱敏ADR](adr/0058-masked-settings-and-explicit-secret-reveal.md)。

节点上方操作栏与下方编辑卡片按节点自然锚定，即使超出当前窗口也不自动挪动、翻转或夹紧到可见范围。卡片保持固定屏幕宽度，用户自行平移 / 缩放查看；底部工具栏与左下角控件位于节点附件上方。窗口尺寸与附件位置不触发节点、视口或任务修改，见[ADR-0042](adr/0042-node-anchored-overlays.md)。

| 节点 | 可编辑内容 | 输入与输出 |
| --- | --- | --- |
| 图片生成 | 名称、提示词、图片模型、尺寸、数量 | 依协议接受图片引用；输出一批图片 |
| 视频生成 | 名称、提示词、模型、模式、分辨率 / 比例、数量、时长、音频开关、帧角色 | Seedance单条；文生 / 混合参考 / 首尾帧；历史Mock可播放 |
| 图片资源 | 名称 | 上传自动创建；可作为合法参考图 |
| 视频资源 | 名称 | 上传自动创建；本地视频播放、查看与另存 |
| 音频资源 | 名称 | 上传自动创建；本地音频播放、查看与另存 |
| 语音生成 | 名称、文字、音色ID、语速、音量 | 无输入端点、无模型选择；输出一份音频 |

添加菜单提供图片生成、视频生成、语音生成。点击上传或拖拽图片 / 视频 / 音频到画布会自动显示相应资源节点；接收字节后由后台导入任务发布素材。图片 / 视频生成优先使用匹配模型；收起生成节点 / 无素材占位节点选中显示浮动面板，多选用于移动 / 删除。

文件在可见画布内部松手，只添加到该画布，不进入左侧Agent输入框、不显示Agent的图片数量 / 大小限制蒙版；从左侧移入画布会清除原蒙版。最终在画布外松手不添加到画布，按Harness原规则处理。无效文件在画布内报错，不转送Agent；独立弹窗、header和项目列表不视为画布接收区，见[拖放边界](adr/0065-exclusive-canvas-file-drop.md)。

图片 / 视频资源节点只展示媒体；生成节点空态只有媒体图标，完成后显示主图，均以浮动名称提供双击改名（Enter / 失焦提交，Escape取消；键盘Enter / F2可进入编辑）。资源图片顶部操作栏只有旋转 / 下载 / 放大，视频只有下载 / 放大，选中时显示。旋转顺时针90°，仅当前编辑页面生效，不修改原文件；放大与下载始终使用原媒体。所有端点为灰色圆圈加号；资源仅输出，生成节点输入 / 输出都显示，空输出禁用。连线和拖动中的连接预览均为Bezier曲线，具体素材绑定不变。

单选节点时，其直接上游 / 下游连线在灰色底线上显示蓝色动态亮段；入边从上游输出流向当前输入，出边从当前输出流向下游输入，与节点左右位置无关。切换单选即切换范围，空白取消、多选、框选中、侧栏隐藏或页面隐藏时停止；系统减少动态效果时为静态蓝色高亮。该效果仅用于识别关系，不表示任务执行，不递归点亮其他层级。见[ADR-0036](adr/0036-selected-node-relationship-flow.md)。

生成结果的媒体就是节点，去掉父容器背景 / 外框，选中提示仅作用于媒体画面。端点用SVG绘制正圆与水平 / 垂直居中的加号。

音频资源使用圆角波形卡片，名称浮动并支持双击改名，仅输出端点，选中时顶部可下载原文件。中间96条幅度反映实际音频的声音强弱；已播放部分高亮并显示红色游标，底部显示当前时间、播放 / 暂停、总时长。点击 / 拖动波形定位；方向键前后5秒、Home / End到首尾、空格 / Enter播放。音频不自动开始或循环，节点音视频共享当前播放身份，切换播放、离屏、页面隐藏或卸载停止旧声音；已有音频不显示下方资源编辑面板。波形派生缓存不改原文件，失败时仍可尝试播放 / 下载，见[ADR-0028](adr/0028-audio-waveforms-and-compact-prompts.md)。

底部当前时间、总时长和留白可按住左键拖动节点，普通点击可选中；播放按钮与波形独立处理播放 / 定位，不能从它们拖动节点。此规则同时用于普通音频与TTS音频结果，播放器双击仍不触发画布缩放。

音频游标与高亮逐帧跟随实际播放位置，底部时间文字按媒体事件更新。暂停、缓冲、结束或隐藏时停止帧更新，定位立即同步；不对停止的音频推算虚假进度，不每帧重绘整个画布。

选中收起状态的生成节点，下方卡片首排放上传按钮，有引用时显示已连接参考缩略图，随后是提示词和底部模型 / 参数摘要 / 生成箭头；没有引用不显示说明行或留空的参考区域。展开时点击任何结果均不显示该卡片。参数面板按所选真实模型capabilities提供有效分辨率、比例、背景、画质、数量或视频时长；切换分辨率优先保留支持的比例，不提供虚构组合。GPT的23种有效尺寸与Banana各型号能力见[协议参考](providers.md)，所有生图模型按1:1、2:3、3:2、3:4、4:3、4:5、5:4、9:16、16:9、21:9排序，仅显示参数允许项，不提供25:9或9:25；4K只显示合法项。没有当前类型可用配置时选择器禁用并显示前往设置提示，生成按钮禁用。仅保存 / 派发本次请求期间锁定输入、模型和参数；收到回执后可修改并再次提交，旧任务继续使用原快照。

图片 / 视频提示词与语音文字输入区统一从70px高度起步，内边距10px，自然随输入 / 换行增长到220px，之后内部滚动。参考图到正文保持紧凑间距，@徽章与正文20px行高一致。生成编辑卡片不再显示任务成功页脚，最底部固定为模型 / 参数 / 生成控制行；校验说明在该行上方，任务详情和失败动作从顶部“任务”查看。

图片 / 视频提示词与语音文字输入区使用统一的柔和底色，与编辑卡片区分：浅色主题稍深、深色主题稍浅，无常驻边框。颜色直接跟随Harness表面与文字色混合，主题切换和自定义配色即时生效。

节点和原视频预览共用一行自定义播放 / 暂停、当前时间、可拖拽进度条与总时长，声音开启、音量1，不提供静音、全屏、更多或额外控制。键盘可操作按钮与进度，控件不拖动或缩放画布。原图 / 原视频预览使用深色遮罩，媒体按原比例适应可用空间，不显示名称、另存按钮或弹窗卡片边框；只有关闭按钮和视频必要的播放控件。可用关闭按钮、Esc或遮罩关闭，关闭停止原视频并返回原入口焦点。下载仍在节点操作栏，见[ADR-0024](adr/0024-custom-video-and-chromeless-preview.md)。

双击图片 / 视频资源节点的画面，会在画布内选中、居中并放大该节点，保留周围画布与连线；按当前节点尺寸适应可用空间，缩放仍在0.1–2.5内。名称双击仍改名，顶部放大按钮仍查看原文件；视频单击循环播放行为保留，生成节点不新增此双击行为。

空白处左键按住拖动框选，Shift扩展选择；空格加左键拖动、中键 / 右键拖动平移。普通滚轮及空格加滚轮上下平移，不改变缩放；触控板双指移动按横纵两个方向平移。Command / Ctrl加滚轮以指针为中心缩放，触控板捏合保留缩放。输入映射与原生实现依据见[ADR-0023](adr/0023-canvas-wheel-and-trackpad-gestures.md)。

框选矩形与结束后的分组选区内部完全透明，使用主题色虚线边框。只有矩形完整包住的节点主体进入选择，标题 / 端点 / 浮动按钮不扩大范围；拖回或缩小矩形会移除已经移出的节点，屏幕外未测量节点按实际位置与展示尺寸判断。普通框选替换旧选择，Shift保留开始前的选择；取消 / 失焦恢复原选择。框选过程中不显示浮动操作和编辑面板，多选结束后不显示单节点操作；连线沿用原规则，跟随被选中节点的连接。见[ADR-0033](adr/0033-strict-marquee-selection.md)。

鼠标位于音频卡片、波形或播放按钮时，双指移动仍平移画布；点击 / 拖动波形和播放按键保持原行为。音频顶部操作栏、提示词和参数控件仍独立处理滚动，见[ADR-0029](adr/0029-generation-sliders-and-audio-wheel.md)。

Backspace / Delete删除选中节点或连线。提供小地图、缩放控件和适应全部节点。界面缩放范围为 `0.1–2.5`；数据契约允许更宽的范围，见[数据参考](data-api.md)。

0.2.78多选结束后显示透明分组选框、右侧输出端点和仅下载的顶部操作栏。拖分组选框端点到生成节点可一次连接全部有效输出，按图节点顺序跳过类型 / 格式不符、数量满、重复与循环；普通节点也可拖到目标主体。单批次连接主图，多次历史先展开使用每个明确结果端点；下载资源 / 主图及展开后可见结果，不包含未完成媒体。点击边再Delete只解除引用；目标提示词@了该素材时显示Harness确认，确认后文字保留、标签失效。底栏右侧键盘图标列出现有快捷键，macOS显示Command，Windows显示Ctrl；提示词撤销等仅在输入区生效。见[ADR-0068](adr/0068-selection-output-and-reference-interactions.md)。

文本框、按钮、播放器使用独立交互区域，操作控件不应拖动画布。模态窗口支持 Esc 和焦点管理；具体可访问性仍需按[手动验收](manual-tests.md)确认。

## 提示词中的 @ 引用

图片 / 视频生成共用提示词编辑器。输入 `@` 后可按素材名称搜索当前画布的已连接参考图与可合法连接的素材，方向键选择、Enter / Tab确认，Esc关闭，也可用鼠标点击。未连接素材选择后自动增加入边，已连接素材不重复增加；候选遵循模型类型 / 格式 / 数量和无环约束。单次批量的新引用使用当前主图；多次提交历史须先展开逐素材连线，未连接结果不进入自动连线候选，已连接历史结果仍可引用。

标签显示缩略图与 @参考图N，绑定具体素材UUID。名称改变或切换主图不会改绑；N随入边顺序更新。删除标签保留参考连线，移除连线后对应标签提示失效，必须重新引用或删除标签再生成。中文输入法、换行、复制 / 粘贴、整体删除、撤销 / 重做可用，空格与删除键不会操作画布。复制以纯文本UUID语法保留身份，跨画布粘贴不自动导入素材。

节点prompt仍为字符串；提交快照将标签转换成按入边编号的 `[参考图N]`，并固定同一组素材ID。普通文本与无标签的旧节点保持，标签不改变模型参数或自动生成下游。详情显示本次解析后的输入，后续修改不改变历史任务。规则与实现见[ADR-0027](adr/0027-prompt-asset-mentions.md)。

## 模型配置

0.2.19起TTS情绪选择显示 `@平静`、`@自信` 等文字徽章，尺寸 / 边框 / 基线与图片 / 视频@标签一致；实际prompt仍保存 `(calm)`、`(confident)`，已有值自动显示徽章，无需重新插入。徽章支持整体删除、撤销 / 重做和复制原始值，候选弹层不被编辑卡片裁切。TTS空态沿用图片 / 视频生成节点的320×180背景、边框和灰黑图标，仅保留浮动名称，节点内部没有说明文字或prompt预览；仍仅输出。见[ADR-0031](adr/0031-tts-emotion-badges-and-monochrome-nodes.md)。

语音节点使用单一FishTTS服务，在设置的“FishTTS语音服务”保存接口地址与API Key，节点内不提供模型 / 数量 / 参考素材选择。音色ID文本可空；语速默认1.00（步长0.1、最小0.1）、音量默认0.00（步长1、可负数），均为减 / 输入 / 加计数器。文字中输入@可按中英文选择情绪、语气、声音效果和停顿，插入文档中的原始括号语法，不建立连线。情绪置句首可叠加，声音 / 停顿可放文字中。文字随内容增高至220px；生成前保存当前图，接受任务后锁定输入，修改配置只影响后续任务。结果显示真实波形并复用原音频手动播放 / 下载；只有输出端点，失败动作从顶部任务查看。协议细节见[模型协议](providers.md)，决策见[ADR-0030](adr/0030-fish-tts-nodes-and-streamed-audio.md)。

用户配置内置模型的供应商密钥，不能添加自定义模型、渠道或API Base。GPT Image 2.5 Sunburst / Flare各有Model Link和OpenAI，Nano Banana Pro / 2 / 2 Lite / 2.1各有Model Link和Gemini，按模型分组、Model Link默认优先；密钥不共享，不自动换渠道。GPT的background / quality采用中文标签和英文值；Banana每次1张，不提供这两项，Lite参考上限1、其他14。比例 / 分辨率映射有效size，能力表见[模型协议](providers.md)。旧记录与历史结果保留，不自动修改节点模型。

生成数量使用带断点滑块；当前全部Mock生图 / 生视频提供1–10张 / 条。视频时长按模型能力显示固定秒数断点或区间滑块：Mock Video为4 / 8 / 12秒，Mock Video · 区间为0–12秒、步长1秒且不显示断点。0秒可编辑保存，但生成前提示需大于0秒；切换模型默认取支持值。键盘方向键逐档选择，Home / End到首尾，当前值与单位随滑块更新。

模型类型创建后不能改变；名称、协议（同类型内）、模型标识、地址和密钥可编辑。切换节点模型会重置参数为新模型默认值；已有引用保留，若不再被支持，会说明原因并禁止生成，需用户主动移除。

设置页面不会读取已保存密钥原文。编辑表单留空时不提交 `api_key` 字段，保留旧密钥；输入新值替换；勾选清除时显式提交空字符串。读取仅有是否设置和固定掩码。当前真实模型 / TTS未设密钥时前后端均拒绝新生成。

未结束任务使用提交时的配置和密钥，后续编辑不改变该任务。仍被未结束任务使用的模型不能删除；删除没有未结束任务的模型后，节点和历史结果保留，节点需要重新选择有效模型。

## 导入、引用与重新导入

资源节点引用插件上传到OSS的文件，删除用户原始文件不影响素材。拖拽 / 按钮共用分块断点续传，网络恢复自动继续；同浏览器 / 同站点刷新或重开插件后从缓存原文件继续，宿主重启保留确认进度。画布顶部居中显示小胶囊，左侧圆环、右侧百分比；最多五枚横向叠放并露出各圆环，其余用「+N」，100项显示五枚与「+95」。未结束仍可追加，共享管理器最多五份并发，成功 / 终态失败后接入下一项。胶囊无静态描边、轻悬浮，边缘是真实彩色Beam，表面与光晕强度跟随Harness黑白主题；首次从上方进入，后续从右叠入，完成移除并向左补齐，减少动态效果时保留静态进度。完整接收后后台导入独立于页面，接受不代表OSS成功。面板上传保留目标，保存完成后幂等连接；失败或目标被删除不重复上传。缓存不可用先报错，清站点数据 / 换浏览器不能续传，见[恢复协议](adr/0063-resumable-uploads-and-progress-capsules.md)与[展示 / 并发](adr/0064-bounded-upload-capsules-and-five-transfers.md)。

从素材 / 生成结果右侧连接点拖到生成节点左侧，连线绑定当时的**具体素材 ID**。保存拒绝不存在的节点或素材、不属于来源节点的素材、重复引用、自连接和有向环；具体约束见[数据参考](data-api.md)。

- 同一素材不能被同一个目标重复引用；不同目标可以引用它。
- 模型限制决定可接受类型和引用数量；未选模型时仅允许基础图片引用。
- 切换结果预览、编辑提示词、重生成不会改动已有连线。
- 再上传始终创建新的资源节点，不更改原素材和原出边；使用新素材需要主动连接。
- 删除连线只移除输入引用；不会删除对应文件或清空下游旧结果。

文件格式、参考图字节限额与元数据规则见[模型协议](providers.md)和[运行配置](operations.md)。可导入的 GIF 不等于可作为生成参考；当前适配器仅接受 PNG / JPEG / WebP 参考图。

## 提交与结果

点击生成立即增加本次提交卡片，再完成当前图保存；宿主根据已保存节点、修订号和入边构建任务快照。非空提示词、模型类型、参数和引用都校验通过后才登记任务。同节点可有多个未结束任务，每次使用独立requestId，受既有全局队列 / 并发限制；相同请求重放返回原任务。明确拒绝撤回临时卡片，不确定响应保留待确认并按确切requestId核对，不自动重提。

任务目录 / 详情按 1:1 持久化，详情记录输入快照、外部任务 ID、成功时间、失败阶段 / 原因和执行尝试。真实任务密钥使用固定凭据版本引用，不进入任务表；严格匹配内置 Mock 快照的任务 credential_ref 为null，执行本地渲染，submit_issued不置位。Mock中断可按同任务 / 输出ID恢复；保存失败重试已有暂存结果，不再渲染。修改面板只影响下一次生成。刷新、关面板不销毁宿主 Runtime；禁用后台插件、停止 Harness 或关机会停止本地处理，重启按原身份恢复。

顶部“任务”打开当前owner所有未删除画布的目录表格，列为任务ID、当前文件夹名称、当前画布名称、提交时生成节点名称、模型名称、提供商、状态、更新时间、提交时间、查看详情；模型 / 提供商使用提交快照，配置变化不影响原任务，缺失信息与导入显示“-”，详情也展示；未归档显示“未归档”。查询区支持完整任务ID精确查、文件夹 / 画布名字面模糊查、图片 / 视频 / 语音 / 导入类型和提交时间单侧 / 双侧范围，全部条件AND联合。点击查询才应用；重置清空条件。时间按浏览器本地时区，默认整日边界并包含结束秒；日期控件为双月日历。分页默认10、可选10 / 20 / 50 / 100，支持跳页并固定在底部，只有表格滚动，弹窗外层不滚动；翻页上限排除其后新任务，重新查询才纳入。详情仅正文滚动，返回保留条件与页码；失败恢复动作仍在详情里，不增加状态标签页 / 导出。见[任务弹窗ADR](adr/0035-searchable-paginated-task-dialog.md)。

任务ID列缩略为前16位加省略号，悬停可查看完整值；左侧复制图标复制完整ID并反馈结果，复制不打开详情、不发新查询。名称列超出显示省略号。搜索控件与分页各自固定宽度、窄窗口换行，表格保持列基准宽度并在内部横向滚动。

返回的媒体上传到OSS并登记ready后才形成可预览结果。仅一次提交的图片 / 视频多结果仍作为主图分组，默认叠层显示主图（初次为第一份）；右上角数量按钮展开两列结果，每份支持下载 / 设为主图，收起按钮固定在最后一行左侧结果的右上角（4份为第3份，2份为第1份），不跟随主图移动。主图用现有 selectedResultId 保存，展开状态仅当前页面；只有主图显示输入 / 输出端点，新连线引用当前主图。切换主图不改已存边的assetId。见[ADR-0026](adr/0026-primary-only-group-interaction.md)。

同节点第二次提交起，图片 / 视频 / TTS切换为按提交历史堆叠：最新提交始终在顶部显示自身Loading，原结果留在下方；完成在原位置换为媒体，不按完成时间重排。展开后各任务按顺序展示，多输出在该任务内成组，各素材均可下载和独立连接，没有设主图。收起没有可见输出，也不能新增连线；已有边保留不可见锚点及原assetId。图片 / 视频输入仍属于节点，TTS无输入。每张卡片独立等待自身任务和媒体，旧媒体加载不覆盖其他卡片。见[ADR-0050](adr/0050-submission-history-and-expanded-result-ports.md)。

展开提交历史后点击素材，下面只读显示对应任务快照的提示词 / 模型 / 参数 / 原顺序参考素材，允许复制，不允许修改、上传或提交。收起时关闭面板，重新点击堆叠后恢复最后一次提交的输入，用户可修改并再次生成；查看旧任务不能更换新草稿来源。尚未接受或读取失败时等待 / 提示，不回填其他输入。恢复编号引用时保持原UUID和当前边，缺失引用须用户处理。单次批量展开仍隐藏编辑器。见[ADR-0051](adr/0051-readonly-submission-inspection.md)。

上传 / 生成的图片默认加载压缩封面；视频使用压缩第一帧封面，未点击不加载原播放器，点击节点后有声循环播放；浏览器阻止自动播放时保留播放按钮供主动开始，不自动退回静音。同一时刻一个节点结果播放，取消选择 / 点击空白 / 移出可见区域 / 切换主图 / 展开收起时恢复封面，放大后查看原视频。音频沿用手动播放。封面首次展示时由宿主生成并缓存，失败不影响原文件下载与生成状态；参数见[ADR-0022](adr/0022-media-covers-and-curved-edges.md)。

**结果展示规则**：单次任务允许展示已保存的部分，不要求整体成功。多次提交各有卡片，失败 / 待确认且无结果的卡片保留静态状态，旧批次可展开查看；部分保存结果留在其所属卡片。历史从既有任务派生，刷新保留接受的任务和素材，未接受的临时意图不持久化。

## 任务状态与用户动作

| 状态 | 含义 | 是否锁定节点 / 模型 | 用户动作 |
| --- | --- | --- | --- |
| `submitted` | 已登记，待宿主处理；也可能正在提交 | 是 | 等待 |
| `queued` | 供应商排队 | 是 | 等待 |
| `generating` | 供应商生成或恢复查询 | 是 | 等待 |
| `saving` | 获取 / 保存结果文件 | 是 | 等待 |
| `completed` | 本批结果全部本地保存成功 | 否 | 使用结果或发起新任务 |
| `failed` | 生成失败或提交未取得可用结果 | 否 | 核对错误并修改输入后主动生成新任务 |
| `unknown` | 有外部 ID 的查询无法确认 | 是 | 重新查询原 ID；或结束本地等待 |
| `save_failed` | 下载 / OSS发布失败，或恢复凭据缺失 | 是 | 重试保存结果；或结束本地等待 |
| `abandoned` | 用户明确结束本地等待 | 否 | 新生成前确认可能重复计费 |

有供应商 ID 的视频任务重启后继续查询原 ID；查询时使用原模型地址与原密钥。明确的鉴权 / 请求错误暂停为 `unknown`；临时网络 / 服务器错误按间隔继续查询。错误分类详见[模型协议](providers.md)。

没有供应商 ID，且已开始提交、没有可恢复输出时，重启或提交错误转为 `failed`，不会自动重提。启动修正符合这些条件且无外部完成记录的历史 unknown，保留尝试与快照。画布失败显示红色感叹号，优先于媒体加载；本地失败不代表供应商没有接收或扣费，见[ADR-0054](adr/0054-no-result-submission-failure-and-seedream-id-correction.md)。“结束本地等待”仅结束本地追踪，**没有调用供应商取消接口**。

“重试保存结果”继续同次结果描述和 ID，不提交新生成。已经发布的对象核验后跳过；存在恢复暂存时只重试OSS保存，不重新下载过期结果。尚未取得暂存且供应商结果链接已过期时仍可能失败；当前没有通用刷新供应商输出链接协议。

调度并发控制生成网络 / 保存步骤，远端等待间隔不长期占槽。生成接收队列最多 1000 个 queued / running / external_wait / saving 任务；导入与文件搬移另外有界扫描。没有查询最大次数或取消运行中任务的功能。

## 保存、冲突与删除

画布顶部短时提示复用上传胶囊的彩色Beam与入场 / 补位动画；不同消息按出现顺序横向叠放，最多五枚与「+N」，同时上传另占一行。每条从可见时起显示5秒，追加不重置旧消息，超出的消息补入后才计时；悬停 / 聚焦 / 隐藏暂停，恢复后继续剩余时间，也可逐条关闭。相同正文在队列中去重。提示消失不改变任务失败或保存冲突，持久冲突栏仍保留导出 / 重新载入动作；表单内校验保持，见[共用胶囊](adr/0064-bounded-upload-capsules-and-five-transfers.md)。

图编辑约 650ms 后自动保存，只提交改变的节点 / 边 / 视口及其 SHA-256。实际图变更递增修订并写入 hash 链，无变化不递增。后台上传的占位 / 素材绑定也计入图修订，任务进度不改变图修订。页面可见时每 2 秒读取图与任务摘要，隐藏时暂停浏览器轮询。

拖动保持实时位置、连线与最后坐标保存；纯坐标更新不刷新节点内容 / 编辑器输入，不变轮询复用已有显示。任务进度、新结果、尺寸、主题与展开变化仍正常更新。历史只读 / 收起最新编辑保持，规则见[ADR-0052](adr/0052-position-and-content-render-isolation.md)。

多窗口写同一图采用乐观修订号。无本地改动时可同步更新图；存在草稿时停止覆盖，显示冲突，允许导出 `canvas-draft.json` 再重新载入。导出仅含 `CanvasGraph`，没有资产元数据、任务、文件、密钥，也没有配套导入功能。

返回项目列表会等待保存，再从列表进入其他画布；关闭面板会尽力提交最后草稿，关闭页面有未保存提示。浏览器退出时网络请求不保证完成，重要编辑应等待“已保存到本机”，再关闭。列表每次请求完成后约 4 秒再次读取目录，隐藏页面暂停请求；只在编辑器中读取图 / 任务状态。

节点删除先用Harness弹窗确认并移除相关连线，保留其他节点、结果、任务历史与云端对象。取消 / Escape / 关闭 / 隐藏不删除，确认时再次检查最新任务；未结束任务（含 `unknown` / `save_failed`）或上传中的节点不能删除。只删除连线无需确认。见[ADR-0062](adr/0062-harness-node-delete-confirmation.md)。画布采用目录软删除；没有自动云端对象或任务清理。

## 对象存储与资源访问

统一“无限画布”设置包含对象存储 / 模型设置 / TTS设置。对象存储当前只实现阿里云OSS，可保存多份配置，只有一个活动新写入目标；新配置验证失败不切换。停用配置保留历史读取，已接受上传 / 生成使用固定目标和凭据版本。密钥轮换刷新历史读取及链接缓存，旧任务版本不变。

路径按“前缀 / 文件夹名称__ID / 画布名称__ID / 资源名称__ID”组织，未归档独立层。改文件夹 / 画布 / 节点名或移动画布后，持久清单后台Copy、校验并CAS切换定位；失败读旧对象并可重试。旧对象保留，成功发布的本机暂存清理，派生解码临时文件完成清理；无永久本机媒体库。

页面原媒体与封面从OSS签名HTTPS读取，波形JSON通过认证Host从OSS读取后同源返回，见[ADR-0045](adr/0045-same-origin-waveforms-and-ratio-order.md)。SQLite只存定位与元信息，URL / expiresAt只在有界缓存中；按需最多100项批量解析，默认1小时、剩余不足5分钟刷新。恢复标签、播放 / seek / 预览前检查；更新源恢复时间和播放状态，加载失败只强制刷新一次。模型提交前重新准备参考，URL协议用24小时新签名，当前multipart / data URL格式保持，见[ADR-0043](adr/0043-object-storage-and-expiring-media-access.md)。

## 当前功能边界

已提供逐节点文生图 / 图生图 / 文生视频 / 单图生视频、本地素材导入、引用、结果保存、任务恢复和条件 GPU 合成。GPU 只向共享视口提出合成提示，不改变 React / 布局计算；实现见[架构](architecture.md)，验证见[验证记录](verification.md)。

Seedance仅文生视频、混合参考和首尾帧：无引用自动文生，首份图 / 视频 / 音频默认参考；有引用时仅参考 / 首尾帧下拉，frames必须手动选择。首尾帧最多两图，默认顺序首 / 尾且可交换，清空引用后text、重新接入默认reference。型号数量 / 格式 / 时长和2.5自动帧比例见[模型协议](providers.md#seedance能力与供应商)。不兼容连线仍阻止frames，已接受任务固定模式 / 原Key / EP，历史只读原输入；不接入编辑 / 修改 / 延长 / 样片、不自动执行下游，见[ADR-0056](adr/0056-seedance-mode-inference-from-references.md)。

已增加FishTTS文字转语音；未提供自动执行链路、Agent 调度、聊天文字框选转节点、跨设备同步、协作权限、完整历史浏览和图导入。可播放性依赖编码与浏览器；真实模型兼容性仍需手动联调。
