# ADR-0058：配置脱敏与显式查看完整值

状态：已采纳

部分替代[ADR-0057](0057-provider-cards-and-direct-model-editing.md)的固定遮罩 / 不回显条款与[ADR-0016](0016-host-runtime-task-details-and-credentials.md)的浏览器凭据隔离边界；已接受任务固定凭据版本保持。

文档类型：解释；负责人：项目维护者 / 开发执行者；最近核对：2026-10-29。
记录日期：2026-10-29。配置查看范围、认证或显隐生命周期变化时复核。

## 背景与驱动因素

1. 用户要求所有API Key、EP等配置默认脱敏，参考样式保留头尾、中间星号，并通过右侧眼睛图标查看完整值。
2. 仅切换新输入的password类型无法查看已经保存的Key；用户要求已配置内容同样可查看和编辑。
3. 显示当前配置不得改变编辑草稿、凭据版本、已接受任务或其他模型组合；慢响应不能在取消或切换后展示旧值。

## 决策

- 模型卡片的Key / EP采用头3位、8个星号、尾3位；长度不超过6位时全遮罩，空值不造假。常规models / tts-settings / storage读取只返回Key掩码和状态，EP保持既有配置字段，但默认UI遮罩。
- 模型Key / EP、FishTTS Key、OSS AccessKey ID / Secret表单使用统一眼睛控件。字段默认password；点击显示为完整text，再次点击隐藏；已存Key通过placeholder显示部分掩码，输入留空继续保留原值。
- 已存Key仅在用户点击时通过Harness认证owner路由POST settings-secret读取。严格区分model / tts / storage以及字段；模型只允许现有内置配置UUID，存储校验owner。接口只返回所选字段的当前值，no-store，不接受GET、查询参数、任意Vault ref、历史task ID或额外字段。
- 此接口只读，不更新models / bindings / Vault / 数据库；不调用供应商或OSS、不触发生成。存储查看跟随当前readCredentialRef，任务执行仍固定原credentialRef。
- 读取结果仅留在控件内存，显示已存Key属于预览，不回填编辑草稿。用户实际输入才替换；只查看后保存仍省略api_key或AK字段，保留原凭据。
- 隐藏、取消、保存禁用、切换组合、关闭控件或页面隐藏时清除预览并取消读取。迟到结果由请求序号与AbortSignal拒绝；读取失败保持脱敏，仅显示固定错误和显式重试，不回显服务端私有错误。
- 使用现有Harness按钮与输入、主题色和键盘语义。眼睛是type=button，有显示 / 隐藏标签、aria-pressed与读取状态，不能误提交表单。配置名称、型号等公开识别信息保持原显示。
- 按用户截图移除模型设置底部的“模型配置与凭据保存在本机……”说明段落；设置卡片与编辑表单不显示该段落。

## 备选方案

| 方案 | 评估 |
| --- | --- |
| 常规GET返回全部Key再由UI遮罩 | 无需点击即把所有密钥交给浏览器，不采用 |
| 眼睛只显示新输入 | 无法查看已有配置，不满足用户要求 |
| 点击后按owner / 当前字段只读获取 | 满足完整查看与最小读取范围，采用 |

## 后果

正面：配置字段默认脱敏并可逐项核对；Key / EP编辑语义和原任务版本保持，慢请求不串显示。

负面：用户主动显示期间浏览器与本机屏幕可见完整值，显式查看响应同样可由当前owner检查；掩码不是认证或加密边界。没有新增多用户授权、审计数据库、密钥加密或自动撤销机制。

## 可逆性与重审条件

新增一个owner认证只读路由，原DTO仅新增可选OSS Secret掩码，无新依赖、DDL或数据迁移。成功前保留0.2.52包与一致备份；回退界面不覆盖新接受数据。多用户、远端暴露、历史凭据查看或批量读取需重审；不得扩大为任意Vault读取。
