# ADR-0057：供应商卡片与已保存模型直接编辑

状态：已采纳

Key固定遮罩 / 不回显条款由[ADR-0058](0058-masked-settings-and-explicit-secret-reveal.md)的默认脱敏与显式查看替代；卡片布局和编辑组合保持。

部分替代[ADR-0040](0040-configured-provider-combinations-only.md)的设置概览布局与无行内入口条款；画布选择器仍仅展示完整配置组合。

文档类型：解释；负责人：项目维护者 / 开发执行者；最近核对：2026-10-29。
记录日期：2026-10-29。设置布局、组合身份或编辑保存规则变化时复核。

## 背景与驱动因素

1. 用户指出按模型逐行列出全部已配置渠道会随着型号增长变得过长，要求参考供应商卡片展示，不显示 Base URL。
2. 已保存配置没有直接编辑入口；用户要求能修改已配置模型，同时保持原有逐模型 / 供应商独立Key与EP。

## 决策

- 设置概览按供应商身份分组，以自适应卡片网格展示；宽面板可多列，窄面板自动单列。Model Link 的三个协议地址归入同一卡片，地址仅用于实际组合定位，不在卡片显示。
- 卡片显示供应商名称、配置状态、已配置 / 支持模型数量、图像 / 视频类型，以及已经保存密钥的模型。列表有最大高度并可键盘滚动，型号增加不会无限拉长整张卡片。
- 已保存模型逐项提供“编辑”，定位原 UUID、型号、供应商和协议地址。编辑固定组合身份，只修改该组合 Key / EP，不用供应商共用密钥替代各模型独立配置。
- 未配置供应商保留卡片入口；卡片“配置模型”仅列出该供应商支持型号，并按选中型号解析具体协议地址。顶部通用“配置模型”继续先选择型号再选择供应商。
- Key 输入不回显原密钥，卡片统一显示遮罩。留空保留原密钥；清除需显式勾选且仅作用于当前组合。官方 EP 回填并校验，Key 已存但 EP 缺失的组合显示“待完善”，仍可进入编辑。
- 表单在同一设置面板替换卡片，避免位于长列表底部；进入时聚焦字段，取消 / 保存后回到原入口，入口因清除消失时回到通用配置按钮。
- 保存沿用原 ModelInput / Host 校验。成功才用服务端返回目录刷新卡片并通知画布；失败保留草稿供用户重试，取消无写入。保存中锁定表单，重复提交只派发一次。

## 状态与性质

| 操作 | 结果 |
| --- | --- |
| 打开设置 | 只读获取目录，按供应商身份分组，不触发配置保存 |
| 编辑已保存组合 | 精确回填 EP，Key 留空；其他组合保持 |
| 取消 / 保存失败 | 原配置保持；取消清除临时 Key，失败供显式重试 |
| 保存 / 清除 | 当前组合更新；其他供应商同型号保持 |
| 从卡片新增 | 限定供应商支持型号，按型号定位正确协议地址 |

不改变画布菜单过滤、节点参数、已接受任务快照、凭据版本、媒体或数据库结构；不自动重提任务或批量修改设置。

## 备选方案

| 方案 | 评估 |
| --- | --- |
| 保留逐模型长行并增加编辑按钮 | 编辑可用，但仍随型号增长拉长页面 |
| 每供应商一份共享 Key | 不满足现有独立组合身份与快照约束 |
| 供应商卡片内逐模型直接编辑 | 符合参考布局并保持现有保存契约，采用 |

## 后果

正面：供应商和支持范围更易查看，已有配置可直接修改，原独立组合与任务快照保持。

负面：卡片内模型多时需要滚动；没有新增搜索、自动路由、偏好模型、站点或云端 / 本地分类功能。

## 可逆性与重审条件

仅 Client 布局 / 表单交互变更，无新依赖、字段、路由、DDL或数据迁移。成功前保留0.2.51核验包与本轮 profile / 完整停机数据备份；失败按[ADR-0021](0021-local-update-and-package-retention.md)回退，不覆盖后续新任务。增加共享密钥、批量操作或新的配置作用范围时新建ADR。
