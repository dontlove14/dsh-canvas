# ADR-0029：通用参数滑块与音频节点滚动透传

状态：已采纳

文档类型：解释；负责人：项目维护者；最近核对：2026-10-27。
记录日期：2026-10-27。模型能力、滑块输入或画布滚动变化时复核。

## 背景与驱动因素

1. 用户要求图片 / 视频生成数量以1–10断点滑块选择，视频时长根据模型使用固定档位或区间滑块，交互共用组件。
2. 音频播放器与波形均带nowheel，触控板位于音频节点上时无法平移画布；已有播放 / 波形拖动仍须独立处理。

## 决策

使用React受控[UiSlider](../../src/client/UiSlider.tsx)，提供value / onChange / min / max / step / showStops，以及values固定档位、showLabels和formatValue。原生range按步长索引定位，固定值排序去重后映射回实际数值，可处理4 / 8 / 10等非等距秒数；支持方向键、Home / End、PageUp / PageDown及实际数值ARIA，独立样式继承Harness主题，不新增依赖。

当前全部Mock数量改为1–10。原Mock Video保留身份、4 / 8 / 12秒和4秒默认；新增Mock Video · 区间展示0–12秒、步长1秒、不显示断点，默认1秒。0秒可保留草稿，但提交前说明视频时长需大于0秒，不创建无效任务。真实协议能力仍按原适配器限制，未扩大请求数量或声明新协议。

ModelCapabilities增加可选secondsRange，优先于seconds固定列表；它只由能力定义派生。图 / 快照仍使用现有params.size / n / seconds，n校验上限由4放宽到10，不修改SQLite表列或数据格式、不回写旧数据。切换模型沿用重置参数规则。

移除音频播放器及波形的nowheel，保留nodrag / nopan、播放身份、指针定位、键盘隔离和帧同步游标。普通wheel透传至现有XYFlow双轴平移；参数弹层 / 滑块与音频顶部操作栏继续独立处理滚动。

0.2.27补充边界：nodrag只用于实际波形定位区与播放按钮，不能覆盖整个播放器或底部时间行；整个播放器仍保留nopan维持原生鼠标画布平移 / 双击缩放边界，普通区域可拖节点，专用wheel处理仍透传。见[音频交互规则](0028-audio-waveforms-and-compact-prompts.md)。

本次覆盖参数交互与音频滚动，对[ADR-0023](0023-canvas-wheel-and-trackpad-gestures.md)、[ADR-0025](0025-generation-groups-and-local-mock.md)、[ADR-0028](0028-audio-waveforms-and-compact-prompts.md)作局部补充；其他决定保留。按[ADR-0021](0021-local-update-and-package-retention.md)交付。

## 备选方案

| 方案 | 评估 |
| --- | --- |
| 每处自写拖拽并使用相同数值区间 | 重复逻辑且非等距档位可选到非法值，不采用 |
| 加入外部Slider库 | 当前官方UI包无Slider，需要额外运行依赖，收益有限 |
| 共享原生range并映射合法档位 | 输入和主题统一，连续区间 / 固定值兼容，采用 |

## 后果

正面：参数控件一致、键盘可用、模型能力决定合法值；10个结果继续沿用有序保存 / 主图 / 连线规则，音频节点不再吞掉画布平移。

负面：10条视频会增加本地渲染时间与存储，仍逐项处理。旧版n上限4，不能直接读取新版本保存的n>4图 / 任务；0秒不是可播放视频。原生滑块的视觉与触控板实际手感仍需人工验收。

## 可逆性与重审条件

无需迁移或更改存量数据结构。新版本可读取已有图 / 快照；回退至0.2.16及更早版本必须考虑新保存的n>4，恢复更新前静止完整数据备份或继续使用支持10的版本，不静默裁剪数量。真实模型接入、亚秒时长或官方Slider可用时重审能力与组件映射。

## 验证与证据

[滑块与参数](../../tests/sliders.test.tsx)验证非等距 / 连续 / 步长 / 键盘 / 禁用 / ARIA及四个Mock选项；[Mock流水线](../../tests/mockGeneration.test.ts)验证十个图片 / 视频的有序结果、唯一原文件、主图与重开持久性、零秒草稿 / 提交拒绝；[生成组](../../tests/generationGroup.test.tsx)覆盖10结果主图端点与底部收起；[音频滚动](../../tests/audioWheel.test.tsx)在真实音频DOM上使用XYFlow / D3原生wheel，核对加载区域、波形、播放按钮和双轴平移及保留隔离区域。
