# ADR-0005：连线绑定具体素材，预览独立

状态：已采纳（补录）

文档类型：解释；负责人：项目维护者；最近核对：2026-10-26。
补录日期：2026-10-26；原决策日期未单独留档。复核规则见[ADR 索引](index.md)。

## 背景与驱动因素

1. 一个生成节点可能反复生成、多图切换；下游已经选好的参考不应因预览改变而静默漂移。
2. 任务必须能说明提交时用了哪份素材，而不只是哪个上游节点。
3. 资源主动重新导入表达替换意图，需要与生成结果切换区分。

## 决策

2026-10-26 更新：具体素材 ID 规则继续有效；重新上传现在创建新资源节点，不替换旧出边，见 [ADR-0014](0014-canvas-catalog-and-upload-nodes.md)。下段替换行为仅为 0.1.0 的历史说明。

CanvasEdge 保存 assetId，节点 selectedResultId 仅用于预览；连接时取当前具体素材，任务快照保存参考 ID 列表。校验来源归属、目标、唯一引用和无环，拒绝悬空边。

生成节点预览 / 重生成不改已有边。资源节点主动重新导入将节点 assetId 与全部出边改为新素材 ID，但已提交任务快照不变。完整操作语义维护在[业务参考](../business.md)。

## 备选方案

| 方案 | 未选择的原因 |
| --- | --- |
| 边只记录来源节点，提交时取最新结果 | 新结果会静默改变下游输入，无法准确回溯 |
| 所有边永远自动跟随当前预览 | 查看结果也会修改创作输入，预览与编辑混淆 |
| 把参考文件复制内嵌到每条边 | 重复媒体字节且图变大，备份和验证成本上升 |

## 后果

正面：引用确定；重生成不会破坏既有输入；任务可回溯具体素材；同一素材可被多个下游复用。

负面：使用新生成结果需主动重连；旧媒体必须保留；资源重新导入会有意更新多个下游，需清晰验收；历史素材不能简单按当前预览清理。

## 可逆性与重审条件

可新增显式“跟随最新”模式，但必须保持旧 assetId 边语义并区分预览 / 编辑，不静默迁移存量引用。用户明确需要动态链路或素材版本管理时重审，同时验证历史任务与媒体清理规则。
