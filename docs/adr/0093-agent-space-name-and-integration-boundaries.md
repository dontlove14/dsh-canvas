# ADR-0093：Agent 空间的正式命名与对接边界

文档类型：架构决策记录；负责人：项目维护者 / 开发执行者；最近核对：2026-11-11。

状态：已采纳
后续界面设计以[ADR-0100](0100-agent-space-upper-left-card-and-working-podiums.md)为准：左上浮卡、工作站台缩小态、仅动作展示及整轮完成后的主级正面待机；本轮先准备素材，尚未替换已安装界面。本文命名、真实身份与只读对接边界继续有效，原形态保留为历史记录。
记录日期：2026-11-10
实施版本：0.2.129（命名与文档统一）；延续[ADR-0087](0087-visible-agent-collaboration-journal.md)的日志与权限边界和[ADR-0092](0092-floating-agent-collaboration-network.md)的悬浮界面决策，仅替代该功能此前的描述性名称。

## 背景与驱动因素

1. 同一功能此前使用“智能体协作”“Agent 协作”“协作过程”“协作监控”“协作浮层”等称呼，分别描述入口、过程或界面形态，后续需求与模块对接需要稳定的功能定义。
2. 用户将这个可视化展示 Agent 运行状态的功能正式命名为“Agent 空间”，要求已有 ADR 统一称呼，并保留有效技术决策与既有对接契约。

命名必须覆盖既有入口和完整展示能力，避免把它误认为新智能体、执行调度器、文件工作区，或只指展开态中的关系图。

## 决策

### 正式名称与定义

正式名称固定为 **Agent 空间**，保留 `Agent` 的大小写以及与“空间”之间的一个空格。后续 ADR、需求、功能说明、对接文档和新增界面文案统一使用这个名称。

**Agent 空间是绑定当前根会话的智能体运行与协作可视化功能：以真实会话、公开事件、已保存成果和实际执行回执为来源，让用户查看主智能体与子智能体的运行状态、任务委派、公开过程、成果回传和主级接续。**

Agent 空间包含缩小入口、顶部状态气泡、展开容器中的关系图、任务列表、过程详情与成果阅读；聊天派发卡片是打开同一 Agent 空间并选择相应批次的入口。它不对应新的 Agent 预设，也不等同于 Harness 文件工作区、创作项目或画布。

### 功能范围

| 组成 | 定义与既有行为 |
| --- | --- |
| 缩小入口 | 输入框上方、靠近聊天右边缘的 Voice Ring 与状态气泡；当前根会话有记录时显示，完成后保留，无记录隐藏 |
| 状态气泡 | 显示最新公开状态与事件摘要；子级自报标为报告，未知状态明确显示，不展示模型隐藏思维 |
| 协作关系图 | 圆点绑定真实 root/childId，运行中呼吸、未工作置灰；曲线表达实际委派与短暂反向回传，按 ADR-0092 的有界布局与时效显示 |
| 任务列表与过程详情 | 按实际批次查看任务、来源、公开消息、允许字段的工具摘要和实际回执；历史分页，更新不抢阅读位置 |
| 成果与交接 | 读取该批次已保存成果的正文、版本与认可状态；子级完成、主级接续、用户认可分别展示 |
| 节点定位 | 用户显式点击后定位对应节点，沿用既有导航；不修改节点、夺取控制权或提交生成 |

“Agent 空间”描述功能整体；“Agent 空间入口”“Agent 空间状态气泡”“Agent 空间协作关系图”“Agent 空间任务详情”“Agent 空间日志”用于指明组成部分。运行中的 Agent 数量按真实会话统计，不能把角色类型数量当作运行会话数量，也不能为未启动角色补造圆点。

### 后续对接契约

| 对接对象 | 必须沿用的来源与身份 | 边界 |
| --- | --- | --- |
| 根会话与权限 | HTTP `sessionId` 为根会话，日志 `rootId` 与真实 `childId` 关联；沿用 Harness owner 鉴权 | 切换会话隔离数据，跨根会话任务/成果拒绝；角色名仅用于展示 |
| 任务批次 | 任务记录 `id`，工具交接中的 `taskId`；原生父调用与子会话关联来自宿主日志 | 状态和数量依实际批次，不能以模型自报替代执行回执 |
| 成果 | 实际保存回执中的独立 `artifactId`、版本、status 与 needsReview | 按[ADR-0088](0088-saved-artifact-handoff-and-independent-identity.md)核验复用；批次 ID 与成果 ID 分开 |
| 读取与实时更新 | 现有 `agent-collaboration`、`agent-collaboration-detail`、`agent-collaboration-artifact`、`agent-collaboration-events` 路由，完整参数见[数据接口](../data-api.md) | 同根会话共享 GET/SSE；revision 隔离迟到状态，重连只读当前状态，不重放执行 |
| 日志与临时投影 | `agent-collaboration.json` v1；activity/activeTasks 按现有契约派生 | 正式名称不引入新仓储或迁移；原文全文、隐藏思维、凭据和模型 replay 不进入过程摘要 |
| 界面接入 | 原生 `conversation.input.overlay`，原派发卡片打开同一容器；展开/选择状态按会话隔离 | 不新增协作侧栏页签；明暗主题、减少动态、隐藏暂停、键盘操作与滚动规则沿 ADR-0092 |

现有 `collaboration*` 源码模块、`dsh-canvas-collaboration` 插槽 ID、`canvas-dispatch` 聊天节点类型、HTTP 路径和字段继续作为实现契约。品牌命名不要求将这些机器键重命名为 `agent-space`，也不修改 CanvasGraph、两库 DDL、任务/素材/成果身份或已保存记录。

Agent 空间保持只读观察职责。执行仍由主智能体协调、专业子智能体产出内容、画布执行子智能体落实清单，权限与幂等由宿主持有。后续需要新增操作能力时，必须另行定义执行权限、用户授权及失败恢复，不能因为入口位于 Agent 空间就获得写入或生成权限。

### 旧称与文档衔接

ADR-0087 和 ADR-0092 的标题、正文及索引统一采用 Agent 空间；其原有编号、文件路径、版本记录、历史布局和有效技术决策保留，通过本 ADR 建立命名关系。

历史截图、日志与既有界面中的“智能体协作”“Agent 协作”“协作过程”等显示文字均指向同一 Agent 空间。这些字面文字只用于历史对照和定位已有界面；本轮统一命名与文档，界面文字替换在后续界面修改中按正式名称同步，不将历史实现描述改写为新增功能。

### 固定办公室动作方案的独立验证

2026-11-11 按用户要求先在全角色动作 Demo（历史附件 `Agent 空间-透明循环验证/Agent 空间-透明循环验证.html`，当前仓库未保留可访问文件）验证统一固定办公室、角色透明动作视频和可选前景家具遮挡，再迭代视觉效果。现存后处理 WebM、PNG、场景 SVG 与来源 / 脚底 / 循环参数清单统一存于 [`src/client/assets/agent_team/motions`](../../src/client/assets/agent_team/motions/README.md)；原始角色 GLB、设定图和存量画布成果身份保留。

该 Demo 包含 8 位角色、26 条动作和派发、专业间流转、并行、排队、失败重试、取消、主级接续 / 用户认可等模拟情景。只有主级具备真实左右行走视频；专业间交接使用原地手势和资料标记，不补造专业角色行走或转向。

上述原地跨工位传递是首轮验证方案，用户后续验收已要求替换为真实走近 / 转身 / 面对面递交。固定 1.8 倍、提前准备全部素材、动态待机 / 失败 / 招呼与统一一批补充流程现以[ADR-0098](0098-agent-space-motion-and-preparation.md)为准；新动作未齐时不再演示旧飞文件方案。

Demo 的模拟记录、预设角色数量和时间线不得直接成为真实 Agent 空间的数据来源。用户当前要求先调整独立 Demo；此处记录素材归属与验证边界，不宣告插件实现、安装或真实事件对接已完成，也不替换现有运行界面的 Voice Ring / 会话圆点方案。后续接入仍需保留本 ADR 的真实身份、只读事件、实际回执和用户认可分离等契约。

## 备选方案

| 方案 | 结论与理由 |
| --- | --- |
| 继续使用各处描述性名称 | 不采用；入口、整体功能与关系图容易被误当成不同模块，增加对接歧义 |
| 统一正式名称，保留现有机器契约 | 采用；用户沟通有稳定名称，历史引用与已实现对接保持连续 |
| 命名时同时重命名路由、仓储和历史记录 | 不采用；命名不需要数据迁移或契约变更，会增加兼容成本 |

## 后果

正面：Agent 空间具有唯一正式名称、明确组成和对接边界；需求、ADR 与后续界面实现可以共同引用本记录。

负面：历史截图和现有界面仍可能出现旧称，需要保留一次性对照；后续界面修改时须同步文案，不能将缩小/展开形态误认为不同功能。

## 可逆性与重审条件

本次命名仅更新文档与术语，不涉及数据迁移。以后名称、观察范围或权限发生变化时，新增 ADR 并链接替代关系。跨根会话总览、跨设备同步、新执行入口或非公开数据展示均需独立评估，本命名不预先授权这些能力。
