# ADR-0032：缩放时释放画布缓存合成层

状态：已采纳

文档类型：解释；负责人：项目维护者 / 开发执行者；最近核对：2026-10-27。
记录日期：2026-10-27。视口合成、缩放清晰度或图层策略变化时复核。

## 背景与驱动因素

1. 用户提供放大画布后节点名称、图标和边框发虚的截图，未随画布缩放的浮动面板相对清楚。
2. 现有硬件检测通过后，永久将共享视口设置will-change:transform和零位移三维translate；这种长驻合成提示可能让浏览器放大已有栅格缓存，影响文字和矢量清晰度。截图 / 代码支持该假设，但不代替目标浏览器图层实测。
3. 用户仍要求可用GPU条件下优化平移，同时不能覆盖React Flow视口、改写图数据或打断媒体播放。

## 决策

- 保留[ADR-0010](0010-conditional-gpu-compositing.md)的共享硬件检测、软件 / 未知回退和不持久硬件信息；替代其中“永久视口提示”部分。
- 基础视口设will-change:auto、translate:none，不再强制三维图层；确认硬件且实际视口只平移时，才暂设will-change:transform。
- 订阅React Flow Store中的transform，无论滚轮 / 触控板、控件、小地图或fitView改变视口，逐步比较x / y / zoom。倍率变化立即切到zoom，混合手势后续平移也保持不提示；无变换200ms后idle，下一次固定倍率平移可重新提示。
- 更新仅改变画布容器data-viewport-motion，不逐帧setState或重建节点 / 媒体；不修改React Flow的inline transform、不吸附位置或限制任意小数倍率。
- 页面隐藏、窗口失焦、卸载或硬件回退释放提示 / timer / 订阅。该策略覆盖共享画布所有节点的名称、图标、边框及内容，而非单独改TTS名称字体。
- TTS图标保持用户提供的SVG路径和灰黑currentColor，改为直接嵌入静态SVG，移除mask纹理方式；其他节点原矢量、媒体 / 字体样式保持。
- 本轮不改Host、图 / 任务契约、SQLite、Key或原媒体。自动化证明策略和生命周期，实际清晰度与性能由用户手动验收，不声明已测得GPU提速或消除所有子像素抗锯齿差异。

## 备选方案

| 方案 | 评估 |
| --- | --- |
| 所有状态永久保留GPU图层 | 有缓存放大导致发虚的可能，撤销该部分 |
| 每个名称反向缩放 / 改字号 / translateZ | 增加图层和布局复杂度，改变文字显示关系且未解决全视口缓存 |
| 固定倍率平移短暂提示，缩放及静止释放 | 兼顾既有硬件条件与重新栅格化机会，采用 |

## 后果

正面：缩放时不再被本插件永久合成提示固定旧缓存；保持平移优化条件、视口坐标与原媒体生命周期。

负面：释放合成层可能增加静止 / 缩放时重绘工作；浏览器最终图层和字体抗锯齿仍由其实现决定，需要目标设备验证。

## 可逆性与重审条件

这是纯渲染策略，回退0.2.19无需数据转换。若目标浏览器仍持续模糊、出现平移性能退化或图层内存增长，依据实际图层 / 帧时间 / DPR证据重审；不通过强制逐节点3D图层扩大影响。
