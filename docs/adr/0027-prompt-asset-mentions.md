# ADR-0027：图片 / 视频提示词的稳定素材引用

状态：已采纳

文档类型：解释；负责人：项目维护者 / 开发执行者；最近核对：2026-10-26。
记录日期：2026-10-26。提示词编辑、模型输入语义或引用范围变化时复核。

## 背景与驱动因素

1. 用户提供其他项目的 MentionPromptEditor.tsx，希望生图 / 生视频提示词同样支持输入 @ 搜索与插入素材引用。
2. 节点改名、引用排序、分组切主图都不能悄悄改变已引用的素材；必须保持现有图 / SQLite / 任务与凭据兼容。
3. 本轮继续使用本地 Mock 验证界面和业务，真实模型接入后需要明确提示词与附件顺序的关系。

## 决策

两类生成节点复用同一个 contenteditable 编辑器。借鉴原组件的不可编辑标签、光标附近候选列表、方向键 / Enter / Tab选择、Esc关闭、中文输入法和纯文本剪贴板；不引入其他项目的素材库、头像、模板或富文本运行依赖。候选弹层 portal 到 body，使用宿主主题和压缩封面。

@ 搜索当前画布的已连接参考素材与合法上游素材。按模型支持的类型 / 格式 / 数量过滤，排除本节点、下游形成环的节点、无素材节点与非主图未连接结果。选择未连接素材时，提示词与新增入边作为一次图编辑提交；已连接素材不重复添加边。既有历史入边的具体结果仍可引用。

原 CanvasNode.prompt 字符串保存 `{{asset:UUID}}`，不增字段 / 表。展示标签为 @参考图N与缩略图，N对应当前入边顺序；UUID是事实身份。改名更新说明，不改变引用；删除标签只改文字，保留入边；删除入边或素材后保留失效标签并禁止生成，用户重新引用或删除标签。

Service从已保存节点和有序入边构建快照前验证标签，在任务快照中转换为 `[参考图N]`，同时保留原referenceIds顺序；节点prompt仍保存UUID。Mock与真实提交共享解析规则，纯文本原样保留；历史任务快照不重写。附件仍由入边决定，无标签的既有提示词继续工作。通用占位语义供后续模型联调，不宣称所有供应商理解这些编号。

编辑器使用原生 input / beforeinput / composition / clipboard事件，中文组合期间不重建DOM或触发选择；按UTF-16位置恢复光标，标签原子删除。自定义插入 / 粘贴 / 删除支持最多100条当前编辑会话撤销 / 重做；纯文本复制保留UUID，粘贴不导入HTML，未连接UUID显示失效。原prompt长度32000上限保持。快捷键与画布隔离，提交前flush当前输入，组合输入未完成时提示完成输入。

## 备选方案

| 方案 | 评估 |
| --- | --- |
| 提示词仅插入可变节点名称 | 改名 / 重名后引用不明确，不采用 |
| 整体复制用户组件及其他项目依赖 | 包含本项目没有的业务和模块，不采用 |
| 引入富文本JSON与新增数据库字段 | 本轮无必要，会改变存量契约，不采用 |
| 现有prompt保存UUID标签，共享编辑器和提交解析 | 身份稳定、范围明确并兼容普通文本，采用 |

## 后果

正面：图片 / 视频交互一致，标签和实际输入相互对应；主图切换不改旧引用，Mock可以验证完整持久链路。

负面：失效标签需用户修正；复制原始文本包含UUID语法，跨画布粘贴不会自动查找或复制素材。当前仅协议支持的图片可用于生成输入，未增加视频 / 音频模型输入；输入法、移动端选择和窗口边缘效果仍需人工验收。

## 可逆性与重审条件

不迁移历史数据，纯文本仍可用；旧版编辑器会显示原始UUID标签。以后增加其他媒体输入、供应商专用引用语法、跨画布复制或富文本格式时重审；继续保留任务快照与具体素材绑定，不重新提交旧任务。
