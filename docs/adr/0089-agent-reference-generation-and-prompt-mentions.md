# ADR-0089：Agent 参考生成与提示词标签原子保存

文档类型：架构决策记录；负责人：项目维护者 / 开发执行者；最近核对：2026-11-05。

状态：已采纳
记录日期：2026-11-05
实施版本：0.2.120；延续[ADR-0086](0086-creative-projects-and-scoped-canvas-executor.md)的精确执行清单和[ADR-0080](0080-manual-generation-parameter-review-handoff.md)的人工生成交接。

## 背景与驱动因素

真实会话中主级只创建了带firstFrameId的视频节点，并明确要求执行子级不连线。宿主交接仅核对模型、节点与修订，未发现实际输入为空、提示词没有媒体标签。参数中的素材ID不等于edge.assetId；用户看到参考描述，供应商却收不到参考。

节点输入框的@已用`{{asset:UUID}}`保存在现有prompt中。Agent没有获得同等指导，容易只写“参考图1”而未绑定素材。用户要求大多数有素材的视频优先参考生成，并逐项说明人物、场景及音视频用途。

1. 参考文件必须真实进入模型输入，并与提示词标签的身份一致。
2. 创作模式与用途应由主级及专业成果明确，宿主执行不能猜测或改写历史素材。

## 决策

主级和全部专业方法共享参考策略：有素材时优先参考生成，首尾帧用于用户指定或明确锁定起止画面的镜头。模型能力、供应商、素材身份和用户生成点击规则保持；能力不符交回主级协调，不自动丢弃参考或换模型。

| 边界 | 契约 |
| --- | --- |
| inspect → 主级/执行子级 | promptReferences返回实际可引用素材的source、assetId、kind、filename、token；专业级限获授assetIds |
| 主级清单 → 执行子级 | create/update新增可选references数组，每项严格source/assetId，最多100；prompt含每项字面token和用途 |
| 执行子级 → 图持久化 | 构造节点、真实边和必要视频模式推断后同次mutateGraph；新增边ID由operationId及引用序号稳定生成 |
| 旧分步connect → 主级 | 返回reference.token，并同次保存真实边与依赖它的视频模式；随后必须补提示词标签 |
| 主级 → 人工生成交接 | 核对原始首尾帧参数、真实边、每份参考的标签及完整模型生成参数；返回实际videoMode与references |

references追加明确输入；已存在的同source/assetId边复用原身份，不删除或替换历史边。重复清单、错误归属、循环、无效类型/数量、未连接token、缺少新引用token在提交前拒绝，无半保存。原有epoch、根身份、精确清单、CAS和操作幂等继续执行。只改名或位置时不重写旧提示词。

交接先验证已保存的原始显式模式，防止模式推断把悬空firstFrameId静默变为文生视频；无显式模式的旧节点仍按实际边推断。已连接媒体都必须在prompt中有标签；用途的语义质量由Agent指导和人工核对，宿主只确定标签与输入身份。失败保留当前控制，不派发生成。

原生呈现回执的可选reason缺失时不返回undefined，避免已保存节点被ToolRuntime误判“value is not lossless JSON”。不在通用工具层做静默JSON清洗。

## 备选方案

| 方案 | 结论 |
| --- | --- |
| 仅修改Agent提示 | 不足以拦住引用遗漏和交接假成功 |
| 所有视频强制参考模式 | 不采用；仍需无素材文本模式、明确首尾帧和各模型能力 |
| 宿主猜用途、补写提示词或重新连到最新输出 | 不采用；改变专业意图和历史素材身份 |
| 现有工具可选原子引用参数并加强交接 | 采用；执行清单可精确审计且兼容旧调用 |

## 后果

正面：节点、参考边与标签同时落实，交接失败能明确暴露缺口；无参考连线的假准备不再通过。
负面：主级清单需要提供精确引用，旧节点缺标签时需先调整才能交接；语义用途仍需人工核对。

CanvasGraph、两库DDL、prompt存储和sidecar版本不变；不新增工具或HTTP路由，不迁移原会话/节点。旧参数未传references继续兼容；旧缺引用节点交接会失败，需主级读取现状并提交新的明确修改清单。升级不自行修补用户图或重跑批次。

新错误409 AGENT_REFERENCE_INVALID用于缺标签和悬空帧依赖；其他图/模型错误沿用原校验。相同成功operationId读取旧回执，不生成重复边。失败后创作意图变化使用新operationId，修订冲突先重新读取。
