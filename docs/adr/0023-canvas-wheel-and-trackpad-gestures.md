# ADR-0023：画布滚轮与触控板操作映射

状态：已采纳

文档类型：解释；负责人：项目维护者 / 开发执行者；最近核对：2026-11-06。
记录日期：2026-10-26。输入规则或React Flow事件处理变化时复核。

## 背景与驱动因素

1. 普通鼠标滚轮和触控板双指移动此前沿用React Flow默认缩放，用户要求改为移动画布。
2. 左键框选、空格加左键拖动画布和修饰键加滚轮缩放已经符合习惯，需要保留；macOS上同时支持Command与Ctrl。
3. 鼠标与触控板都发出wheel事件，按设备或delta大小猜测会误判惯性 / 高精度滚轮；编辑面板和播放器也需要保留独立滚动。

## 决策

采用React Flow原生属性：`panOnScroll=true`、`panOnScrollMode=Free`、`panOnScrollSpeed=1`、`zoomOnScroll=false`、`zoomOnPinch=true`，`zoomActivationKeyCode`使用稳定的`['Meta', 'Control']`数组。

普通滚轮上下平移；双指移动使用deltaX / deltaY沿两轴平移；空格加滚轮仍平移。修饰键由React Flow键盘状态切换原生wheel处理器，以指针为中心缩放。保留浏览器以Ctrl+wheel编码的触控板捏合缩放、原缩放边界和视口保存。

左键拖动框选与空格加左键拖动继续使用现有`selectionOnDrag` / `panOnDrag`状态。不新增全局wheel监听器或设备识别；编辑器、播放器、工具栏沿用`nowheel`隔离。提示、业务规则和手动清单同步新映射。

后续工具栏已用画布根现有非passive监听转交原生renderer处理；0.2.61按用户要求将节点内自定义视频播放器纳入同一转交范围，覆盖画面、时间、播放按钮SVG与进度条上的双指平移 / 惯性及捏合 / 修饰键缩放。保留指针中心、原边界与视口保存；编辑器与原视频模态预览不转交，不增加新监听器、设备猜测或独立视口计算。此规则替代上文历史的节点播放器整块滚轮隔离，详见[ADR-0024](0024-custom-video-and-chromeless-preview.md)。

0.2.127将实际节点浮动编辑卡片、只读检查卡片和生成记录卡片纳入同一转交入口，替代上文历史的整块编辑器滚轮隔离。ReactFlow的children是renderer的兄弟元素，wheel不会经过原生监听；只移除nowheel不能解决。卡片以`data-dc-canvas-wheel="true"`显式标记，从所属ReactFlow根解析直接renderer，并检查当前画布归属；保留nodrag / nopan / nowheel保护指针操作，不扩大到参数 / 模型选择弹层或原文件预览。

卡片内普通wheel先检查实际滚动容器：能沿当前方向滚动时保留原生滚动，不能滚动或已到该方向边界时转交画布平移。捏合与修饰键wheel始终转交；只放行Meta / Control单独按键供原生键盘订阅，提示词删除、输入、撤销等快捷键仍隔离。沿用原生指针中心、边界、视口保存和监听生命周期，不猜设备或自行计算视口。

## 备选方案

| 方案 | 评估 |
| --- | --- |
| 保持React Flow默认滚轮缩放 | 与明确用户要求不符 |
| 按设备 / delta阈值区分触控板和鼠标 | 无可靠标准，容易误判，不采用 |
| 自定义全局wheel并自行计算视口 | 需要额外维护指针中心、缩放边界、事件归属，不采用 |
| 原生双轴平移加修饰键缩放 | 利用现有wheel、键盘和视口生命周期，采用 |

## 后果

正面：普通滚轮和双指移动统一为平移，两种修饰键均可缩放；保留存量选择、资源双击、控件和自动保存规则。

负面：普通滚轮的使用习惯改变；不同系统 / 浏览器的自然滚动方向和捏合编码仍需目标设备人工验收。

## 可逆性与重审条件

仅客户端输入映射，不修改存储结构、节点 / 素材 / 任务身份。将来用户更改操作习惯、React Flow升级改变原生处理，或出现修饰键 / 控件事件冲突时重审。
