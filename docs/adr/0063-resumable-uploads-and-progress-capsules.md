# ADR-0063：断点续传与上传进度胶囊

状态：已采纳

并发上限、胶囊展示与尺寸由[ADR-0064](0064-bounded-upload-capsules-and-five-transfers.md)部分替代，其余恢复协议保持。

文档类型：解释；负责人：项目维护者 / 开发执行者；最近核对：2026-10-29。
记录日期：2026-10-29。恢复协议、缓存、并发或回退策略变化时复核。

## 背景与驱动因素

1. 原拖拽和按钮共用全文件流，接收中断只能重新上传；用户要求自动续传，并支持刷新和宿主重启后恢复。
2. 用户要求画布顶部居中显示小胶囊，左侧圆环、右侧百分比；多个横向叠放并露出每个圆环，未完成时仍可追加文件。
3. 保持现有画布DTO、主库schema 3的23表、预审库schema 1的7表、原上传 / 导入 / 对象存储身份。

## 决策

新客户端先将完整原始Blob、UUID、文件名、类型、位置及可选引用目标写入IndexedDB，然后以size显式开启续传。每次主动新上传使用新UUID，恢复使用原UUID和原字节。浏览器缓存不可用或配额不足时在创建服务端占位前报错，不虚假承诺刷新可恢复。缓存以API路径区分，不保存凭据。

Host使用最多4MiB的固定边界分块、严格offset和SHA-256。字节流按位置有界写入并fsync，再原子写入独立600权限的resume.json及目录fsync；记录累计offset和各块hash，不增加数据库字段。启动与最终完成复核已提交的块，清除未提交尾部，缺失 / 短文件 / 同长度损坏明确失败。每个UUID串行处理，数据目录原执行锁限制单Host；停止时中断流并等待所有上传操作结束再关闭数据库。

GET进度使用独立buffered的upload-status路由，POST字节仍使用streaming的upload路由。Harness0.2.1-rc.2会为streaming请求始终添加body，GET / HEAD会在到达插件前被WHATWG Request拒绝；不能将GET挂到streaming上传路径。编译产物检查禁止这种注册组合，实际安装后读取原完成会话核验认证HTTP。

客户端最多4个传输并发，更多文件缓存后等待。网络、超时、408 / 429 / 5xx按退避重试，online / focus唤醒；401 / 403保留缓存等待登录恢复。任何不明回执先GET进度，不直接创建新UUID或重发已提交块。完整接收后通过幂等complete将既有导入事务一次提交；重复完成返回原taskId。导入沿用原固定对象存储与重试保存流程，接受不代表OSS保存成功。成功发布清理Host暂存，客户端确认接受后清理缓存；带引用目标时保留到幂等连线完成，图修订冲突重新读取，继续遵守原模型限制和Seedance规则。

画布顶部胶囊为88×32px、圆环20px；相邻重叠52px，因此每个左侧圆环完整露出，最后一枚显示百分比，悬停提供对应文件 / 进度。窄区域保留单行横向滚动。色值继承Harness，等待恢复环使用现有警告色，减少动态效果关闭进度过渡。上传入口可继续追加文件，不将传输进度塞进媒体或生成任务Loading。

无size的旧接口保留全文件流与旧中断语义；新恢复判定移到Runtime启动，不能将所有receiving统一标失败。终态错误cancel仅结束未接受上传并清理暂存，不取消已接受导入，不删除节点或云端文件。

## 备选方案

| 方案 | 评估 |
| --- | --- |
| 全文件自动重新上传 | 丢失已传输进度且可能重复节点，不满足需求 |
| 仅内存保留File | 可恢复短断网，不能刷新后自动恢复 |
| 数据库新增分块表 | 可实现，但不符合本轮两库结构保持约束 |
| 直接浏览器OSS分片 | 需要新的浏览器凭据 / CORS / 云端恢复生命周期，超出本轮已有Host上传范围 |
| 串行上传 / 禁止追加 | 无法满足用户多胶囊与未结束时追加要求 |

## 后果

正面：同一身份保留已确认字节，恢复不重复节点 / 导入，拖拽与按钮统一；进度独立、可追加，主库与预审持久契约保持。

负面：浏览器保留一份原Blob，Host保留接收暂存；有空间成本。换浏览器、切换localhost / 127.0.0.1来源、清除站点存储或浏览器主动回收缓存后无法恢复原字节，Host不会伪造恢复或自动删除待续传文件。页面关闭期间不传输；重开插件后继续。Host到OSS仍是原导入 / 重试保存流程，本轮续传保证仅覆盖浏览器到Host。实际浏览器缓存配额、断网事件与胶囊视觉由用户验收。

## 可逆性与重审条件

无DDL或存量图变更。回退前必须确认没有新协议receiving，或在停机状态恢复同一次完整备份；不可让0.2.62接管未结束的续传会话。浏览器缓存和Host暂存需同时保留，不通过清空数据库恢复。协议、并发、存储容量或浏览器策略变化时重审。
