# ADR-0025：简洁生成节点、多结果分组与本地 Mock

状态：已采纳

文档类型：解释；负责人：项目维护者 / 开发执行者；最近核对：2026-10-26。
记录日期：2026-10-26。生成模型接入、分组或参数契约变化时复核。

## 背景与驱动因素

1. 用户提供七张参考图，要求生成节点只显示图标 / 主图，编辑卡片和参数面板简洁，资源只输出、生成输入输出都有圆圈加号。
2. 同次多图片 / 视频需要分组、主图选择与展开收起；主图切换不能破坏下游已引用的具体素材。
3. 用户明确当前尚未接入模型，点击生成先用Mock假数据验证UI和业务，动态参数以后随真实模型调整。

## 决策

0.2.11根据用户验收反馈，由[ADR-0026](0026-primary-only-group-interaction.md)更新分组交互：只给主图端点、展开隐藏编辑卡片、收起固定在左下结果。以下保留0.2.10初版决策背景；Mock / 持久化 / 主图保存原则仍有效。

生成节点使用独立最小组件，浮动名称复用改名交互；空态不显示冗余标题 / 状态栏。选中后下方卡片提供上传引用、提示词、模型、参数摘要和生成箭头。参数弹层从模型capabilities推导分辨率 / 比例 / 数量 / 视频时长，只允许受支持的真实尺寸组合。

图片 / 视频共用分组逻辑：默认显示第一份或所选主图，右上角数量展开两列结果，逐份下载 / 设主图，当前主图按钮收起。主图使用现有selectedResultId保存，展开状态只在当前页面。展开每份提供result:assetId输出；边仍只保存source / target / assetId。已有连线不随主图或折叠变化改绑；较早批次的边保持默认节点输出位置。

画布UI固定选择内置Mock并调用独立mock-generate路由。真实设置、适配器和已接受任务保留；旧节点不自动改模型，用户主动选择Mock。完整 / 精简图片与视频提供不同参数能力，不假定所有模型支持相同参数。

Mock任务复用现有事务、CAS、幂等、引用hash、持久队列、文件发布与恢复。只有全部字段匹配内置ModelRecord才走无凭据分支，credential_ref为null，submit_issued不置位，不调用模型网络。sharp合成本地图片，ffmpeg生成同尺寸 / 所选时长MP4；提示词只参与样例配色变化，参考图不执行真实推理。输出ID由同一taskId / 序号确定，完整暂存文件后持久描述，保存失败复用原描述；中断后允许安全本地重渲染。存量DDL、图 / 边 / 任务DTO均不改变，媒体尺寸 / 时长复用现有字段。

## 备选方案

| 方案 | 评估 |
| --- | --- |
| 只做静态UI，不保存Mock结果 | 无法验证引用、下载与刷新恢复，不采用 |
| 浏览器假结果或远端图片URL | 不能验证真实文件发布 / 任务持久化，且依赖外部网络，不采用 |
| 新增分组表 / 节点类型 | 破坏现有契约且本轮不需要，不采用 |
| 本地Mock加复用现有批次与主图 | 满足本轮完整业务验收，采用 |

## 后果

正面：可无Key验证生成、分组、主图、具体素材连线和恢复；图片 / 视频统一规则，真实配置和历史任务保留。

负面：Mock不是真实推理，不能用于评估模型效果；大尺寸与多视频仍消耗本机CPU / 存储。当前无完整历史批次切换器、没有取消运行中任务；真实模型能力接入后仍需单独联调。

## 可逆性与重审条件

真实模型接入时调整UI模型来源 / 提交入口与能力定义，保持Mock身份隔离和旧任务恢复。若分组需要独立移动、跨批次整理或更多数量，再评估新数据模型。现有决定不授权数据迁移或覆盖已有配置。
