# ADR-0056：Seedance 根据引用自动判断生成模式

状态：已采纳

替代[ADR-0055](0055-seedance-video-modes-and-independent-provider-routing.md)的手动文生视频选择规则。

文档类型：解释；负责人：项目维护者 / 开发执行者；最近核对：2026-10-28。
记录日期：2026-10-28。模式判断、连接入口或快照规则变化时复核。

## 背景与驱动因素

1. 用户指出没有图片 / 视频 / 音频引用时自然就是文生视频，无需额外手动选择；接入任意素材应默认参考生成。
2. 首尾帧只由用户手动切换。清空全部引用后应回到文生视频，再次接入素材不能自动恢复首尾帧。旧实现还会因text模式阻止首份连线 / 上传 / @引用。

## 决策

- 无引用显示“文生视频”自动状态，不提供文生视频下拉选项。接入首份图片 / 视频 / 音频即默认reference；有引用时下拉只有参考生视频和首尾帧生成。
- frames必须用户主动选择；原最多两图、按连接顺序默认首尾、角色交换及2.5自动比例保持。部分移除保留frames，清空后切text并清除帧角色；重新连接恢复reference。
- 输入资格允许空视频节点接入首份合法图片 / 视频 / 音频。连线、上传、@引用、删除单边 / 全部引用 / 来源节点经过同一图编辑转换，模式与边一起保存，不靠渲染Effect回填。
- 图编辑只处理入边真正变化的Seedance目标节点；边未变时直接返回，不把拖动变成全部节点参数同步。
- Client展示 / 校验和Host新任务快照共用当前引用推导。无引用的旧reference / frames草稿也能创建text任务；有引用且无显式frames的新提交为reference。Host图校验使用有效模式，不要求API调用者先选择text / reference。
- 已接受任务按原快照、ID、EP和Key执行；推导仅用于草稿 / 新提交，Providers不改已接受任务的模式，不自动提交、重提或改写历史。

## 状态与性质

| 当前状态 / 操作 | 结果 |
| --- | --- |
| 无引用 | text；可输入提示词生成，可上传 / 连接素材 |
| 接入第一份素材 | reference，不自动frames |
| 有合法图片，手动切frames | frames，默认顺序角色 / 可交换 |
| frames移除部分引用，仍有图 | frames，剩一图为首帧 |
| 清空全部引用 | text，清除角色 |
| 清空后重新连接 | reference |

必须保持：首尾帧不自动选中，引用与模式一致保存，不改变已接受快照。最终应达到：首份合法素材可进入，全部移除后可继续文生。边已保存及配置可用是条件；保存冲突仍保留草稿。此局部转换无新锁 / 定时器 / 重试，原requestId幂等与未知提交处理保持。

## 备选方案

| 方案 | 评估 |
| --- | --- |
| 保留三项下拉并要求先切模式再连接 | 多一步且阻止自然引用流程，拒绝 |
| 只显示推导结果，清空仍持久保留frames意图 | 重接会意外恢复frames，拒绝 |
| 入边编辑时统一转换并保存，有引用时仅两项选择 | 满足默认与人工选择，采用 |

## 后果

正面：无需手动选择文生模式，所有素材入口遵守同一转换，拖拽快路径保留。负面：清空后必须重新主动选择frames；不兼容音视频 / 超数量时仍拒绝frames。2.0仅音频参考仍需图或视频，2.5纯音频能力保持。

## 可逆性与重审条件

不增加字段、DDL、schema版本、依赖或HTTP路由，不启动数据迁移，不清理配置 / 图 / 媒体 / 任务。模式继续写已有params JSON，历史保持。成功前保留0.2.50包及本轮停机备份；回退不得覆盖安装后新接受的任务。增加自动帧选择或更改引用判断条件时新建ADR并更新状态表。
