# ADR-0082：Wan Model Link 供应商临时停用

状态：已采纳

文档类型：解释；负责人：项目维护者 / 开发执行者；最近核对：2026-11-03。
记录日期：2026-11-03。用户确认网关恢复服务、模型目录或历史任务恢复规则变化时重审。

## 背景与驱动因素

1. 用户确认 Model Link 已停止提供 Wan 视频模型，要求暂时关闭 Wan 3.0 / Prime 的该供应商，保留 Aliyun 官方。
2. 已保存密钥、节点和任务仍需可读，不能为关闭候选而删除或重写存量数据。该决定部分替代[ADR-0067](0067-wan-and-minimax-native-video-protocols.md)的 Wan 双渠道可用性，不改变原协议或历史记录。

## 决策

1. 从内置可配置目录过滤 Wan Model Link 两个组合（UUID 尾号001f / 0021），保留 Aliyun 官方两项0020 / 0022及其他供应商的原UUID。目录由41项降至39项，不重新编号。
2. 设置页不提供两项的密钥配置 / 编辑入口，画布和 Agent 不将其作为生成候选。共享 `isSuspendedModelLinkWan` 同时限制配置目录与可用性；Host 新配置 / 生成直接返回400 / MODEL_NOT_SUPPORTED，提示选择 Aliyun。
3. 不删除已保存模型、Vault密钥或绑定，不重写节点、画布、历史快照、任务ID和数据库。旧节点需用户自行选择官方组合并配置官方Key；不共享密钥或自动替换供应商。
4. 保留提供商标签和协议适配，已取得外部ID的任务继续按冻结的原提供商 / Key / ID查询；尚未发送的任务不向停用网关新建请求，沿原Runtime处理失败并保留任务身份。失败任务不自动重新生成；保存失败沿原任务仅恢复下载 / 保存。
5. 临时停用由维护者管理，没有到期自动开启。恢复须用户确认网关可用，移除共享停用判断及 Host 两个门禁，并重新检查原UUID、配置、候选与历史兼容。

## 备选方案

| 方案 | 评估 |
| --- | --- |
| 只注释设置控件 | 已配置节点和直接API仍可能提交，未采用 |
| 删除旧配置和密钥 | 无法保留历史身份及未来恢复，未采用 |
| 目录 / 候选 / Host同时关闭，历史保留 | 符合用户暂时关闭要求，采用 |

## 后果

正面：停止新增网关使用，同时保留旧配置与历史；其他Model Link系列、官方模型和数据库保持。

负面：原网关节点需用户手动选择官方并配置官方Key；服务恢复后需开发者撤销停用并重新交付。

## 可逆性与重审条件

源码停用可撤销，原UUID和密钥绑定仍在。服务恢复由用户确认后重新交付，不把协议测试当作网关线上可用性证据。
