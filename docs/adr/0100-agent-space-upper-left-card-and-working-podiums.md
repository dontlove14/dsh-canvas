# ADR-0100：Agent 空间左上浮卡与工作站台缩小态

文档类型：架构决策记录；负责人：项目维护者 / 开发执行者；最近核对：2026-11-12。

状态：已采纳
记录日期：2026-11-11。
部分替代：[ADR-0092](0092-floating-agent-collaboration-network.md)的右下侧入口、Voice Ring、摘要气泡、关系图与默认缩小展示；[ADR-0093](0093-agent-space-name-and-integration-boundaries.md)的对应界面形态；[ADR-0098](0098-agent-space-motion-and-preparation.md)中整轮回复完成后的默认招呼 / 待认可展示。命名、真实身份、只读日志、成果 / 认可和已有动作归属继续有效。

## 背景与驱动因素

1. 用户已确认独立动作 Demo，指定参考图中的对话左上悬浮卡片和缩小按钮，要求移除旧右侧入口及摘要气泡；协作用角色动作表达，不显示任务文字、状态标签或成果正文。
2. 正面素材另由画布 Agent 一次准备 9 项，用户已观看并接受当前原片及轻微瑕疵，0.2.136使用对应透明循环替换0.2.135的同角色侧向替代；用户指定预设切换时确认、全页加载蒙版及真实百分比。
3. 根会话完成、子任务完成、连接中断必须区分；全部动作不能靠假进度、逐个首次播放或修改任务数据实现。用户后续已明确授权本轮接入后安装并重启 Harness，替代前轮暂缓安装要求。

## 决策

### 位置与生命周期

卡片绑定当前根会话，位于对话内容区域左上、聊天页顶栏之下。0.2.135–137曾预留整行高度，导致卡片右侧空白；0.2.138–139改为左侧独立分栏，又造成整列空白。用户明确要求左上悬浮，0.2.140因此移除两种占位，卡片独立绝对定位叠在内容区左上，正文、输入框和宽度控制保持原生布局。旧右侧入口、Voice Ring、摘要气泡及关系图入口由新卡片替换，不新开协作页签。原派发消息卡片保留按需展开的原任务详情，供原有成果阅读路径使用，不放进 Agent 空间。

0.2.137按用户截图修正外观：卡片无独立白色外框、描边和内边距，展开时直接展示办公室背景，缩小时仅透明角色与站台。展开 / 缩小按钮固定于卡片右上角，跨边悬浮，不占内容宽高；外层允许按钮溢出，办公室与站台各自保持裁切。窄窗口为按钮保留外侧空间，正文避让和横向滚动边界仍有效。

0.2.140的seat只在资源就绪且卡片可见时挂载，`position:absolute;top:16px;left:12px`；尺寸和展开标记仅写入插件自建seat，不修改原生内容区class、style或dataset。展开宽度375px，低高度310px；缩小宽度随实际站台人数变化，超出窗口可用宽度时沿原横向滚动浏览。两态宽度仅约束卡片自身并为跨边按钮留空，不预留任何整行高度、左侧外边距或分栏宽度，不覆写`--dsh-chat-content-width`和宽度控制柄位置。保持原scroll直接子级、原输入框、草稿、滚动位置和原宽度偏好，不重建 / 搬移原生元素，不增加测量或改Harness上游。正文从原位置滚动，浮卡仅覆盖自身展示范围，用户用既有按钮控制展开 / 缩小；卡片下方不再是一整列占位。

| 事件 / 形态 | 展示 |
| --- | --- |
| 尚无本轮发送或历史完成展示 | 不凭空制造工作的 Agent |
| 用户消息实际发出、主级开始本轮处理 | 显示卡片，默认展开办公室，主级进入工作表现 |
| 用户点击卡片右上悬浮缩小按钮 | 仅当前正在工作的 Agent 以正面工作循环站在独立站台上，并排展示 |
| 某个专业 Agent 工作结束 | 从工作站台展示中移除；不能据此判定整轮主级回复结束 |
| 主 Agent 本轮最终回复完成 | 全部角色的展示回到待机，自动缩小为主 Agent 单人站台，正面待机循环 |
| 会话已停止、异常或未知，用户缩小且没有实际工作角色 | 保留主 Agent 单人正面待机站台；原生命周期状态保持，不视为最终成功完成 |
| 用户主动重新展开 | 可查看当前办公室；空闲角色使用已有待机动作 |
| 下一轮用户发送 | 默认重新展开并进入新的本轮工作展示 |

0.2.135–138的缩小态仅在本轮成功完成后保留单人主级待机；用户在已停止的历史会话缩小时，工作角色集合为空，结果只剩展开按钮。0.2.139按本轮反馈补充空集合规则：有实际工作角色时继续仅显示工作者；没有时保留当前主级单人正面待机，使用已有M09与1.0倍循环，`working=false`。停止 / 错误 / 未知不转成成功完成，不改变自动收起条件；展开态仍使用原失败 / 待机动作。其他专业待机、排队、失败角色不进入缩小站台，不用工作动画伪造运行。

最终回复完成由当前 root 本轮真实生命周期确定，不由子级自报、工具返回、任意一次消息落盘或断流推测。展示回待机不改写任务 / 日志 / 成果状态，不等同用户认可、不重提执行。卡片只读观察的权限边界保持。

### 内容与素材

展开态使用已确认的办公室及真实侧向工作 / 行走 / 交接动作，表现来自实际公开状态。缩小态每个工作角色单独站台、正面工作，无任务状态文字、任务内容、摘要气泡、工具清单或成果正文。角色类型不代表实际运行会话，不能以 8 类素材虚构 8 个活动子 Agent。

站台由 UI 独立绘制，不烘焙进视频。新增目标为 9 项：M09 主级 `idle-front`、M10 主级 `work-front`、S09 / V09 / B09 / A09 / R09 / F09 / E09 专业 `work-front`。复用先核验真实已有正面循环，M08 转向用户后回侧向的招呼不能代替连续正面待机。其余专业角色正面待机 / 失败 / 招呼 / 行走不属于本批次。

按[ADR-0099](0099-agent-space-per-action-playback-rates.md)延续动作倍速：正面待机 1.0 倍、正面工作先 1.8 倍；既有 M08 招呼 1.2 倍与 V07 / R07 右步态 1.6 倍保留。旧招呼素材不删除，但新卡片完成后默认播放正面待机，不因旧 Demo 的待认可情景延迟自动收起。

视频准备就绪与播放请求生命周期分开：暂停、后台恢复或展开 / 缩小造成旧`play()`被中断，不代表视频首帧失效，不能由旧拒绝回调隐藏已经恢复的视频。每次挂载准备实例后应用当前暂停条件、循环和倍速，成功播放与`playing`事件确认就绪；旧成功回调也只作用于当前播放请求。减少动态、后台和不可见时仍暂停。M09的循环由视频自身驱动，不依赖展开办公室的动作时钟，不新增模型调用或重新生成。

内容简化不删除真实协作日志、原任务、已保存成果或认可记录，不新增用户 @ 指派或执行功能。正式命名与机器键继续遵循 ADR-0093。

### 预设确认与资源准备

只包装 Harness 原生 `conversation.hero.agentPreset` 的 `select`，保留原选择器、默认选项和新会话暂存语义。显式选择 `canvas-creator` 成功后，弹窗正文为“当前 Agent 需提前加载资源，请耐心等待”，提供“确认 / 取消”：

- 确认后全页蒙版播放固定 `thinking-orbs@0.3.2` 的 `solving`（官网 Solving…）动画，显示“资源加载中”、百分比与进度条。用户已指定 Loading，不再询问选型。
- 取消通过同一个原生 `select` 恢复刚才的预设；刚才没有明确选择时取真实 `isDefault` 选项，不硬编码默认 ID。取消不下载素材，重复点击不重复恢复。
- 加载失败允许重试或取消；恢复预设失败单独显示重试恢复，网络恢复不能误触发资源加载。会话变化 / 卸载 / 插件停用使旧确认失效，不写另一会话。
- 返回已有本预设历史会话自动准备资源，不再模拟一次用户切换；已准备的资源共享复用。

资源由同源只读 `GET /api/canvas/v2/agent-space-assets` 提供包内清单及白名单文件。构建核对原片 / 首帧 SHA-256，只复制动作、首帧与三个场景 SVG；运行清单不含原文、任务或素材来源私密路径，SVG 去掉演示工位文字。下载 4 并发、解码 2 并发，网络和首帧准备有 60 秒超时；完整字节 / 长度 / SHA-256 校验后保留共享 Blob，再准备每个首帧。进度按下载字节占 90%、首帧完成占 10%，全部成功才 100%。失败保留成功资源，只重试缺失或未解码部分；插件卸载中止并释放 Blob / 视频 / 订阅。

### 真实状态与实施边界

主级来自原生 `sessions.binding(rootId)`，发送接受态立即展开；只消费 durable `turn/start` 与同轮 `turn/end.reason.kind=completed`。断流 / 错误进入未知或失败，不视为完成；历史 prepend / 重复 seq 不重播。尚无本轮 start 的恢复窗口只展示实际活跃子会话，不能把旧完成任务当作当前工作者。

子级来自共享 root GET/SSE 的 `childId` 和公开任务状态；同角色多个实际 childId 分别站台。root 最终完成只改变展示，全部待机并自动缩小主级；不写回任务、CanvasGraph、DDL、原成果或认可。

公开日志目前提供 root→child 派发、child→root 回收；据此播放主级走近、按手掌接触时间同步交接、返回原位并恢复右向。不得从角色顺序猜专业 Agent 间交接。缺主级独立转身片时保留既有右向恢复，不镜像、平移静态图或用其他角色冒充转身；真实专业间交接需后续明确公开链路才可接入。

[素材准备指令](../../发给画布Agent-Agent空间正面动作素材准备.md)作为本批次来源保留。资产位于 `src/client/assets/agent_team/motions`，全部87条动作与首帧参与预加载。9条正面来源的画布、节点、任务、素材ID、候选、原片hash及真实引用保存在本地素材清单；S09 / V09使用用户认可的最新候选2，其余使用候选1。只派生透明WebM与首帧，不修改原片、画布节点、引用或任务。原片已获用户认可；后处理后的站台合成仍由用户手动验收。可见性、后台、减少动态与横向滚动保护沿用公共机制，暂停不生成日志。

## 备选方案

| 方案 | 判断 |
| --- | --- |
| 保留右侧 Voice Ring / 摘要 | 不满足位置与纯动作目标，替换 |
| 每次开始播放时才下载 | 无法同步多人动作，采用切换确认后提前准备 |
| 缩小仍显示整间办公室 | 小角色难辨，使用实际工作者独立站台 |
| 全部角色补齐所有正面动作 | 本轮无对应用途，仅准备 9 项 |

## 后果

正面：卡片只表达实际协作，根完成与子完成隔离；共享资源一次准备、有限重试，原任务、成果和数据身份保持。

负面：首选预设要等待资源准备，包体和浏览器内存增加；缺主级转身与专业间公开链路，发丝残边和合成效果需用户手动确认。原片可接受的瑕疵不触发重新生成。

## 可逆性与重审条件

展示为只读客户端派生，无 schema 迁移；本机web / 3080继续沿已授权交付流程。按 ADR-0021 备份目标配置、安装同一核验包、正常重启和加载核验，成功前保留已安装0.2.139用于回退，成功后再清理根目录旧包。0.2.135保持未安装候选，0.2.140保留137的外观 / 播放与139的主级待机兜底，本轮移除138–139分栏，落实用户要求的真正悬浮。

若需要展示非工作者、增加任务内容、改变自动收起时机、开放执行入口或接入专业间公开交接，调整设计与权限边界；新正面素材只替换对应动作 / 首帧并重建资源身份清单。
