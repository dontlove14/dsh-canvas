# ADR-0039：画布模型选择仅显示有配置的真实模型

状态：已替代

文档类型：解释；负责人：项目维护者 / 开发执行者；最近核对：2026-10-27。
记录日期：2026-10-27。模型入口、默认渠道或Mock退出策略变化时复核。

已由[ADR-0040](0040-configured-provider-combinations-only.md)替代：按每个模型与供应商组合的Key过滤，未配置渠道不再显示；原空态、无Mock后备与历史数据保留约束继续有效。

## 背景与驱动因素

1. 用户要求没有配置任何供应商的模型不出现在画布选择器中，移除截图中的Mock Image数据。
2. 用户补充没有配置模型时直接显示“请前往设置页面配置模型”，不能为满足最少一个选项而注入Mock或占位模型。
3. 存量Mock节点与任务已有结果和引用，移除选择入口不能扩大为删除、改写或自动重生成存量数据。

## 决策

设置中的完整内置目录继续用于新增配置；画布选择器只展示至少一个供应商有非空Key的真实模型。符合条件的模型保留已知渠道分组及配置状态，Model Link优先；选择未配置渠道仍会阻止生成。清除最后一个供应商Key后，该模型立即从画布选择器移除。

无当前类型可用模型时，选择器直接显示用户指定文案“请前往设置页面配置模型”，禁用空选择器，不打开空菜单，不回填占位模型。新节点的modelId / params保持null；有配置时默认选择已配置渠道，优先Model Link。不自动替换已有节点的模型或切换已接受任务渠道。

不向画布注入任何Mock后备项；Mock Image不再显示或作为旧节点选中标签。真实视频尚未提供内置目录时也显示无配置提示。Mock共享定义、任务识别和Host适配器仅为历史读取 / 恢复与既有协议回归保留；不删除已有图、边、模型UUID、任务、媒体或预览结果。旧Mock节点重新生成前由用户选择已配置真实模型。画布只调用真实generate / tts-generate，已接受历史任务仍由原Runtime快照恢复。

该决策替代[ADR-0025](0025-generation-groups-and-local-mock.md)与[ADR-0037](0037-fixed-provider-image-models.md)中当前UI的Mock选择 / 全目录展示部分；历史身份、结果分组、目录与尺寸规则保持。HTTP目录DTO、任务契约及数据库DDL不变。

## 备选方案

| 方案 | 评估 |
| --- | --- |
| 展示全部未配置模型并逐个提示未配置 | 不符合用户要求，不采用 |
| 无配置时默认注入至少一个Mock | 违背明确空态要求，不采用 |
| 移除Mock时删除历史节点 / 素材 | 破坏已保存数据与引用，不采用 |
| 配置决定可见性，空态直接提示，历史身份只读保留 | 满足选择体验与数据兼容，采用 |

## 后果

正面：画布候选反映实际配置，未配置模型与Mock不会误导用户；无配置提示明确，存量数据保持。

负面：用户需先配置模型才能生成；真实视频逐个接入前没有视频生成候选。旧Mock节点须手动选择真实模型，不自动改写历史。

## 可逆性与重审条件

新增真实视频目录或供应商时通过原配置流程开放，不引入Mock占位。恢复旧界面按包保留规则执行；不得为恢复候选而改写原任务身份或清空数据。
