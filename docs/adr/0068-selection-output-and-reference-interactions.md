# ADR-0068：临时分组选区输出与引用连线操作

状态：已采纳

文档类型：解释；负责人：项目维护者 / 开发执行者；最近核对：2026-10-30。
记录日期：2026-10-30。节点几何、端点、引用校验、删除或快捷键变化时复核。

## 背景与驱动因素

1. 用户要求框选多个节点后提供统一输出端点和仅含下载的顶部操作栏；允许从端点拖到节点主体，批量跳过类型 / 数量不符的引用。点击连线后用Delete删除引用，提示词使用对应@标签时须确认；底栏提供按操作系统显示的现有快捷键说明。
2. 原画布合同只包含真实节点与assetId固定引用。分组选区不应成为存储节点，也不能让批量操作绕过既有模型、结果身份、重复与循环校验。

## 决策

[SelectionNode](../../src/client/SelectionNode.tsx)作为React Flow临时投影：两个以上真实节点选中、框选已结束且工作区可交互时，按节点当前展示尺寸计算透明虚线框。0.2.80修正主体外边界：顶部外扩52px包含名称、改名输入与TTS标记，左侧40px包含输入端点，右侧52px使24px批量输出与最右节点输出至少留12px间隔，底部12px。右侧原生source Handle承接拖线、坐标与自动平移。该节点不可选择、拖动、删除或键盘聚焦，不进入getGraph、计数、GraphMutation或数据库；小地图不绘制该框，适应画布使用真实节点。原生分组拖动层保留，仅隐藏重复边框；框选命中仍按真实主体判断。

顶部使用NodeToolbar，锚定临时选框本身并向上间隔12px，只有下载按钮，不新增整理、删除等按钮。[selectionDownloads](../../src/client/selectionOutputs.ts)按当前可见媒体去重下载：资源原文件、普通生成主图；展开的单批次 / 历史组包含已显示结果，未完成项无文件；无可用媒体时禁用。使用现有media附件URL逐文件下载，不整段读取视频到内存，不新增ZIP依赖。多文件实际下载行为由浏览器验收。

[selectionOutputs](../../src/client/selectionOutputs.ts)按图节点顺序收集当前有效输出，在拖线开始冻结sourceId、assetId、handleId。普通节点 / 单批次只使用原生主图端点；多次历史收起时没有可连接输出，展开后按每个显式result:assetId端点收集并去重。拖线中改变主图不会替换已经选定的素材。每个引用在逐步累积的最新候选图上执行原connectReference校验；失效素材、类型 / 格式不符、数量满、重复、自连或循环均跳过，后续项继续。一次edit返回全部有效边，走原模式归一和同次保存，不自动提交生成。

[useCanvasConnections](../../src/client/useCanvasConnections.ts)组合原生onConnectStart / onConnect / onConnectEnd。连接输入端点时只提交一次；结束时没有原生有效端点，且最终elementFromPoint命中当前可见画布内的真实节点主体，则接入同一连接校验。按钮、播放器控件、端点、编辑器、菜单、底栏、遮挡与画布外均不作为主体。普通输出拖到空白继续走[ADR-0066](0066-shared-node-creation-entrances.md)快捷创建，分组拖到空白不创建。Escape、取消、失焦、隐藏、弹窗、切换或卸载清除待连接引用。

原生从输入端反向拉到输出端的连接保持，最终source / target仍按输出到输入归一，经过同一校验；反向从空白释放不创建。视频模式专项的几何适配器须触发完整onConnectStart后再onConnect，以覆盖冻结引用的真实生命周期，不能只调用结束回调。

[删除确认](../../src/client/useNodeDeleteConfirmation.tsx)继续复用Harness Modal / Button和React Flow Delete / Backspace。点击边将焦点交给画布并取消节点选择，删除只移除关系。仅边删除且目标prompt没有对应assetId的真实{{asset:…}}标签时立即删除；有标签时显示“删除连线”二次确认。确认解除选中边，提示词 / 标签文字保留并由原编辑器显示失效，媒体 / 任务不删除。普通@文本或其他asset标签不误触发。节点删除沿用任务保护与原确认；异步确认前后检查工作区、可见性、候选节点与边的source / target / assetId，迟到或身份变更不删。取消 / Escape / 隐藏 / 卸载返回false。此规则补充[ADR-0062](0062-harness-node-delete-confirmation.md)的仅边无需确认条件。

0.2.80点击连线时，[RelationshipEdge](../../src/client/RelationshipEdge.tsx)复用单节点选择的source→target流光，仅投影选中边的flowing标记，不保存。无节点选择且工作区 / 页面可见、框选未进行时播放；单节点仍展示直接关联边，多节点或框选自动带出的边不播放。切换选择、删除或清空停止旧边；隐藏暂停，恢复与取消框选后恢复原选择。沿用原减少动态效果规则与点击热区、标签、箭头。

[KeyboardGuide](../../src/client/KeyboardGuide.tsx)位于现有底栏右侧。用键盘图标打开四栏说明，macOS与Windows分别直接读取用户提供的Command / Ctrl SVG路径，跟主题文字色，Ctrl裁去导出留白，全部修饰键组合复用；只列现有选择 / 平移 / 缩放 / 删除 / 方向键移动和提示词撤销 / 重做 / @候选操作，没有新增全局快捷键。提示词操作与焦点条件明确标注。非模态面板限制在当前画布可见范围，窄窗口两栏、必要时内部滚动；公共文字禁选 / 主题作用域覆盖portal。Escape与关闭返回入口焦点，外部点击、隐藏、失焦、卸载清理；面板内按键不删除画布。

## 备选方案

| 方案 | 评估 |
| --- | --- |
| 保存分组节点及合并引用边 | 改变图合同和旧数据含义，拒绝 |
| 自制指针拖线与自动平移 | 重复原生手势和坐标维护，拒绝 |
| 临时原生节点端点 + 逐引用纯图校验 | 保持图结构和既有手势，采用 |
| 删除边同时移除prompt标签 | 用户只要求删除引用关系，会改写文本，拒绝 |

## 后果

正面：复用原生Handle满足分组与主体连接；无Host、Worker、DDL、依赖或新生成调用。

负面：临时框多一个可见投影，批量校验逐次验证图，大选择场景增加计算但仅连接提交时执行，关闭时无背景任务。

| 不变量 / 风险 | 门槛与证据 | 失败动作 |
| --- | --- | --- |
| 分组选框不持久化 | 真实React Flow专项保存只含真实边，不新增节点 | 阻止安装 |
| 类型 / 数量 / 循环 / 结果身份 | 纯图专项验证继续跳过、逐步上限、主图冻结与历史显式端点 | 修复后全量核对 |
| 原生事件仅提交一次 | 实际鼠标端点 / 主体 / 分组、取消与菜单回归 | 保持旧包 |
| 删除范围与焦点 | 真实点击边 / Delete / Backspace、@确认取消、身份变化和无节点 / 媒体修改 | 阻止交付 |
| 操作栏范围 | 多选只含下载；框选过程中不显示；平台图标 / portal / 焦点专项 | 修复并人工验收 |

## 可逆性与重审条件

可回退上一已核验0.2.77包，仅失去本轮操作；现有真实节点 / 边和已创建引用继续有效，不回写数据库备份。新增持久分组、嵌套节点、输出选择语义、批量性能或原生端点协议变化时重审。
