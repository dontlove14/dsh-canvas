# ADR-0012：保留媒体历史与最新可用批次展示

状态：已采纳（补录）

文档类型：解释；负责人：项目维护者；最近核对：2026-10-26。
补录日期：2026-10-26；原决策日期未单独留档。复核规则见[ADR 索引](index.md)。

## 背景与驱动因素

1. 下游连线可能引用上游旧结果，重生成和删除节点不能直接删除历史媒体。
2. 新生成失败应尽量保留可用结果；多图保存可能只完成部分，需要真实表示已有文件。
3. 当前交互提供批次内预览和逐节点生成，没有定义完整历史浏览器、级联删除或媒体 GC。

## 决策

保留任务和素材记录 / 文件。删除节点需确认，移除节点和相关连线，保留下游节点、旧结果和媒体；tracked 任务节点 / 模型拒绝删除。没有工作区删除联动清理或自动 GC。

节点预览按任务列表倒序选择第一批包含已保存 resultIds 的任务；批次内 selectedResultId 选择预览，不改变边。新批次无已存结果时回显旧批次；新批次部分保存失败时展示新批次的部分结果。最新任务状态独立显示；当前没有全历史批次切换器。规则维护在[业务参考](../business.md)。

## 备选方案

| 方案 | 未选择的原因 |
| --- | --- |
| 重生成覆盖旧文件 / 级联删除媒体 | 破坏已有下游引用和历史快照 |
| 只展示整体 completed 的批次 | 隐藏已本地保存的部分结果，不符合现有 nodeResults 语义 |
| 首版加入完整历史与引用计数 GC | 增加 UI / 回收规则，未有明确产品范围 |

## 后果

正面：旧引用文件仍可用；失败不清空所有结果；部分成功能够访问；删除不会破坏下游已完成结果。

负面：磁盘与元数据持续增长；部分新批次会替代旧批次预览；旧结果保留但没有统一历史选择入口；看不到的素材不等于可安全删除。

## 可逆性与重审条件

未来可增加历史浏览或显式回收，必须计算当前图、所有任务快照和结果对素材的引用，并定义保留 / 恢复规则。长期空间增长或用户需要批次切换时重审，不按“当前节点未显示”自动删除。
