# ADR-0099：Agent 空间按动作设置播放倍速

文档类型：架构决策记录；负责人：项目维护者 / 开发执行者；最近核对：2026-11-11。

状态：已采纳
记录日期：2026-11-11。
替代范围：[ADR-0098](0098-agent-space-motion-and-preparation.md)的全局固定 1.8 倍要求；其动作、交接、准备与身份规范继续有效。

## 背景与驱动因素

用户在 78 条动作整合后要求不再统一倍速：角色待机使用 1.0 倍，行走和其他动作先保留 1.8 倍，之前偏快的两条行走先改为 1.6 倍比较效果。原片检查中的两条为 V07 视觉资产右向行走、R07 审查右向行走。

随后用户将主 Agent 招呼（M08）单独调整为 1.2 倍；下表为当前试看配置。

1. 待机、招呼与两条偏快步态需要分别校准，统一倍速影响自然程度。
2. 视频倍速、角色位移和接触时间必须一致，不能改视频后仍按旧速度滑行。

## 决策

| 动作 | 倍速 |
| --- | --- |
| 所有角色的 `idle` 自然待机，包括无任务、排队、已回传后的待机 | 1.0 |
| M08 主 Agent `greet` 招呼，包括主级接续后的待用户认可 | 1.2 |
| V07 视觉资产 `walk-right`、R07 审查 `walk-right` 步态核心 | 1.6 |
| 其余行走、工作、失败、递交、接收与转身 | 1.8 |

以素材清单的 `playbackPolicy` 为当前配置来源。例外按派生动作 code 匹配；同源 `V07-LR` / `V07-RL`、`R07-LR` / `R07-RL` 转身保持 1.8 倍，不能因来自同一原片而继承 1.6 倍。

办公室和逐动作检查使用同一配置，恢复默认参数保持该策略。页面显示当前倍速供用户比较，无需重生成、裁切或重新编码视频，也不改变素材 / 任务身份。历史原片验收记录中的旧倍速说明保留为历史证据，不能覆盖当前策略。

情景内部保留统一逻辑时钟，按各动作倍速换算到视频源时间。慢步态的移动时长按同样比例增加，覆盖前往、返程与取消后返回，避免视频被减速但人物位置仍按旧速度移动。递交接触时刻和单次转身结束点由动作源时间换算；手位坐标仍使用原片时间。

逐动作检查时轴、时长和 ±1 帧操作保留原片时间，播放推进使用所选动作倍速。暂停、后台、收起、准备屏障、卡帧恢复及实例复用继续遵循 ADR-0098。

## 备选方案

| 方案 | 判断 |
| --- | --- |
| 统一 1.8 倍 | 不符合用户对待机 / 招呼 / 步态的校准 |
| 仅设置视频倍速 | 与同步时钟和移动速度冲突 |
| 重新编码 | 重复素材、改变身份，不采用 |
| 运行时按动作换算 | 采用，视频与位移同步 |

## 后果

正面：保留原素材身份，动作速度可独立校准，步态和位移一致。

负面：每种动作需按源时间换算；当前试看倍速仍需用户确认，不能以逻辑检查代替观感。

## 验证与证据

独立 Demo 和[清单](../../src/client/assets/agent_team/motions/manifest.json)共享配置；0.2.135候选通过[运行时倍速](../../src/shared/agentSpace.ts)与[回归检查](../../tests/agentSpaceState.test.ts)接入，安装 / 重启遵循 ADR-0100 的用户指令。Demo 自动检查按动作倍速、原片时轴、实例复用、慢步态移动、42 种专业交接组合与取消返回；用户手动比较待机自然程度及两条右步态的节奏。

## 可逆性与重审条件

运行时配置可直接调整，不重编码、不改变素材 / 任务身份。

用户继续调整某条动作、要求单独控制转身或改动行走移动节奏时更新该策略。1.6 倍是当前试看值，不代表最终美术验收。
