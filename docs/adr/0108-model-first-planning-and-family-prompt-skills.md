# ADR-0108：先选模型的创作规划与模型族提示词方法

文档类型：架构决策记录；负责人：项目维护者 / 开发执行者；最近核对：2026-11-13。

状态：已采纳
记录日期：2026-11-13。
补充[ADR-0079](0079-configured-generation-model-user-selection.md)、[ADR-0104](0104-agent-skills-and-host-authority.md)及[ADR-0105](0105-reviewed-creative-skills-and-scoped-workbooks.md)。

## 背景与驱动因素

1. 用户发现先写分镜、后选视频模型，容易将原本能一次生成的连续内容拆成多个任务，增加片段差异；型号的合法时长和多模态参考容量各异。
2. 用户要求从ClawHub核验提示词方法，使图片和视频规格采用所选模型的写法；未来新型号不应再维护一份Markdown能力数值表。

## 决策

0.2.153保留8角色和现有工具权限。新增7份模型族Skill及7份按需工作表，合计36份方法、32份工作表：GPT Image、Banana、Seedream、Seedance、MiniMax、Wan、Kling。每份提供输入、实际操作方法、交付、检查、阻塞、模板和正反例。提示词方法按已集成protocol映射，能力仍来自当前已配置、可用且用户确认的真实型号/供应商。新增同族型号继承方法；新适配族无映射时明确无专属方法，用通用方法且不猜能力。

`canvas_specialist`新增可选`modelKinds: ('image'|'video')[]`，最多两项，仍是严格对象。宿主不依赖模型自行填对：所有shots任务必需video，assets生成规格/提示词方法必需image；其他模型相关委派用modelKinds声明。未有有效用户选择时409 `AGENT_MODEL_SELECTION_REQUIRED`，不启动子级或创建运行记录；独立story和assets外观概念不需要先选模型。有效选择复用，用户更换沿原生选择卡片。

宿主创建只在真实批次存活的`planningModels`，包含所选模型/供应商、当前capabilities、参考类型/数量/单份与同类时长/组合约束、型号身份fingerprint和用户选择approvalId。专业上下文和只读inspect均可取得；不含密钥或api_key_mask。将方法补入本批skillNames，在真实子级启动/请求/步骤/工具前按原SkillRegistry来源、版本与哈希校验加载；主级下一步自动加载当前所选模型方法。只有main/review可用七族，assets仅图片族，shots仅视频族；story/audio/voice/executor不增加模型方法或工具权限。主动加载或委派不匹配方法409 `AGENT_MODEL_SKILL_MISMATCH`。

模型能力由现有`PublicModel.capabilities`与连接/输入校验的同源定义生成，数值不写在Skill里。新增`videoReferenceDurations`供规划与校验使用，保留现有输入行为。只有已配置可用项进入目录，供应商身份独立，不自动回退。当前未知参考时长必须待核，不能以零估算。尺寸与模式组合仍由共享视频校验及实际节点提交校验负责。

绑定在注册、Skill状态、保存文件admission和最终成果交接时复核。型号、供应商、能力或用户选择变化，409 `AGENT_MODEL_PLAN_STALE`；旧批次不得继续保存或把迟到结果标完成。重新确认同一型号也产生新approvalId，旧任务不自动复活。只让主级复核受影响范围并开新批次，已保存成果及认可保留。绑定仅宿主瞬态数据，不改CanvasGraph、DDL、任务/素材ID或历史成果记录结构。

序列方法区分“叙事镜头”与“一次生成片段”：一个片段可承载多个镜头。优先把同场连续动作、预算和必要参考并集都合法的镜头合并，保留内部切镜；例如当前能力支持12秒时4秒加8秒可作为一个12秒片段。跳时/换场、动作超载或必要参考并集超限须具体说明拆分原因，不为用满上限增加无用内容，不为合并删除必要引用。输出另给片段表，主级按片段准备视频节点。

## 来源与边界

ClawHub源正文、配套文档、版本、SHA-256、页面与正文许可差异及采用/拒绝范围记录在[来源身份](../agent-skill-content-sources.json)和[NOTICE](../../NOTICE.md)。GPT Image与Banana再对照OpenAI/Google公开提示指南。内容独立改写为本项目中文方法；不移植第三方API、文件目录、英文/JSON强制、旧型号固定数值、自动生成或付费重试。Banana候选未声明许可且存在禁止文字等错误，只记录评估，正文依据官方指导独立编写。

MiniMax分节是单一prompt内组织方法，不新增API字段；身份/表演/声音分开，不承诺蒙版、原波形或逐帧口型锁定。Kling按当前Omni角色，不捏造外部elements、voice_ids或音频转视频绕行。参考统一真实`{{asset:UUID}}`和同次边，不凭编号猜素材。

默认中文与原生视频有声保持；图片/视频仍由用户检查并点击生成，TTS仍需原精确授权；无新增观看、试听、剪辑、混音或生成工具。

## 备选方案

| 方案 | 判断 |
| --- | --- |
| 分镜完成后再选择并修订型号 | 容易形成过度拆段和不合法参考，改为正式任务前确认 |
| Markdown维护每个型号上限 | 双重事实源易遗漏，采用实时配置和同源输入校验 |
| 外部Skill整体安装并开放其工具 | 接口、权限与存量身份不符，仅采用经核验独立改写方法 |
| 按protocol匹配方法并绑定当前模型 | 采用；新族显式维护，未知方法与能力不猜测 |

## 后果

正面：模型在创作前确定，分镜和提示词可按真实容量规划；同场连续内容减少不必要独立生成，新增同族型号无需维护第二份数值表。

负面：模型切换要求受影响专业任务重新核对；同族方法仍需要随协议和实测反馈维护，自动化验证不能保证真实表演、文字或声音质量。

## 可逆性与重审条件

0.2.153安装核验成功前保留0.2.152包，失败恢复原插件/profile，不清数据、不改已存成果或重提生成。若新增适配族、观看/试听/剪辑工具或改变用户生成流程，按0104重新评估角色/Skill/权限与反例。仅回退代码不撤销用户在新版本保存的合法内容。

## 验证与证据

[专项测试](../../tests/agent.test.ts)覆盖七族自动注入、必要选型不被空参数绕过、原角色读写边界、工作表身份、匹配/未知族、能力变化/重新选择后的保存和迟到交接、原批次重复回执。[包核验](../../scripts/verify-artifact.mjs)从编译模块读取36份正文和32份资源，离开源码可运行。沿完整check、双构建、同包核验、web3080安装重启与HTTP实际preload；浏览器交互和真实生成质量由用户手验482–487。

维护新型号只更新正常接入和能力定义；新族额外登记方法路由、角色白名单、正文/资源清单、来源、匹配与反例测试。Skill不扩权；所有写入仍受根身份、精确commands、CAS/epoch与幂等限制。
