# ADR-0098：Agent 空间动作语义与提前准备

文档类型：架构决策记录；负责人：项目维护者 / 开发执行者；最近核对：2026-11-11。

状态：已采纳
倍速部分由[ADR-0099](0099-agent-space-per-action-playback-rates.md)替代；以下全局 1.8 倍要求保留为原决策，当前执行待机 1.0 倍、主级招呼 1.2 倍、两条右步态 1.6 倍、其余 1.8 倍。
整轮回复完成后的新卡片默认展示由[ADR-0100](0100-agent-space-upper-left-card-and-working-podiums.md)替代为自动缩小、主级正面待机；0.2.135候选已接入卡片，待用户明确安装 / 重启，旧招呼素材及独立 Demo 情景保留。
记录日期：2026-11-11。
实施范围：独立动画 Demo 的动态状态、近距交接、固定倍速、启动准备与返回朝向。补充[ADR-0093](0093-agent-space-name-and-integration-boundaries.md)，替代其独立验证中“专业角色原地跨工位传递”的临时方案；不替换已安装插件界面或只读契约。

## 背景与驱动因素

用户验收指出：静态闲置欠自然；专业角色都朝左、资料跨工位飞行无法表达真实交接；并行播放时才加载视频导致等待；失败和待认可缺少对应动作；要求全局固定 1.8 倍，主级返回恢复最初右向站姿。用户明确补充素材统一一批制作，继续“画布 Agent 准备 / 用户生成 / 本地助手后处理”的三方流程。

1. 动作需要直接表达闲置、工作、失败与近距交接，不能依赖文字或远距纸张动画。
2. 多角色同步需要提前准备完整视频和首帧，并保持真实素材身份和既有生成任务。

## 决策

### 动作对应实际状态

| 状态 | 必须使用的表现 |
| --- | --- |
| 闲置、无任务、已回传后的常态、排队等待 | 自然呼吸 / 眨眼 / 小幅随动的待机视频循环；主级右向、专业角色左向 |
| 工作 | 该角色工作循环；不能用工作动作代替闲置 |
| 失败与失败后等待重试 | 紧张表情及肩膀 / 手部动作循环；不能仅置灰 / 改文案代替 |
| 主级接续后待用户认可 | 面向用户友好招呼循环；实际完成、主级接续、用户认可仍是独立状态 |
| 主级返回起点 | 恢复最初右向待机，不能遗留左向返回姿态 |

静态 PNG 只用于初次准备、媒体失败、显式静态展示或减少动态。缺失动作明确标为待补，不能用 CSS 伸缩 / 摇晃、镜像或停在无关视频中段假装已完成。独立 Demo 时间线结束后，允许待机继续循环；用户暂停、隐藏、收起和减少动态优先暂停。

### 专业角色近距面对面交接

传出者到接收者工位左侧的交接点，面向右；接收者保持左向并抬手接收。资料在实际手位接触窗口改变归属，不沿跨工位抛物线飞行。完成交接后接收者工作，传出者以真实步态返回原工位，恢复左向待机。

需要传出角色的左 / 右步态、左转右 / 右转左、向右递交，以及接收者已有向左接收。转身与步态分段，角色所有端点保持身份和脚底一致；不把静态人物平移当行走。转身、递交原片缺失时不开放对应情景。主级与专业交接同样限制为近距，不以远距纸张动画掩盖角色位置错误。

后处理清单需记录实际转身片段、步态循环区间、手位采样和递交 / 接收接触时刻。视频不能含另一个角色或烘焙办公室；资料内容及身份仍由宿主真实回执决定，视频仅表达动作。

### 全局固定 1.8 倍与提前准备

1. 动作视频、行走位置、阶段和资料接触窗口共用固定 1.8 倍时间基准。无临时倍速选择器，恢复默认参数不能变回 1 倍；不修改原文件时长或素材身份。
2. 进入 Agent 空间即按完整已验收清单提前读取压缩视频、准备所需播放实例及可显示首帧；并行任务开始前全部参与角色准备完成。`preload="auto"`、已获取 URL、metadata 或请求已发出均不等于就绪。
3. 独立 `file://` Demo 以首帧可解码及从零到结尾连续缓冲为就绪条件；准备分有限并发，失败明确列出并支持用户重试，准备期间不推进情景时钟。
4. 动作切换复用已准备实例，不再设置同一 source 或调用 load。插件接入应按文件 hash / 版本共享已读压缩资源，避免多角色、检查区重复下载；首帧准备和播放解码队列均有并发及资源预算。
5. 预加载不能宣称浏览器永远不会回收解码器；发生卡帧 / 实例失效时保持当前姿态并恢复，不能让角色一部分先开始、另一部分等待加载。隐藏 / 关闭暂停播放；退出空间释放不再引用的资源，重连观察不触发执行。

此处准备提示属于独立 Demo。插件正式 Loading 继续遵循 ADR-0046 / ADR-0061 / ADR-0094，不因该文字提示重新选用插件 Loading。

### 素材补充与归属

一次统一准备 38 条原片：8 待机、8 失败、1 主级招呼、14 专业步态、7 专业转右递交。右步态 / 右递交含真实双向转身，后处理切出转向片段，不额外增加转身生成节点。完整可复制要求见[给画布 Agent 的指令](../../发给画布Agent-动作补充与面对面交接.md)。

所有插件复用 WebM、PNG、场景和清单统一放 `src/client/assets/agent_team/motions`。各派生动作保留原始 sourceAssetId / sourceTaskId / hash 和裁切区间；派生本地文件不冒充新的 Canvas 成果身份。按实际参考预算连接 v3 与方向图，不镜像补右向、不丢必要参考、不重提原任务。

## 备选方案

| 方案 | 判断 |
| --- | --- |
| 静态闲置、远距飞纸、按需加载 | 无法满足用户验收，停用 |
| 为每种角色组合生成双人片 | 组合膨胀，角色和办公室难统一 |
| 单角色动作与统一近距交接 | 采用，需真实转身 / 手位及提前准备 |

## 后果

正面：单角色素材可复用，保持任务和原片身份，动作能够表达实际协作。

负面：新增启动读取与资源预算，交接依赖原片切分和精确手位；插件只在有公开真实链路时展示对应交接。

## 验证与证据

原轮修改独立 Demo、动作素材和规范，38 条已留用原片拆为 52 条透明动作，保留此前 26 条，共 78 条；包括 8 待机、8 失败、1 招呼、14 专业步态、14 双向转身及 7 右向递交。Demo 专业角色组合与完整团队流程已开放。后续插件接入和安装边界以 ADR-0100 为准。

本地证据：[动作身份清单](../../src/client/assets/agent_team/motions/manifest.json)、[插件资源准备](../../src/client/agentSpaceResources.ts)、[同步动作实现](../../src/client/agentSpaceState.ts)。独立 Demo 情景是视觉验证，不是实际任务状态。

候选来源以[本轮原片身份记录](../../Agent%20空间-38条补充素材检查/素材身份与检查记录.json)为准：M07 / V07 / R04 / R07 使用重抽候选 2，M08 使用候选 1。用户本阶段接受主级招呼的短时尾尖小截断、审查右行走的轻微尾尖截断，以及视觉资产右行走偏快；这些限制随派生清单保留，不声称后处理恢复了原片之外的细节。编剧右递交只使用完整伸手核心，转身来自同角色右步态原片。

每个右步态原片分别输出步态循环与两个真实单次转向，共享该原片的固定尺寸与脚底锚点。专业递交与原有交回 / 接收按实际帧采样手位，延迟较早伸手者的手势起点，使接触时刻对齐；站位按双方手位计算，资料标记跟随手心改变归属。手位属于 Demo 可校准表现参数，不是任务或成果归属证据。取消时，正在转身者先完成剩余转向，离开工位者真实走回并恢复左向。

自动验证固定倍速、准备屏障、实例复用、返回朝向、暂停、静态备用、42 种专业交接组合、取消返回与手位接触。用户在 Chrome 验收并行启动、循环边缘、近距手心交接、失败紧张表现和招呼。自动检查与透明帧抽查不能替代人工视觉。

## 可逆性与重审条件

原片与派生身份保持，运行时动作替换可逆；不涉及 CanvasGraph / DDL。插件候选未安装前保留原已安装包。

需要角色组合从接收者右侧交接、坐姿工位、移动摄像机或真实写入交互时，另行扩展动作 / 权限契约。此规范保持 ADR-0093 的 root / child / task / artifact 身份与只读边界。
