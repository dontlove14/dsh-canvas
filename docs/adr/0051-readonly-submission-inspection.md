# ADR-0051：展开历史只读查看，收起恢复最后提交

状态：已采纳

文档类型：解释；负责人：项目维护者 / 开发执行者；最近核对：2026-10-28。
记录日期：2026-10-28。任务快照、历史编辑或引用恢复规则变化时复核。

## 背景与驱动因素

1. 用户要求展开图片 / 视频 / TTS提交历史后，点击任意素材，在其下方看到对应任务的提示词、模型和参数，只允许查看。
2. 修改并提交前必须收起，编辑最后一次提交的输入，不能把刚查看的旧任务当成新草稿。

## 决策

- 多次提交展开后按任务身份和可选素材ID选择记录，使用既有GET taskDetail读取持久快照；校验任务、节点、画布和媒体类型。切换、隐藏、收起或卸载时取消读取并丢弃迟到响应；按画布 / 实际任务ID缓存已验证快照，不随进度轮询重读。
- 独立GenerationSnapshotEditor只接收快照和显示数据，没有修改、上传、生成或任务操作回调。文字可复制，模型与所有已保存参数为静态值；参考素材按快照UUID和原顺序显示。模型被移除 / 未配置时仍可查看历史，不使用当前节点或连线填补记录。
- 只读面板锚定被点击素材的行 / 列位置，随平移和缩放更新，不按视口边界避让；固定栏层级保持。
- 收起时关闭面板，用户重新点击收起的堆叠后恢复按提交顺序最新任务的prompt / modelId / params；一次恢复后保留用户后续编辑，不因点击 / 轮询重置。首次点击已收起历史也初始化最后提交；查看旧任务不能改写草稿。
- 新任务尚未接受或快照读取失败时不开放编辑 / 生成，不回退到旧任务或当前草稿。明确归属错误按失败处理；重新展开 / 收起可重试。
- 提示词快照保存的是实际提交文本，可能已将UUID引用转换为编号。恢复编辑时只将可识别编号按快照原UUID还原，不改写当前边；丢失引用继续由既有校验拦截，不能自动连到新结果。
- 单次提交批量展开仍隐藏编辑器，保持设主图规则；[ADR-0050](0050-submission-history-and-expanded-result-ports.md)的多次提交展开隐藏编辑器条款由本决策替代，其余堆叠 / 独立端点 / 任务规则保持。
- 不增加接口、数据库列或图字段，不改任务快照 / 媒体 / 凭据，不重新提交已有任务。当前schema 3及DDL保持。

## 备选方案

| 方案 | 评估 |
| --- | --- |
| 直接显示节点当前输入 | 与旧结果不对应，不采用 |
| 共用可编辑组件并隐藏生成按钮 | 仍可能保留写入路径，不采用 |
| 查看旧任务后直接继续编辑 | 违反必须收起且使用最后提交的要求，不采用 |
| 独立只读组件，收起恢复最新快照 | 保持历史准确和提交入口，采用 |

## 后果

正面：各素材可查看准确输入，查看不修改草稿、不产生新任务；收起后有明确的新任务编辑入口，不改变位置、标题、主图字段或引用边。

负面：查看历史需要一次认证GET，错误时不能展示伪造的兜底输入。旧快照没有提交前的原始草稿，不能承诺恢复原始空白 / 标签写法。缓存为当前画布会话内存，不持久化。

## 可逆性与重审条件

回退旧包即可恢复旧展示；不覆盖业务目录或删除新接受任务。若需要从旧任务复制参数生成，应另行设计明确入口并重审，当前没有此功能。
