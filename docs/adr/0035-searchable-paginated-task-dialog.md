# ADR-0035：任务目录分页查询与可返回详情

状态：已采纳

文档类型：解释；负责人：项目维护者；最近核对：2026-10-27。
记录日期：2026-10-27。查询范围、分页契约或时间精度变化时重审。

## 背景与驱动因素

1. 用户要求顶部“任务”弹窗以目录表格和分页展示，查询区支持任务ID、文件夹 / 画布名、类型和时间联合查询。
2. 旧列表仅当前画布，游标加载更多不能跳页，也没有目录上下文；详情展开混在列表中。
3. 不能修改已存储画布格式或SQLite结构；现有SDK没有日期范围和分页组件，需复用公共Button / Input / Select / Modal并封装通用控件。

## 决策

新增只读 `GET /api/canvas/v2/task-search`，保留原tasks游标、task详情与任务操作接口。查询当前owner的未删除画布任务：任务ID完整UUID精确匹配；文件夹 / 画布名称trim / NFC后字面包含（转义SQL LIKE的百分号、下划线和反斜线）；类型image / video / tts / import；提交时间created_at按毫秒包含端点。各条件AND联合，允许单侧时间。参数化SQL、严格参数校验、拒绝重复 / 未知 / 非法参数和反向时间范围。查询不加载整张图，不返回prompt、快照、私有URL或凭据。

文件夹与画布展示当前名称，未归档显示“未归档”；生成节点名称使用任务提交时的title快照。导入显示其资源节点名称。类型从现有kind和提交快照派生，TTS以fish-tts协议识别；目录状态映射为公开TaskStatus。不新增表 / 索引 / 列，不重写旧节点或任务。

页码从1开始，pageSize为10 / 20 / 50 / 100，默认20；按queue_seq降序。首查返回当前owner活动画布任务最大序号upperBound，后续翻页 / 改条数沿用上限，排除其后新提交任务；查询 / 重置重新取上限。一次SQLite Worker消息内返回上限、总数和页数据；页码超范围钳制到最后页。上限不是持久快照：任务状态、目录名称和软删除仍以当次查询为准。无自动轮询；用户点击查询获取新列表。

表格仅八列：任务ID、文件夹名称、画布名称、生成节点名称、状态、更新时间、提交时间、查看详情。查询 / 重置显式提交，不按输入逐键查询。请求取消与卸载标记抑制过期回包；加载 / 失败 / 空结果不显示旧行。详情替换同一弹窗内容，按该行canvasId读取；返回保留查询草稿、已应用条件、页码和每页条数，并恢复详情按钮焦点。现有未知任务 / 保存失败操作保留在详情里。

`UiDateTimeRangePicker`为受控通用组件：双月日历、年月切换、日期和时刻输入、键盘日期移动、清空 / 确定、单侧条件。浏览器本地时区解释输入；默认开始00:00:00 / 结束23:59:59，结束时间含最后一秒999ms。草稿只在确定时提交，非法日期 / 非法本地时间 / 反向范围不提交。弹层位于所在Modal / dialog内，避开滚动裁切并保留宿主焦点边界，Escape只关闭选择器。窄屏双月纵向排列。

`UiPagination`为受控通用组件：总数、每页条数、上一页 / 下一页、紧凑页码 / 省略号、跳转输入。跳转Enter或失焦提交，超出范围钳制；修改条数回第一页。表格内部滚动，固定表头和操作列；宿主浅 / 深主题继承，不添加原型未要求的状态标签页、导出或额外筛选。

0.2.26根据真实宿主截图修正尺寸：共享UiInput的原生内层使用border-box，宽度100%包含自身padding / border，防止越出外层并挤掉间距；不引用SDK哈希类名。搜索区固定任务ID 240px、文件夹 / 画布220px、类型144px、时间范围420px，窄窗口换行、单控件最多占满可用宽度。表格列基准依次180 / 180 / 180 / 200 / 110 / 175 / 175 / 100px，总最小宽1300px，窄窗口内部横向滚动，名称超出省略并可悬停查看全名。任务ID只显示前16位和省略号，左侧按钮复制完整ID；成功反馈、失败不宣称成功。剪贴板接口不可用或拒绝时尝试所在Modal内的选择复制并恢复焦点。分页条数108px、页按钮32px、跳转框56px，控件不收缩、容器允许换行；原查询和跳页行为不变。

## 备选方案

| 方案 | 评估 |
| --- | --- |
| 前端下载所有图 / 任务后筛选分页 | 多余数据与内存，详情泄漏到目录请求，不采用 |
| 修改旧tasks接口并增加数据列 | 容易破坏调用方 / 存量，不采用 |
| 新只读查询接口、派生DTO、通用控件 | 可联合搜索和跳页，保持旧接口与数据，采用 |

## 后果

正面：目录清晰，支持跨画布联合查询和稳定翻页；详情不占列表行，返回上下文保持；日期 / 分页可复用。

负面：模糊匹配和总数需读取匹配范围，未宣称大规模任务的性能实测；分页上限不能冻结名称、状态或删除，用户需查询刷新。双月日历的真实宿主视觉 / 焦点验收仍由用户执行。

## 可逆性与重审条件

删除新增路由和控件，恢复旧列表即可回退，无数据迁移。任务量使查询阻塞、要求历史目录快照 / 自动刷新 / 含已删除画布、SDK新增公开日期控件时重审。分页上限是只读查询参数，不进入已存储图。
