# ADR-0064：五路上传与共用有界胶囊通知

状态：已采纳

文档类型：解释；负责人：项目维护者 / 开发执行者；最近核对：2026-10-30。
记录日期：2026-10-29。并发、展示上限、通知时限、依赖或动效变化时复核。

## 背景与驱动因素

1. 用户确认断点续传可用，要求胶囊更圆润、去掉静态边框，并保留轻悬浮效果。
2. 大批文件不能无限延长胶囊条；用户指定最多五枚，剩余用「+N」表示，同时最多五路并发上传。
3. 用户指定首次从上方弹入，后续从右向左叠入，完成后自动消失并向左补位；边缘直接使用libraries.dev/beam并适配Harness主题。
4. 保持原UUID、Blob缓存、分块恢复、图DTO及两库结构，不通过动画驱动或重启上传。

## 决策

部分替代[ADR-0063](0063-resumable-uploads-and-progress-capsules.md)的四路并发、无限胶囊与旧尺寸条款；其余恢复协议保持。

[共享常量](../../src/shared/uploads.ts)指定UPLOAD_CONCURRENCY=5，浏览器共享管理器最多占用五个完整上传流程的槽。更多文件缓存后排队，成功或终态失败都会释放槽并唤醒下一项；网络 / 登录等待仍保留原槽和身份。这是单个CanvasApi共享管理器的上限，不增加Host到OSS的后台导入并发，也不声称跨浏览器 / 标签页全局限流。

[UploadCapsules](../../src/client/UploadCapsules.tsx)仅投影当前画布最早五项未完成活动，其余总数显示「+N」；100项为五枚与「+95」。完成即移除，下一项进入可见范围。不为不可见文件创建Beam、圆环或动画。计数不删除或合并真实任务。

胶囊88×34px、18px圆角、圆环20px，相邻重叠52px、完整露出36px左侧。移除静态border，使用轻阴影；数字为独立小标签。实际边缘直接使用既有border-beam@1.4.1的sm / colorful，duration=3.6、strength=.9、glowSize=.65，固定彩色配色并保留旋转。胶囊各自隔离绘制层，右侧胶囊覆盖前项时不被前项流光穿透。公开css参数仅调强度、显现与暂停，不重写依赖的边缘几何或keyframes。通过既有NodeLoadingContext传入Harness明确主题；浅色 / 深色是表面和强度适配，不代表流光必须灰度，不改节点Loading选型。

0.2.66按用户截图纠正0.2.65的不可见效果：旧mono令依赖层透明度再乘.5，关闭inner并将bloom再乘.12，浅色最终bloom仅约0.0062。恢复彩色和内侧 / 外侧光晕；深色stroke / inner / bloom倍率为1.2 / .6 / .6，浅色为3.2 / .65 / .85，保留窄柔光。边缘显现交给胶囊自身入场淡入，设依赖opacity为1，避免额外600ms淡入让短上传看不到Beam；旋转和遮罩仍直接使用依赖。视效是否达到用户参考图由人工核对，组件挂载和依赖哈希不能视作视觉通过。

首次出现采用300ms的上方18px / 轻缩放 / 淡入；已有胶囊时新项采用240ms的右侧44px叠入。完成直接移除，其余按旧 / 新实际位置差，以transform平滑补位。连续完成时先读取旧动画的当前位移，再取消旧动画测量新目标，避免跳回旧位置。只在可见身份或数字位数改变时测量最多六项，百分比与「+N」同位数更新不重复入场、不测量媒体。

减少动态效果、工作区隐藏与页面不可见时停止布局动效和Beam旋转，保留可读进度；卸载和全部完成时取消动画并释放引用。支持不足时静态胶囊仍显示正确数量和进度。动画不影响上传队列、原画布交互或文字禁选作用域。

### 0.2.77：画布消息复用胶囊

用户指定画布顶部错误提示也使用上传胶囊，并要求定时消失、多个消息叠放和消失后补齐。[CapsuleStack](../../src/client/CapsuleStack.tsx)统一真实Beam与有界布局动效；上传尺寸、圆环、五路并发和恢复身份保持。[NotificationCapsules](../../src/client/NotificationCapsules.tsx)显示带错误图标、正文与单项关闭按钮的34px文字胶囊，最多五枚与「+N」，文字项相邻重叠12px，悬停 / 聚焦提升层级，长文省略并保留完整title。顶部公共容器将消息与上传分为两行，避免同时出现时互相覆盖，空白区域不截获画布操作。

消息按独立UUID追加；当前可见 / 排队中的相同正文去重，防止周期查询失败挤满通知。每项进入可见范围后才开始完整5秒倒计时，新消息不重置前项；关闭只移除对应项，剩余自动补位。悬停、键盘聚焦、页面或工作区隐藏分别暂停，恢复后仅继续剩余时间；减少动态效果只停止动画，不暂停通知时限。可见子项卸载时取消定时器，共用布局卸载时取消动画，不为排队项创建Beam或计时器。

仅替换useCanvas.report对应的短时顶部提示；保存冲突的持久处理栏、节点失败状态和表单内校验继续保留，消息消失不改变任务 / 草稿状态，不重提请求。消息仅属于当前工作区页面，重新载入成功按原行为清空，无新增持久化或接口。

## 备选方案

| 方案 | 评估 |
| --- | --- |
| 每项都渲染、靠横向滚动缩短 | 百项仍有百个动效，不能满足用户展示上限 |
| 只有一枚汇总进度 | 不能保留五项独立圆环和进度 |
| 排队项只存内存 | 刷新会丢失原文件，违背续传约束 |
| 新增动画库 / 自绘Beam | 已有依赖和原生动画接口足够，无需扩大依赖与维护范围 |
| 完成动画保留额外第六枚 | 可能突破可见上限，完成直接移除后补位 |

## 后果

正面：展示长度和Beam数量有界，五路并发与追加保持，完成补位清楚，主题沿用宿主，恢复及两库身份不变。

负面：重叠项主要露出圆环，最后一项完整显示百分比，悬停可读对应文件 / 进度；真实动画观感仍需用户验收。增加一条浏览器到Host传输槽，仍有原缓存与暂存空间成本；不会把Host到OSS改为五路保存。

## 可逆性与重审条件

仅Client调度上限、投影、动效和共享常量，无DDL、接口或原会话变更。0.2.64仍理解相同缓存和Host journal，可回退显示 / 并发行为；不得覆盖新用户数据或清空缓存。跨标签页全局并发、最大文件数量、浏览器动画 / 存储策略或Beam版本改变时重审。

## 验证与证据

[浏览器队列专项](../../tests/uploadRecoveryClient.test.ts)以真实IndexedDB API缓存100个文件，固定种子`0x6500cafe`逐项乱序完成，检查活动传输峰值恰为五、槽不泄漏、每项独立原UUID和最终清缓存；另检查终态失败释放槽。[胶囊专项](../../tests/uploadCapsules.test.tsx)保留真实Beam，检查百项只有五环 / 五Beam、计数与补入、上方 / 右侧进入、进度不重播、连续完成的当前位移、实际彩色渐变及非零光晕倍率、主题 / 暂停 / 卸载；jsdom只替换布局数值与原生animate接口，不声称实际像素或帧率通过。[工作区回归](../../tests/canvasPerformance.test.tsx)继续验证追加入口与媒体内容稳定。五路实现见0.2.65 manifest，边缘显现修正的全量、双构建、同包安装 / 实际preload及两库身份见0.2.66 manifest；人工267–271。

[通知专项](../../tests/notificationCapsules.test.tsx)覆盖追加独立时限、百项五Beam与可见后计时、单项关闭 / 补位、悬停与聚焦独立暂停、隐藏 / 减少动态效果区分、主题 / 卸载、真实useCanvas多错误去重与重新载入；工作区专项核对离线与冲突两条提示同时出现，自动消失后冲突处理栏仍保留。0.2.77检查及同包身份见manifest，真实外观与补位由用户298–300验收。
