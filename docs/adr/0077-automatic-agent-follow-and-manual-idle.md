# ADR-0077：Agent 自动跟随、人工操作空闲恢复与背景水印

文档类型：解释；负责人：项目维护者 / 开发执行者；最近核对：2026-11-02。

状态：已采纳
记录日期：2026-11-02

## 背景与驱动因素

1. 用户要求每次发送消息恢复跟随，开始操作画布自动切到人工视角，超过10秒未操作后恢复跟随；当前回复完成后回人工视角。
2. 原顶部跟随 / 恢复按钮使状态切换依赖手动点击，暂停后的视角容易遗留；跟随与人工浏览缺少背景区别。
3. 连续拖动、长按与滚动不能按第一次操作倒计时中途抢回视角。聊天发送、回复结束和媒体任务完成是不同事件，不能靠节点生成状态推断回复结束。

补充 [ADR-0075](0075-agent-node-highlight-and-centered-viewport.md)，替代 [ADR-0072](0072-agent-presentation-navigation-and-readonly-inspection.md) 的顶部按钮与永久浏览暂停策略。原显式写权委托 / 接管仍按0071；视角暂停允许检视、播放、复制和滚动，不自动取消运行中的Agent。

## 决策

插件根 observer 通过明确声明的 `sessions` 服务借用当前右侧会话的既有 `binding().session`，订阅公开 `getSnapshot/subscribe`。对新增 `pendingSubmissions.requestId` 识别每次发送，包括运行中的 queue / steer；首次快照和重连基线不重放已有提交。匹配原意图的 session / canvas / epoch 才呈现，原生 running 为回复状态真源，晚到的Host运行意图不能覆盖已经结束的原生回复。

97起过滤无关文字流快照：只有会话身份、提交数组、running、removed、openState或promptError变化才通知跟随并触发同步，避免逐字更新重启居中或刷新整张图。

每次新提交解除当前视角暂停，回到最新操作；意图尚未到达时保留同会话的恢复请求。原生尚未进入running的提交短暂等待，发送错误立即结束等待，未进入running最多15秒回人工视角，避免放弃提交留下水印。回复完成、意图清空、epoch更换、会话切换、重连与卸载清理旧倒计时和手势持有状态。无运行回复和有效意图时不自动跟随。

画布和其React所属portal的真实pointer / wheel / keyboard / input / click触发人工视角。指针与按键持有期间不启动恢复计时，窗口外松开 / 取消也能释放；最后一次活动或最后松开后超过10000ms恢复最新意图。拖动和重复输入只重置单一计时器，不逐事件通知React。程序调用setViewport、媒体自动播放和普通鼠标悬停不作为用户操作。隐藏释放手势，卸载清理监听器，人工离开目标窗口继续遵从原导航保护。

删除顶部“跟随 Agent / 恢复跟随”按钮。跟随且可见时显示灰色背景与重复斜向“Agent 操作中”水印；背景使用Harness当前文字色8%与原背景混合，水印使用文字色9%透明度，自动适配浅色 / 深色 / 系统主题。SVG位于React Flow背景和节点之间，无指针事件、不接受焦点、对读屏隐藏，不遮挡媒体或控制。人工视角与回复结束恢复原背景。原Border beam在人工浏览期间仍标出真实运行目标，回复完成清除。

计时与视角模式仅在客户端；不新增Host接口、图字段、数据库迁移、任务或依赖，不移动节点坐标。

## 备选方案

| 方案 | 取舍 |
| --- | --- |
| 保留按钮与永久暂停 | 需要额外操作，不满足自动切换要求；不采用 |
| 监听聊天DOM、包装prompt或从媒体任务推断回复完成 | 耦合私有实现或错误状态轴；不采用 |
| 公开会话快照与真实手势驱动临时跟随 | 已采用；需要绑定与计时清理，原图和写权保持 |

## 后果

正面：发送和操作自动切换，长拖动不被抢视角，回复结束不残留水印；新消息只恢复最新操作，原布局和媒体任务身份保持。

负面：短暂消息受理等待和浏览器计时调度存在延迟；真实灰度、水印与手势仍须用户浏览器验收。原生会话API改变时需调整适配。

## 可逆性与重审条件

回退上一可用95包无需迁移，原生会话、图和两库格式保持。若公开快照的提交身份 / running语义变化、用户需要不同空闲时长或自动写权接管，重审此决策；不把视角切换扩展成取消Agent或重新提交任务。
