# ADR-0066：统一节点创建入口与拉线快捷创建

状态：已采纳

文档类型：解释；负责人：项目维护者 / 开发执行者；最近核对：2026-10-29。
记录日期：2026-10-29。新增节点类型、端点规则、菜单组件或画布手势变化时复核。

## 背景与驱动因素

1. 用户需要从已有素材的输出端点拉线到空白处，选择类型后一次完成新建与引用；空白处右键也需要快速创建。
2. 独立维护底部添加栏、右键和拉线菜单容易漏入口或产生不同默认参数，未来新增类型必须同时覆盖三个入口。
3. 既有画布、媒体与任务身份必须兼容；连接表示引用，不自动提交生成任务。历史堆叠需要引用实际拉出的结果，不能改成最新主图。

## 决策

以[CREATABLE_NODES与创建工厂](../../src/client/nodeCreation.ts)统一底部添加栏、空白右键与输出拉线菜单。当前为图片生成、视频生成、语音生成；导入资源继续走上传。新增可创建节点类型时必须维护此注册表、图合同 / 默认参数、图与模型输入校验、节点渲染 / 编辑、图标和对应测试，逐一核对三个入口；禁止另写类型数组或只增加底部入口。资源节点等特殊类型若另设创建条件，须明确注册和说明排除原因。

[useNodeCreationMenu](../../src/client/useNodeCreationMenu.ts)只使用React Flow公开onConnectStart / onConnectEnd / onPaneContextMenu。右键静止点击打开菜单，保留右键拖动平移；不是全局contextmenu监听。空白落点须在当前可见画布矩形与窗口内，并由elementFromPoint确认顶层命中；有命中API却返回空值时不回退，只有API缺失才用事件目标。节点、边、编辑器、控件、底栏、独立弹窗与画布外不打开。

0.2.78由[ADR-0068](0068-selection-output-and-reference-interactions.md)连接适配器组合这两个原生端点回调：普通输出释放到节点主体也可接入同一校验；分组选区输出批量连接，只生成真实边且拖到空白不创建。普通输出到空白的菜单与三个创建入口继续按本决策维护。

屏幕坐标通过screenToFlowPosition转换后冻结，选项点击的菜单坐标不影响节点位置。底部入口继续在视口中部创建。新节点默认值、名称和模型由同一工厂决定；无引用按既有模型顺序选择，带引用选择首个兼容的完整配置模型。没有配置时图片引用仍可连接空模型的图片 / 视频节点，视频 / 音频需要相应模型；TTS无输入端，不允许从素材拉线创建TTS。

按0.2.72用户修正，拉线菜单只展示能连接当前素材的类型，不兼容类型直接隐藏；没有兼容项时不打开空菜单或保留临时线。底部添加与空白右键仍展示完整注册表。菜单打开后配置 / 素材变化也重算可选项，没有兼容项即关闭，提交前仍执行最新图校验。

拉线起点冻结sourceId、实际assetId和handleId。单批次使用当时主图，多次历史要求展开且显式result:assetId端点；打开菜单后换主图不替换冻结素材。创建前用useCanvas.getGraph读取最新图，并重查素材归属、任务结果、历史展开状态、模型能力、引用数量、重复引用和循环。直接连接与快捷创建共用connectReference，不把生成时才要求完成的提示词 / 音频补图条件提前套到连接。

新节点与引用边在一次edit updater中返回，再走既有Seedance模式归一与同次GraphMutation保存；失败不返回候选图、不留孤立节点、不提交生成。选中新增节点并清除旧连线选择。菜单期间显示非交互临时曲线，不写入图；重复选取先消耗菜单引用，只能创建一次。

菜单复用Harness公开Menu、坐标锚定、portal、自动聚焦和键盘行为，独立开发采用语义菜单兼容。新增portal通过公共画布文字作用域默认禁选。菜单测量后限制到画布可见范围与窗口，窄区域允许滚动。Escape、外部点击、新操作、平移 / 缩放、页面 / 侧栏隐藏、弹窗、源节点删除、工作区变化或卸载清除菜单和临时线；取消 / 选择回到画布焦点，外部点击保留该操作的原焦点行为。

React portal的合成pointer事件仍沿React祖先经过画布捕获监听。画布必须识别本菜单的实际目标，在菜单内部按下时跳过关闭与框选处理，使完整pointerdown / pointerup / click次序到达选项；仅click()不能验证该路径。菜单外的新操作继续关闭，不改宿主Menu或全局事件。

## 备选方案

| 方案 | 评估 |
| --- | --- |
| 保持仅底栏创建 | 无法满足两种快捷操作 |
| 三处分别写类型列表和默认参数 | 易遗漏扩展、参数和校验漂移，拒绝 |
| 先新建，再异步连线 | 失败可能留下节点，且保存中间状态，拒绝 |
| 共用注册 / 工厂、同步返回节点与边 | 维护点一致，保存原子，采用 |

## 后果

正面：三个入口一致；引用结果 / 位置固定；失败没有部分图；不改Host、两库DDL、媒体、模型、凭据或任务协议。

负面：与React Flow公开端点 / 右键平移事件次序相关；菜单适配器增加少量坐标与焦点维护。菜单测量只在打开期间执行，不增后台轮询，真实主题和手势仍需用户验收。

| 风险 | 可能性 / 影响 | 缓解与证据 |
| --- | --- | --- |
| 连到错误历史结果或删除后的来源 | 中 / 高 | 冻结实际asset并提交前校验最新图与结果身份 |
| 失败留节点 / 重复点击创建 | 中 / 中 | 一次纯图转换，消费菜单引用后同步edit |
| 右键平移误弹或弹窗穿透 | 中 / 中 | 原生平移结束契约与最终顶层命中，原生事件专项 |

## 可逆性与重审条件

可回退0.2.70，保留所有已创建节点、引用与用户数据，仅失去两个快捷入口；不回写旧数据备份。由本地执行者负责安装与恢复。新增类型无法表达默认创建、端点含义或公开Menu / React Flow手势契约变化时重审，不引入分布式服务或新的存储责任。

## 验证与证据

[图与模型专项](../../tests/nodeCreation.test.ts)及[真实React Flow工作区专项](../../tests/nodeCreationMenu.test.tsx)核对注册、默认值、位置、实际原生右键 / 拉线、节点与边同次保存、重复 / 取消 / 隐藏与源删除、键盘及顶层命中。0.2.72增加无兼容项不打开和完整pointer / mouse次序；修正前原生点击两个用例复现不创建，隔离portal捕获后复测。Harness loader用公开契约替身，不能证明浏览器布局与主题通过。双构建、同包安装、实际preload与两库身份以0.2.72 manifest最终记录为准；用户人工280–286。
