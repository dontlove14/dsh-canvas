# ADR-0036：单选节点的上下游连线流光

状态：已采纳

文档类型：解释；负责人：项目维护者；最近核对：2026-10-27。
记录日期：2026-10-27。选择规则、连线渲染或动画生命周期变化时复核。

## 背景与驱动因素

1. 用户要求点击节点后，用参考图中的蓝色动态亮段快速识别其上游输入和下游输出，流动必须遵循输出端到输入端。
2. 现有Bezier曲线与具体素材绑定需要保留；画布有全页和常驻侧栏两处入口，动画不能写入存量图或在隐藏侧栏持续工作。

## 决策

单选有效节点时，仅该节点直接相连的入边和出边显示流光。入边从上游输出流向当前输入，出边从当前输出流向下游输入；方向由source / target端点确定，与左右位置无关。不递归点亮整条链，不表示任务正在执行或自动触发生成。

新增Client自定义边，使用公开getBezierPath与BaseEdge保留几何、素材标签、标记、点击热区和原有选择 / 删除行为。灰色底线之上叠三层蓝色SVG短段，pathLength归一化，CSS负向dashoffset驱动source到target的移动；不使用SVG模糊滤镜、逐边路径测量或逐帧React状态。

0.2.29修正用户反馈的亮段静止：原终点为无单位数字的calc，数学结果是number而非CSS length。改为明确px长度的固定关键帧，尾迹0→-33.333333px，亮芯-1.6→-34.933333px；两层均线性移动一个dash周期，保留亮芯相位与循环连续性。长度单位是SVG用户坐标，不是逐帧测量或改动路径。

基础边投影与焦点投影分离，仅克隆直接相关边并附加浏览器data.flowing；无焦点复用基础数组，不相关边对象保持引用。该字段不进入CanvasGraph、自动保存、API或数据库。单选切换即更新，空白取消、多选、框选期间、侧栏inactive和页面隐藏时移除流光。一个Workspace只有一个页面可见性监听，卸载移除。系统减少动态效果时改为静态蓝色连线。

选择连线的主题色仅作用于BaseEdge主路径，避免覆盖流光颜色或把透明点击热区绘制出来。全页与右侧侧栏共用同一CanvasWorkspace实现。

## 备选方案

| 方案 | 评估 |
| --- | --- |
| React Flow默认animated虚线 | 虚线整体移动，与参考图的灰底蓝色亮段不符 |
| 每条边逐帧更新React / SVG模糊滤镜 | 增加渲染与滤镜成本，未采用 |
| 原Bezier底线加归一化CSS流光 | 方向明确，保留交互，可按选择 / 显示状态移除，采用 |

## 后果

正面：输入和输出来源直观可见，旧图无需迁移；隐藏入口不保留动画，普通连线操作与素材身份保持。

负面：SVG动画仍有绘制成本，长短边采用相同归一化周期，屏幕上的像素速度不同；浏览器视觉与高密度帧时间仍需人工验收。

## 可逆性与重审条件

仅Client视图改变，可恢复默认Bezier边而不改数据。需要多选流光、递归链路、真实执行态或测得高密度性能退化时重审；不能把该效果作为任务状态依据。
