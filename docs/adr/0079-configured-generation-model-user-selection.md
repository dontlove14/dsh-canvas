# ADR-0079：已配置的生成模型与供应商由用户选择

文档类型：解释；负责人：项目维护者 / 开发执行者；最近核对：2026-11-02。

状态：已采纳
记录日期：2026-11-02

## 背景与驱动因素

1. Agent读取完整内置模型目录，可能自行挑选未配置的组合，再让用户配置；与实际可用供应商不一致。
2. 用户要求图片、视频模型由自己决定。说明模型、认可创作方案或通用生成授权，不能替代模型与供应商的明确选择。
3. 提示词约束不足以防止工具跳过询问；同时必须保留原付费任务幂等、人工接管撤权和存量图结构。

补充[ADR-0071](0071-shared-canvas-agent-preset-and-control.md)的媒体生成工具规则；对话LLM的原生模型选择器及FishTTS独立配置保持。

## 决策

Host单一目录只提供当前已配置的内置模型 / 供应商组合：有API Key、要求EP时有EP、支持的内置身份、可配置且有已知供应商。未配置占位、旧自定义身份、Mock及已禁用渠道不作为候选；输出不携带密钥掩码。inspect和动态上下文使用同一目录。

仅主Agent获得`canvas_select_model`。原生UserQuestions单题单选列出该类型全部可用组合，不允许Agent传入或缩小候选；即使只有一个也询问。答案必须是唯一有效选项、没有额外自定义意见。只有该类型零候选时才返回需要配置。用户文字指定模型时，卡片仍核对实际供应商组合，避免猜渠道。图片和视频分别确认。

确认由真实主Agent实例的临时Registry保存，不写图、两库或Ledger格式。有效选择可在当前项目复用，change=true清除旧确认并重新询问。配置失效或EP变化、接管、Agent卸载、切项目或对话模型路线变化使确认失效；取消、过期控制和交错问题的晚到答案不能复活确认。问题等待不占用提交队列，继续使用真实agent / signal / callId。

创建有模型的节点、修改模型和新生成提交都核对具体modelId及类型，并在图 / 任务提交前再次检查。规划节点可暂不绑定模型。新生成必须确认已有人工节点的模型；提示词或名称编辑可保留已有参数。Agent工具的可选字段移除持久Schema的默认值，避免省略参数覆盖模型默认值、部分更新清空modelId或prompt；切模型未给参数时按共享模型默认参数初始化。

已完成工具回执优先重放；已接受任务但工具回执中断时按同一requestId / requestHash查回原taskId，不以新确认阻止查询，不调用生成服务或重提原任务。

## 备选方案

| 方案 | 取舍 |
| --- | --- |
| 仅要求Agent生成前说明模型 | 无法约束供应商和执行工具，拒绝 |
| 完整内置目录加配置状态 | Agent仍可推荐未配置组合，拒绝 |
| 临时用户选择Registry与执行校验 | 采用；无需存量迁移，能拒绝绕过询问和晚到确认 |
| 持久写入用户默认模型或画布确认字段 | 超出本轮范围且可能跨项目误用，拒绝 |

## 后果

正面：当前供应商与模型一致；用户控制模型决定，执行工具可阻断自主改选；旧媒体、任务与数据库保持。

负面：首次选择需要一次原生问答，接管或失效后需要再次确认；配置完整只代表可提交，不证明账户余额、供应商网络或生成质量可用。

## 可逆性与重审条件

Registry只存在内存，可卸载，无数据回滚。若以后需保存个人默认选择，须由用户明确授权并另行设计作用域、过期及迁移；SDK问答或目录契约变化需复核原生身份和选择专项。
