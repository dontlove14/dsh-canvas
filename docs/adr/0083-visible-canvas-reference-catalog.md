# ADR-0083：按实际编辑画布排序的分级引用目录

文档类型：解释；负责人：项目维护者 / 开发执行者；最近核对：2026-11-03。

状态：已采纳
工作区文件候选部分由[ADR-0084](0084-canvas-only-hash-references.md)替代；0.2.111起#仅画布，目录排序 / 跨画布原素材规则保持。
记录日期：2026-11-03
实施版本：0.2.110；部分替代[ADR-0076](0076-native-hash-canvas-and-workspace-references.md)的当前画布来源、单画布候选及切画布拒绝规则。

## 背景与驱动因素

1. Agent 最后控制的画布与用户实际打开的编辑器可能不同。原菜单只列控制记录中的画布，用户关闭它并手动打开其他画布后，候选仍停在旧项目。
2. 用户要求所有分类和画布均可选：当前编辑的分类 / 画布优先，无编辑器时最近编辑的优先，仅第一分类展开，其他分类点击后逐级选择。

## 决策

1. 客户端从现有 CanvasApp 的可见 seat 读取当前编辑画布，同会话可见窗口优先，其次为可见主画布入口。打开项目列表明确为无画布，不回落到旧 Agent 控制记录。视图订阅独立于呈现意图和文字流，随打开、返回、隐藏、卸载更新；加载就绪和无关流事件不触发引用刷新。
2. 候选 GET 增加可选 `browse` JSON，不修改 version1 引用或图 / 数据库 Schema。`currentCanvasId:null` 表示没有编辑器；旧调用不传时保留绑定画布优先。`folderId`（null 为未分类）选择目录，`browseCanvasId` 选择其中的画布。Host 使用同 owner 未删除目录，当前画布优先，其余按已有 `canvases.updated_at` 降序，分类按其最优先画布排序；时间相同用稳定 ID 排序，空文件夹保留。
3. 初始菜单先展示第一分类 / 画布及其媒体、同分类其他画布，再展示其余分类目录。点击其他分类显示该分类的画布，继续点击显示媒体；原生面包屑支持返回。目录 ID 只在源持有的 opaque value 和请求参数中传递，草稿使用可读路径，路径保留字符做全角显示映射，实际归属不按名称推断。工作区文件仍保持原 RPC 路径，进入画布目录不请求文件 RPC。
4. 所有分类 / 画布元数据完整返回，沿现有 catalog 的单机目录规模约定，不截断目录。只读取当前展开画布的 graph / assets；媒体关键词在该画布过滤，最多200项并返回 `mediaTruncated`，输入关键词缩小范围。根关键词可匹配分类 / 画布名以及第一画布媒体；不为跨画布资源全文搜索加载所有图。
5. 当前编辑器变化时冻结旧原生控制器以清空候选并取消请求，再重检同一真实草稿；不能用 dismiss 把原 `#` 标成被忽略。源再次核对视图身份和取消信号，晚到候选与旧选取不插入。已选引用允许在编辑器变化后按原素材身份发送。
6. 序列化与读取媒体按 ref.canvasId / nodeId / assetId 在同 owner 目录验证，允许跨画布引用，不隐式委托或改变当前控制权。只读解析不受写锁阻挡；实际工具仍核验根身份、用户已提交项、当前受控画布权限及取消。图片由共用真实字节附件通道读取原画布，读取前后复核原引用和权限，不触发导航、居中或呈现意图。视频 / 音频仅返回原元数据。文件安全、子级禁止读取、跨会话拒绝和人工接管规则保持0076。

## 兼容、错误与重试

| 表面 | 分类 | 约束 |
| --- | --- | --- |
| choices 的 browse / folders / expandedCanvasId / currentCanvasId / mediaTruncated | 加法兼容 | 单个客户端与 Host 同包部署；省略 browse 保留旧偏好；media / cwd 保持 |
| catalog.updatedAt | 加法兼容 | 来自原字段，不迁移数据库；旧 DTO 可省略，排序按0处理 |
| 跨画布媒体解析 | 条件兼容、纠正行为 | 仍同 owner、同会话与实际节点素材关系；不把切编辑器视为失效 |
| 400 INVALID_REQUEST | 保持 | 无效 / 超长 browse、未知字段、非合法 ID；修正输入 |
| 403 REFERENCE_SESSION / REFERENCE_FORBIDDEN | 保持 | 仅 live 主预设 / 用户已提交；不可通过重试绕过 |
| 409 REFERENCE_STALE | 保持并缩小条件 | 目录删除 / 移出、素材删除、工作区或文件变化；重新选择 |

GET / resolve 均无图、任务或目录写入，可安全重试，无新增幂等 key。owner HTTP 的身份、same-origin credentials、no-store 与原生 signal 全路径保留。没有新增事件、持久状态或用户默认模型；未来继续加可选字段，破坏性变化须另立版本并核验全部调用方。

## 备选方案

| 方案 | 取舍 |
| --- | --- |
| 继续使用 Agent 控制记录 | 无法表达手动切换；不采用 |
| 为菜单同步改控制记录 | 会改变 Agent 写权；不采用 |
| 一次读取所有画布图 | 随目录扩大而变慢；不采用 |
| 可见视图加独立目录元数据 | 控制与浏览分离，仅懒读一个画布；采用 |

## 后果

正面：菜单跟随实际编辑器，全部分类可访问，原素材反馈不跳转或接管；不引入新预览、自动导入或数据库迁移。

负面：输入源持有临时浏览路径，必须验证名称保留字符、面包屑、Esc / IME / 精确草稿范围和卸载；媒体200项与关键词范围是已知边界。

## 可逆性与重审条件

多窗口按同会话可见编辑器优先，新增焦点优先级或跨会话引用时重审。卸载恢复 resolver 并释放视图订阅；回退109保留所有图、媒体、任务、原引用与文件，菜单恢复旧单画布规则。没有新的持久格式，回退无需清空或重提任务。
