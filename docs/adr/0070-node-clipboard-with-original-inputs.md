# ADR-0070：节点剪贴板快照与原上游输入

文档类型：解释；负责人：项目维护者；最近核对：2026-10-30。

状态：已采纳
记录日期：2026-10-30

## 背景与驱动因素

1. 用户确认单节点 / 框选节点支持Command或Ctrl+C/V、节点 / 分组选区右键复制、空白右键粘贴；保留参数和提示词，复制不得触发生成、上传或改动旧节点。
2. 连线绑定具体assetId。生成节点副本是无结果草稿，若把组内来源改为同批副本，会指向没有输出的节点并破坏提示词@、输入顺序和首尾帧角色。
3. 系统剪贴板可被其他程序替换，异步读权限可延迟返回；必须避免旧缓存 / 迟到读取写入已隐藏或另一张画布，且不抢占输入框、只读复制区域的原生文本行为。

## 决策

剪贴板是有类型标记和版本的有界JSON文本，包含来源origin / workspace、操作身份、布局范围、白名单节点输入与所有目标在所选集合内的入边。节点内容在复制时冻结，保留所有参数、提示词与@原始文本；只持有assetId，不携带媒体字节、签名URL、模型配置 / 密钥、任务、结果或渲染状态。仅可粘回同源同画布。

粘贴节点 / 边分配新UUID，名称追加“副本”，保持相对位置。边只替换target，source始终为原上游：框内来源和框外来源相同处理。未复制下游不增加新出边。资源共享assetId；图片 / 视频 / TTS生成节点为新草稿，assetId与selectedResultId为空，任务和历史由新身份自然隔离。

完整候选先检查图引用、素材归属 / 存在性、类型 / MIME、当前模型输入数量与视频模式约束；保存的新节点首尾帧仍引用原assetId。任何所需输入或绑定素材失效均拒绝整批，不降级为部分粘贴。空提示词、未配置模型等草稿状态可复制；原已悬空@保持原文，复制不修复、不新建其来源。通过一次useCanvas.edit写入全部节点 / 边，沿用既有GraphMutation保存管线。已校验的粘贴绕过“原引用为空→新引用”的视频模式推断，避免清掉首尾帧。

快捷键使用原生copy / paste ClipboardEvent读写系统提供的数据，限定可见且可交互画布；原生输入和显式可复制区保留文本行为。菜单复用Harness UiPointMenu及公共portal文本作用域，修饰键复用用户提供SVG；点击复制使用系统writeText / 既有本地选择回退，粘贴每次重新readText，不使用过时内存副本。无法读取时菜单禁用并提示使用快捷键。

复制完成通过独立success通知入口进入共用胶囊，显示主题成功色圆圈勾选并使用status朗读；不能把成功正文包装成Error交给report。真实失败仍使用错误色感叹号和alert，旧未指定类型的通知默认错误。同正文按结果类型分别去重，成功不覆盖画布错误状态，计时 / 补位保持共用。

空白菜单在点击位置落下副本左上角，键盘用最近画布指针，否则按复制范围居中可见画布；同一包在同一位置连续粘贴逐次偏移32画布单位，成功后选中新批次。菜单命令在异步操作前消费；epoch在新操作、Escape、外部点击、隐藏、失焦、换画布、卸载时失效，迟到读取不能写入。右键拖动保持平移。

## 备选方案

| 方案 | 取舍 |
| --- | --- |
| 组内入边连接同批上游副本 | 新生成来源无结果；与用户确认的原上游规则不符，拒绝 |
| 复制时只保存节点，粘贴重新读取原节点 / 参数 | 后续修改会改变粘贴内容，破坏快照，拒绝 |
| 内存剪贴板优先、读权限失败回退旧内容 | 可能粘贴被外部替换的内容，拒绝 |
| 全部原输入快照 + 系统剪贴板 + 整批校验 | 保留具体媒体、参数和@语义，采用 |

## 后果

正面：不新增持久化字段 / 数据迁移 / Host接口，旧节点和任务不变；组内生成副本也能继续复用原素材，批次保存完整。

负面：同画布限制且依赖原来源 / 媒体存在；菜单读权限受浏览器控制。跨画布迁移、外部导入以及复制生成历史不在本轮范围。

## 可逆性与重审条件

Client策略可替换，持久化仍使用原节点 / 连线契约。若将来要求跨画布复制、独立工作流或复制历史，需另行确认素材身份、输入重映射和任务归属；不能默默修改本规则。
