# ADR-0034：对话右侧标签页中的无限画布

状态：已采纳

文档类型：解释；负责人：项目维护者；最近核对：2026-10-27。
记录日期：2026-10-27。Harness右侧标签契约、画布导航或生命周期变化时重审。

## 背景与驱动因素

1. 用户希望在Harness工作区的对话侧边栏打开插件，同时使用对话和画布。
2. 原先只有左侧全页入口；现有响应式规则按浏览器宽度判断，不能适应宽浏览器中的窄侧边栏。
3. SDK支持保留隐藏标签内容，必须区分隐藏和卸载，避免草稿丢失、后台播放、跨面板按键及多余轮询。

## 决策

按安装的SDK `0.2.1-rc.2`公开类型与实现核对，Client声明 `sidebarRightTabs` 注入，包内client依赖增加 `@deepseek-ai/dsh-client-ui-sidebar-right`。通过 `ctx.effect` 持有类型注册的disposer，并通过 `slots.inject` 等待 `sidebar.right.pane.tab` 声明后注册正文。静态类型的id、kind及正文key均为 `dsh-canvas`，提供“开始页 → 无限画布”引导入口。没有资源地址匹配；不替换宿主rightbar、文件、终端或开始页。

正文接收插槽转换后的 `useTabInfo`，以 `tab.visible` 控制活跃状态。设置 `keepMounted: true`，宿主负责标签、会话及停靠生命周期；画布保留当前项目、文件夹和图草稿。隐藏时停止播放、取消正在框选 / 平移、撤销合成提示、关闭弹窗与编辑候选；目录和图状态定时读取暂停，既有650ms自动保存继续。恢复显示后沿用原hook基线和下次轮询，不触发reload；关闭标签或卸载仍按既有flush清理。刷新浏览器或新开标签先进入列表，不增加跨次项目记忆。

左侧全页和右侧正文复用同一CanvasApp、API与模型设置，画布 / 节点 / 媒体 / 任务身份及SQLite结构保持。会话是展示上下文，不自动绑定某张画布；同时编辑同一画布继续使用对象hash和修订冲突保护。按键限定在本画布容器，隐藏标签关闭React Flow全局删除快捷键，避免影响对话或其他面板。

CanvasApp使用命名CSS容器查询适应实际面板宽度：窄侧栏的文件夹换成横向折行、项目卡片保留300px上限、页头紧凑、底部工具栏避让缩放控件；编辑器按ResizeObserver实测宽度布局，隐藏的零尺寸不覆盖有效测量。

## 备选方案

| 方案 | 评估 |
| --- | --- |
| 只保留左侧全页入口 | 实现简单，但不能同时展示对话和画布 |
| iframe或直接修改Harness右侧DOM | 认证、生命周期、布局与升级难以可靠维护，不采用 |
| 公开标签注册并复用现有画布 | 保留宿主行为与数据边界，采用 |

## 后果

正面：对话与画布可并排显示；旧入口和数据继续可用，标签切换不替换草稿；窄布局随实际面板宽度变化。

负面：已访问标签会保留React状态，多个标签增加内存；隐藏时暂停渲染交互与轮询，但不承诺已保留状态零内存。不同入口同时修改同一画布仍可能冲突；RC版SDK升级需重新核对注入与正文契约。

## 可逆性与重审条件

可以移除右侧注册和client依赖恢复旧入口，无数据迁移。SDK不再支持keepMounted / visible、用户要求会话绑定画布、跨次记忆或出现实际多标签内存问题时重审；不以会话切换自动新建画布或重提生成任务。
