# ADR-0042：节点附件自然定位与固定工具栏层级

状态：已采纳

文档类型：解释；负责人：项目维护者 / 开发执行者；最近核对：2026-10-28。
记录日期：2026-10-28。节点附件定位、窗口适配或画布层级变化时复核。

## 背景与驱动因素

1. 用户要求节点上方按钮组与下方编辑卡片保持相对节点的位置，即使窗口展示不下也不能自动上移；无限画布由用户自行平移查看。
2. 原编辑卡片用窗口尺寸与卡片高度夹紧坐标，靠近底边时会移到节点上方；窗口相关max-height也改变卡片显示高度。
3. React Flow节点工具栏会随选中节点自动提高z-index，编辑卡片原层级也高于左下角控件；用户要求节点附件位于底部工具栏与左下角控件之下。

## 决策

下方编辑卡片固定530px屏幕宽度，按节点当前位置与实际尺寸的底部中心锚定。坐标为`left=viewport.x+(node.x+width/2)*zoom-530/2`、`top=viewport.y+(node.y+height)*zoom+18`。保留18px屏幕间距，不用窗口宽高、卡片高度或最小边距夹紧位置，也不根据窗口缩小卡片宽度。

卡片超出左右 / 上下边界时保持自然位置，由原画布边界裁剪；用户平移或缩放查看。去掉编辑卡片的窗口相关max-height与整体滚动限制，内容增长不改变卡片锚点。提示词自身已有高度上限与滚动行为保持。

图片 / 视频资源和音频节点上方按钮组继续使用React Flow NodeToolbar的Top / end / offset42节点锚定，不做边界适配或翻转。传入固定层级样式，覆盖SDK按节点z值计算的工具栏层级，避免选中节点把按钮组抬到固定控件之上。

画布隔离层统一定义`--dc-node-overlay-layer:6`、`--dc-canvas-tools-layer:10`。节点编辑卡片与上方按钮组使用6，底部工具栏和左下角放大 / 缩小 / 定位控件使用10，固定控件保持可见及可点击。节点、画布变换、媒体与边的层级体系保留。

该规则共用于图片 / 视频 / TTS编辑卡片与图片 / 视频 / 音频上方按钮组。模型和参数选择菜单、全局弹窗继续沿用各自定位方式。附件位置 / 层级仅为Client视图，不写入节点、图、任务或数据库。

## 备选方案

| 方案 | 评估 |
| --- | --- |
| 继续把卡片夹紧到窗口可见范围 | 会覆盖节点，违背用户要求，不采用 |
| 把所有节点附件放到最高层 | 遮挡固定工具栏与左下角控件，不采用 |
| 根据卡片高度自动调整画布或节点位置 | 改变用户视口 / 数据，且不符合手动查看理念，不采用 |
| 按节点自然定位，固定控件层级更高 | 位置稳定，用户自行平移查看，采用 |

## 后果

正面：边缘节点附件不再跳位，窗口与内容尺寸不影响锚点，固定操作栏不被节点卡片遮挡。

负面：窗口可能只显示卡片的一部分，窄窗口也不会自动缩小卡片，用户需平移或缩放查看。

## 可逆性与重审条件

用户明确改变无限画布定位规则时重审；不可为展示附件而自动改写节点或视口。回退按已核验包 / profile规则执行，原数据和任务不迁移。
