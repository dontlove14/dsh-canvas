## 构建管线与身份

源码 / package-lock → 锁定依赖 / TypeScript / tests / docs → 清理lib双构建并比对SHA-256 → npm pack → 校验内容 / sha256 → 备份profile / 安装 / 启动与接口检查 → 用户手动视觉验收。

源码目录尚无Git提交，以输入文件hash清单替代commit身份；记录Node / npm版本与lock hash。依赖安装以package-lock为准，构建使用本地依赖、无生成网络图像 / 未声明素材 / Key。构建无缓存，先删除lib；重复构建验证未命中路径，避免旧Worker或声明混入。

单次本地候选按序生成，不并行覆盖包；后续源码变化使旧检查失效，须重新验证。0.2.47使用新包名，安装核验成功后根目录只留最新tgz；历史manifest保留。依赖精确锁定，补丁只加绘图分辨率参数，使用本地锁文件构建，不在页面运行时下载动画代码。构建比较与运行回执使用受限系统临时目录。包名 / 版本 / SHA256与source / lib清单标识同一产物，安装和实际preload核对同一hash；包缺失停止安装，恢复已核验本地产物，不用远端替代。没有托管发布线、镜像 / 自动扩容、长期发布分支或紧急跳过流程。

必需检查失败先修复再生成；人工验收属于运行发布门槛。没有紧急跳过检查流程。
