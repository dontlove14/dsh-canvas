无限画布 · 功能设计提案

明确操作对象，也保留原素材身份

通过 # 引用节点，让 Agent 理解用户在说哪个对象、希望怎样处理，以及它使用了哪些输入、影响哪些下游。图片、视频和音频仍可单独引用到确定的那份结果。

01 / 产品模型

同一套目录，两个明确的引用对象

空节点、资源节点和已经生成过的节点都可以引用。节点引用用于讨论或操作，素材引用用于参考或反馈；用户本轮说的话决定动作和角色。

引用用户表达Agent 获得聊天显示
节点“调整这个节点”“解释它的引用”“帮我准备生成”当前节点配置、准确上游输入、直接下游与输出摘要仅节点名称
素材“参考这张图”“这次视频的动作不对”那一份确定的图片、视频或音频名称、素材类型和结果区分
节点引用随节点当前已保存状态读取；素材引用继续固定原结果。上下游帮助理解本轮需求，默认操作范围仍是用户明确要求的节点。
02 / FR-01 统一候选

点名称引用节点，点当前素材引用结果

推荐方案：分类和画布排序延续当前规则。在画布内部按节点组织，每个节点有一行可选名称；有结果的节点下面直接给出当前素材，右侧箭头查看同批堆叠和历史。

这是产品判断，供评审确认。示意中的节点、素材和关系均为虚构数据，点击只改变这个方案页，不访问插件或模型。

无编辑器时，“资产画布”模拟最近编辑

点 ◇ 行引用节点；点下方素材行引用素材；› 查看节点素材。正式实现复用原生 Enter / Tab 和面包屑。

候选与结果的具体规则

位置 / 状态行为
节点名称行点击或 Enter 插入节点引用，聊天只显示该名称。
当前素材行一步引用画布当前展示的那份素材。生成节点和资源节点都遵守画布已有预览规则。
箭头 / Tab打开节点素材。本次可用批次展开；历史按任务分组，默认收起；可以返回面包屑。
尚无结果 / 生成中 / 失败节点可引用。只有实际已可用的素材才进入素材候选。
图片 / 视频 / 音频资源可引用节点，也可引用其绑定的原素材。
语音生成可引用节点及实际音频结果，保持无输入连线的既有规则。
搜索 / 候选很多匹配当前画布节点名称、素材标签和文件名；历史素材命中直接可选。到候选上限提供继续浏览，不能永久隐藏后续节点。
分类 / 工作区当前画布及分类置顶；无编辑器时最近编辑置顶；其他分类点击进入。工作区文件仍走原生 @。
03 / FR-02 关联上下文

按实际连线理解输入和影响

选择节点后，Agent 可以读取该节点的名称、类型、提示词、参数、当前输出与任务摘要，以及直接上下游。聊天不展开这些内容，保持一个短标签。

例如：“人物设定”现在显示第 2 次生成，但“镜头02”的线仍连接第 1 次结果。Agent 应参考第 1 次结果，不能换成屏幕上最新的一张图。
关联读取规则
上游说明源节点和真正连入的那份素材，包含图片 / 视频 / 音频类型及可用性；有输入用途时沿节点现有配置解释。
下游说明哪些节点使用目标节点哪份结果。修改提示词不代表下游输入或生成结果已同步更新。
更远关系按任务需要继续读取，不默认展开整张图和所有历史。
内容理解需要看图时读取真实图片；视频 / 音频仍依据元数据及用户反馈，不声称已完整观看或聆听。
04 / FR-03 操作意图

引用给出对象，要求给出动作

1 · 定位对象读取引用对应的实际节点和画布。
2 · 理解要求区分目标节点、参考对象及本轮动作。
3 · 核对关联读取准确上游、当前配置与下游影响。
4 · 按授权处理核对控制权与最新保存状态，执行现有能力。
用户表达处理范围
#镜头02，改成 5 秒并保持人物一致镜头02是目标，上游人物素材是参考；核对现有模型和参数能力。
#镜头01，解释它现在用了哪些参考只读关系与实际素材。
参照#人物设定，把#镜头02改得统一人物设定作为参考，镜头02作为编辑目标。
#镜头02，准备生成沿现有模型选择、参考校验和人工生成交接流程，不由引用触发付费生图 / 生视频。
多个引用，只说“改一下”仍有实质歧义时简短澄清目标或动作。

默认仅处理明确要求操作的节点；用户要求联动调整时才扩展到指定上下游。选择或读取引用不会自动获得写权限、接管或跳转画布。真正修改前仍核对目标画布、控制权和保存状态，避免把另一画布的同名节点当成目标。

05 / FR-04 变化与恢复

让引用保持准确，也保留用户的输入

变化结果
改名 / 移动按同一节点身份定位，Agent 获得当前名称；历史聊天标签不改写。
节点配置 / 连线改变读取最新已保存状态；真正写入前再次核对，冲突时重新读取。
尚未保存 / 保存冲突沿已有保存流程完成或处理冲突，保留草稿，避免操作旧版本。
节点 / 画布删除该引用提示重新选择，不能猜同名替代节点，保留已输入文字。
上游原素材不可用明确缺失，不换成最新素材；依赖该输入的操作停止，独立编辑按其条件处理。
切画布菜单跟随当前画布重新排序，已经选中的有效引用仍指向原对象。
旧引用旧图片 / 视频 / 音频及文件引用、原 @ 入口和对话历史保持。
