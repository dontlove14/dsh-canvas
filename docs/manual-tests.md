# 当前版本手动验收

文档类型：操作指南；负责人：项目维护者；最近核对：2026-10-29。复核周期和触发条件见[文档导航](index.md)。

环境：Harness `0.2.1-rc.2` 或本地 `npm run dev`。使用兼容所选协议的真实模型，准备 PNG/JPEG/WebP 图片、可播放的视频和音频。生成测试可能产生模型服务费用。

本表是待执行用例，不是通过记录。执行后按[验证记录](verification.md)填写版本、日期与实际结果；业务预期的权威说明见[业务参考](business.md)。
