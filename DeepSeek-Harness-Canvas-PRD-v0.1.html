01 / PRODUCT CONTRACT

定位与完整流程

面向已在使用 DeepSeek Harness、希望调用自己选择的图片或视频服务进行创作的用户。插件提供画布、模型配置、素材引用与生成任务管理。用户通过画布手动发起生成，V1 的完整流程不依赖 DeepSeek 自动调用工具。

步骤 1配置并保存模型
步骤 2创建节点与输入
步骤 3执行并展示结果
步骤 4本地恢复与复用

启动条件：用户已加载插件，进入画布；首次使用可先创建空节点，再从“配置模型”入口进入设置。未配置可用模型时，生成被阻止，但画布编辑和素材导入仍可用。

完成条件：一次生成的结果已保存到本地并显示在对应节点中；用户能够预览图片或播放视频，将明确的一份结果连接到下游节点，并在重新打开后恢复画布和本地结果。

本地的建议口径：V1 的配置、密钥、画布和媒体文件保存在运行 Harness 的当前电脑，设置保存不依赖云端配置服务。远程 Harness 的部署与“浏览器本地”是否另作支持，见待定事项 D-02。调用外部模型时，提示词、必要参考素材及鉴权请求仍发送到用户配置的 api_base；本地保存不等于本地推理。

03 / PRODUCT MODEL

节点与引用关系

节点类型主要内容可作为下游输入的内容
图片生成节点独立的图片模型选择、提示词、参数、参考图片、最近一次任务与图片结果。已经成功保存的某一张图片。
视频生成节点独立的视频模型选择、提示词、参数、参考素材、最近一次任务与视频结果。已经成功保存的某一个视频；仅当下游模型支持视频输入。
图片资源节点导入文件、缩略图、文件名和图片尺寸。该图片文件。
视频资源节点导入文件、视频播放器、文件名和可读取的时长。该视频文件；仅当下游模型支持。
音频资源节点导入文件、音频播放器、文件名和可读取的时长。该音频文件；仅当下游模型支持。
  • 生成节点与资源节点保持区别。生成结果直接显示在生成节点内，不自动再创建一份资源节点。生成节点保留模型和输入；资源节点不提供模型选择或“生成”操作。
  • 提示词属于节点。V1 在生成节点的编辑面板中输入，不要求再创建文字节点。选择其他节点后，原节点的已编辑内容保留。
  • 连线表达明确的素材引用。连接时选定一份文件或一项生成结果。改变预览中的当前结果、重新生成或移动节点，不静默替换下游已经引用的素材。
  • 多结果展示方案：同一生成节点内展示当前结果及“上一项 / 下一项”和数量；创建连线时引用当前显示的结果。这是为支持参考图中的生成数量而提出的产品建议，待定。
  • 未完成节点不能提供结果。空节点、只有草稿的节点和未保存成功的结果，都不能连接为可用素材；已有成功结果的节点重新生成期间，旧结果仍可被明确选中引用。

04 / FUNCTIONAL REQUIREMENTS

功能要求

FR-01模型设置：本地配置与脱敏回显

在 Harness 设置扩展中提供“生成模型”入口，分别显示“图片模型”和“视频模型”。设置服务于画布生成，不与 Harness 的聊天模型列表混用。

配置字段

字段填写规则保存与回显
模型类型图片 / 视频，必选。新增时指定；已有模型类型不直接转换，以免改变引用节点的含义。保存后按类型进入对应模型列表。
显示名称必填，去除首尾空白后非空。同类型同名时提示调整名称，避免节点菜单混淆。显示在设置列表和节点模型菜单。修改名称不丢失已有引用。
接口协议从首批支持的协议中选择。具体协议与供应商 [TBD]；仅填写地址和密钥不能保证任意接口都可调用。决定可用输入、参数与任务查询能力。属于补齐调用流程的产品建议。
model_id接口要求模型标识时必填，按供应商文档填写；固定模型接口可由协议配置提供。属于调用所需的补充字段。用于发送生成请求；用户可在节点菜单中辅助辨识。
api_base必填，合法 HTTP(S) 基础地址，去除首尾空白。支持 HTTP 的本地服务；拒绝非 HTTP(S) 协议及含用户名、密码的 URL。只保存在本地。保存不会自动发送探测或生成请求。
api_key以密码输入框填写。要求鉴权的协议必填；无鉴权本地协议是否支持，待定。编辑已保存模型时，留空表示保留原密钥。保存后列表显示固定的“••••••••”；编辑时不回填原文，不提供默认展开原文的操作。

首批模型的输入类型、参数选项和默认值需要在接入时明确。V1 节点只展示该模型已支持的能力；不要求用户在设置页手写任意请求 JSON 或参数映射。

动作与反馈

  1. 点击“新增图片模型”或“新增视频模型”，填写字段。保存前检查必填项、地址格式与同类型名称冲突；字段不合法时保留草稿，并在字段附近说明原因。
  2. 保存成功后新增或更新本地记录，密钥输入框清空、列表脱敏。返回画布后，对应类型节点的模型菜单可以使用该记录。保存失败时保留草稿，不显示成功。
  3. 重新打开设置时，地址、名称等可回显，密钥始终以已保存状态展示。更新密钥必须重新输入新值；空白输入不覆盖原密钥。
  4. 修改名称影响菜单显示；修改连接信息只作用于新的任务。已开始任务使用提交时的配置；任务所需旧配置仍仅保留本地，任务结束后不继续作为可选配置。该配置快照规则是恢复异步任务所需的产品建议。
  5. 移除模型前展示模型名称及受影响节点。移除后保留这些节点、输入和已有结果，标注“模型已移除”，要求重新选择后才能生成。存在未结束任务时，不允许直接移除其配置，以免中断查询。

FR-02画布：创建、选中、连接与删除

入口建议：在 Harness 导航中增加“无限画布”，进入插件独立主页面。首次进入显示空画布与“添加节点”入口；有保存内容时直接恢复。V1 按当前工作区关联一个画布是当前建议，尚待确认。

操作规则

  • 添加节点菜单分别列出图片生成、视频生成、图片资源、视频资源、音频资源。资源节点可通过选择本地文件创建；生成节点创建后为空，标题带类型与可辨识名称。
  • 拖动节点改变位置；平移和缩放仅改变视口。节点内的输入框、菜单和播放器操作不触发拖动或画布平移。框选支持多节点；删除操作见共享规则 SR-06。
  • 选中一个生成节点，显示与该节点关联的浮动编辑面板。面板包含参考素材、提示词、模型、参数和生成按钮；图片和视频面板按各自类型展示内容。选中资源节点展示媒体内容，空白处点击收起生成面板。
  • 切换选中节点后，面板载入新节点的草稿。关闭面板不丢失已编辑输入，也不取消正在执行的任务。框选多个节点时不合并提示词或批量发起生成。
  • 连接源节点的输出与生成节点的输入时，校验具体文件、目标模型输入类型、参考素材数量与是否形成循环。不允许连向资源节点、自己、重复素材引用或形成循环。无效连接不创建，说明阻止原因。
  • 未选择模型时，可先添加基础参考图片；模型选择后重新校验。素材不兼容时显示原因并阻止生成，不静默删除素材。删除连线只解除引用，不删除源素材。
  • 连线建立后，素材出现在目标编辑面板的引用区，按加入顺序编号。多图是否可用及数量上限由模型能力决定；参考图中的 @引用素材 文本语法不列为 V1 必选项。

FR-03图片生成节点

节点本体承担结果展示；选中后在其下方或邻近位置出现提示词面板，交互结构参考图 1。面板顶部是素材导入与引用区，中部是提示词，底部是图片模型选择、参数摘要和生成按钮。面板需要始终关联当前节点，不因缩放而遮断必要操作。

模型与输入

  • 模型菜单只列出已保存的图片模型；视频模型不出现。新节点的默认模型为用户主动选择的配置；是否记忆“最近使用模型”见 D-05。在没有明确默认规则前，不静默选择其他模型。
  • 提示词为多行输入，去除首尾空白后不能全部为空。用户可直接导入参考图片，或通过连线引用图片资源 / 已保存的图片生成结果。
  • 无参考图片时按文生图处理；有参考图片时按图生图处理，并显示当前输入方式。若模型不支持图片输入，保留素材和提示词、标明不兼容、阻止提交。
  • 切换图片模型后保留提示词与素材；兼容的参数保留，不兼容的选项要求重新选择。不得静默改变比例、分辨率或数量后立即提交。

图片参数

参数参考图中的候选值V1 规则
分辨率1K / 2K / 4K只显示当前模型支持的选项；若接口按像素尺寸表达，需要在接入时明确映射，不能直接承诺所有模型支持上述档位。
比例自适应、1:1、9:16、16:9、3:4、4:3、3:2、2:3、4:5、5:4、21:9按模型能力提供；自适应仅在模型支持且含义明确时出现。
生成数量1 / 2 / 4 张按接口支持显示。V1 不自动拆成多次付费请求来模拟不支持的批量能力；固定单结果接口只提供 1 张。

执行与结果

用户点击生成前，完成模型、提示词、输入素材和参数校验。通过后创建本次输入快照并展示任务状态。同一节点有未结束任务时不重复提交。状态与恢复统一遵循 SR-02 至 SR-05。

成功保存到本地后，图片显示在节点内，按原比例预览；支持打开大图查看。多张结果采用节点内切换，不覆盖已有下游引用。重新生成时保留旧结果，新结果保存成功后成为当前预览；失败不清空旧结果，错误展示在该节点。

FR-04视频生成节点

视频生成与图片生成使用不同节点和编辑面板。视频面板底部提供视频模型选择、输入方式、视频参数摘要和生成按钮。节点成功后展示具有播放、暂停、进度和音量控制的视频播放器。

模型与输入方式

  • 菜单只显示已保存的视频模型。无模型时提供进入设置的入口，不能用图片模型代替。
  • V1 需要文生视频和图生视频。推荐规则，待定：按参考图片是否存在自动显示“文生视频 / 图生视频”，不另设可能与素材冲突的手动模式选择。首帧、尾帧及复杂多参考模式是否接入，由首批协议确定。
  • 文生视频要求非空提示词；图生视频要求非空提示词和至少一张可用参考图片。具体允许图片数量、图片用途和支持格式由模型能力确定。
  • 导入的视频、音频资源可先在画布预览，但只有模型明确支持这些输入时才能连接到该视频生成节点。存在资源节点不代表所有视频模型都接受这些文件。

视频参数

参数参考图中的候选值V1 规则
比例Auto、16:9、4:3、1:1、3:4、9:16、21:9按当前视频模型支持范围展示；Auto 的行为由该模型定义。
清晰度480P / 720P / 1080P / 4K仅提供可调用的选项；不将图片分辨率字段复用成视频清晰度。
时长秒数，截图当前为 5s范围、步长、离散时长和默认值由模型决定。支持离散值时用选项，支持连续范围时可用滑杆；不承诺统一的最短或最长时长。

异步执行与结果

生成可能是“提交 → 排队 → 生成 → 获取结果”。节点展示实际可获得的状态，供应商不提供进度时显示等待状态，不伪造百分比、预计剩余时间或积分。离开画布、切换节点和收起面板不取消任务。

有任务 ID 时先本地保存，再查询。结果文件保存成功后才能进入“成功”并播放；视频默认不自动播放。重新生成时旧视频仍可播放。多结果在同一节点切换，播放器使用用户当前选择的那个视频。

FR-05图片、视频和音频资源

用户通过“添加资源节点”或生成面板的“上传”选择本地文件。通过画布入口导入时创建对应资源节点；通过生成面板导入时，同时创建资源节点并连接当前节点，避免面板内存在无法追溯的隐藏素材。此统一规则为产品建议，待定。

  • 导入时识别媒体类型并校验是否可读取。图片提供缩略图和大图预览；视频与音频提供基础播放控制。仅显示能够读取到的尺寸、时长等元数据，不伪造缺失信息。
  • 导入后将文件保留在插件管理的本地内容中，后续不依赖原文件仍在原路径。导入失败不创建可用节点或连线；原文件不被修改或删除。
  • 不支持的类型、损坏文件或超过模型能力的素材，给出具体原因。文件类型、大小和数量上限在首批协议接入时确定，见 D-04；素材能够本地播放不等于能够传入模型。
  • 资源播放互不触发生成。切换节点后保留资源节点，删除连线不移除文件。音频资源不提供文生音频功能。
  • 源媒体文件丢失时显示“本地文件不可用”，已有节点与引用保留为缺失状态。用户重新选择文件后，更新对应资源并重新校验引用；不自动上传或下载替代素材。

本模块的本地媒体选择与预览演示包含在 FR-02 的示例内。

FR-06本地保存、恢复和结果复用

保存范围包括模型配置、画布节点与位置、连线及明确引用的素材、视口、节点输入、参数、已提交任务记录、导入媒体和成功生成的媒体。api_key 不进入画布内容或媒体元数据；节点只关联模型配置，密钥保存在独立的本地配置范围。

保存与恢复

  • 推荐规则，待定：模型配置显式点击保存；画布编辑自动本地保存，显示“保存中 / 已保存 / 保存失败”。具体保存延迟不在 PRD 中设定。
  • 恢复画布时保留节点类型、输入、参数、引用、位置、视口和已有结果。模型配置缺失时显示模型缺失状态，结果仍可查看；文件缺失时显示文件不可用。
  • 刷新浏览器不终止运行中的 Harness 任务。Harness 本身关闭后，任务不再由本机持续查询；重新打开后，如果供应商支持并且有任务 ID，继续查询原任务，不重新提交。
  • 提交阶段未获得明确结果或没有可恢复任务 ID 时，显示“提交结果待确认”，不把它当普通失败自动重试。具体确认与重新提交规则见 SR-04。
  • 本地保存失败时保持当前内存内容，提供重新保存，提示尚未可靠落盘。模型保存、任务登记或生成结果保存失败不能伪装成“已保存”。

结果文件

供应商返回文件地址后，插件将结果保存到本地。成功状态以本地文件可用为准；不依赖临时远端链接长期展示结果。生成已完成但文件保存失败时，保留任务信息并显示“结果保存失败”，用户重试保存原结果，不重新发起模型生成。

节点直接使用本地结果预览或播放；图片大图、视频原文件可打开，用户可以将结果另存到自己选择的位置。删除画布节点默认不立即删除本地媒体，以免连带破坏其他引用；独立素材清理不列入 V1 必选范围。

05 / SHARED RULES

共享规则与状态

SR-01配置与密钥边界

  • 密钥保存后采用固定掩码，不以不同长度反映原文长度。设置列表、节点模型菜单和错误详情不显示密钥原文。
  • 密钥用于向用户配置的生成接口鉴权；不写入提示词、画布文件、生成结果描述、导出内容和常规日志。错误响应中出现凭据时也必须清除后展示。
  • 编辑时“留空保留”与“填写新值替换”含义明确。要求鉴权的配置不能被保存为空密钥状态。本地存储方式及是否采用操作系统密钥存储属于后续技术设计，本 PRD 不声称已经具备落盘加密。

SR-02节点草稿与任务输入分离

每个生成节点保存自己的草稿。提交时固定本次使用的模型、连接配置、提示词、参数及素材；后续草稿变更不能影响已经开始的任务。当前节点执行期间，生成按钮和该节点生成输入编辑暂不可用；用户仍可查看旧结果、移动节点或操作其他节点。

最近任务状态与最近可用结果是两个事实。重新生成失败时，状态是“失败”，但旧结果仍可预览、播放和引用。修改输入后提示“输入已修改，尚未重新生成”，不把旧结果标成新输入的产物。

SR-03任务状态的唯一口径

状态进入条件可见行为与下一步
待输入尚未提交任务，可能有草稿。编辑输入、选择模型、添加素材；校验通过后可以生成。
已提交 / 排队提交已被供应商明确接受；异步任务 ID 已保存在本地。等待或继续查询；没有真实进度时不显示百分比。
生成中供应商报告正在执行。继续查询；同一节点禁止重复提交。
结果保存中供应商已完成，正在保存结果文件。等待本地保存；临时远端链接不等于成功。
成功生成结果已可靠保存，本地文件可用。图片预览 / 视频播放；可引用具体结果或主动重新生成。
失败提交被明确拒绝或任务明确失败。展示原因并保留输入和旧结果；修改后用户主动重试。
提交结果待确认请求中断，无法确认是否创建任务，或重启后缺少恢复凭据 / 任务信息。阻止自动重提；优先确认原任务，规则见 SR-04。
结果保存失败生成已完成，但下载、写入或校验本地文件失败。重试保存原结果；不重新生成，旧结果保留。
本地文件不可用已保存的输出或资源文件后来丢失、损坏或无法读取。显示缺失标记，阻止其作为可用素材；可重新导入或恢复原结果。

同步图片接口可以跳过“排队”和“生成中”。查询暂时失败只显示查询异常，保留已知任务 ID，不直接把供应商任务判定为失败。文件不可用是资源可用性状态，可与任务原来的“成功”记录同时存在。

SR-04失败、确认与重试

  • 字段校验失败：不发请求，保留输入，在当前面板说明问题。没有可用模型时提供配置入口。
  • 鉴权或模型不可用：显示可理解的原因，保留节点和输入，允许前往设置修改；错误信息脱敏。返回后必须由用户主动生成。
  • 查询网络中断：保留原任务，重连后继续查询。供应商提供的任务状态是判断是否完成的依据；不要把客户端等待超时当作供应商任务失败。
  • 是否提交成功不明确：优先按协议支持的查询或幂等能力确认。若无法确认，用户可明确选择“结束本地等待”，保留原任务记录并解除当前节点的等待锁；这不代表供应商已取消任务。之后可以重新选择模型、删除节点，或明确“作为新任务重新生成”，提示原任务可能仍在执行并可能再次计费；不能自动重提。
  • 结果保存失败：重试下载 / 保存同一次任务结果；若地址已过期，按协议能力重新获取地址。无法恢复时说明原因，再由用户决定是否重新生成。

SR-05模型能力与参数

所有节点菜单与提交校验使用同一份模型能力定义，包括输入类型、参考素材数量、比例、分辨率或清晰度、数量、时长和音轨。截图选项是参考候选，不是全模型通用能力。模型切换后保留兼容字段，显式标记不兼容字段；未完成校验不能提交。

V1 不展示无来源的耗时预测、积分和任务完成百分比，不自动换模型，不自动拆请求模拟批量输出。首批能力范围在接口接入前确认，未适配协议不能仅凭 api_base、api_key 宣称兼容。

SR-06删除与进行中的任务

删除节点前，说明会同时解除相关连线；不连带删除下游节点。下游已有结果保留，输入引用同步更新并显示输入已修改。正在执行、等待确认或结果保存中的节点暂不提供直接删除，以免丢失任务追踪；其他节点可以删除。无法确认的任务可以按 SR-04 明确结束本地等待后再删除，避免无限锁定节点或其模型配置。

V1 不承诺供应商取消生成能力。关闭面板或页面不等于取消，删除配置也不作为取消方式。节点删除不立即清理媒体文件；若将来增加素材清理，需要单独定义对引用的影响。

SR-07画布可操作性

大量图片和视频节点共存时，缩放、拖动和选中不应被全部媒体同时加载或自动播放阻塞。视频默认暂停；非可见媒体无需持续播放。输入、模型菜单与参数菜单能够通过键盘聚焦操作，错误和任务状态用文字说明，不只依靠颜色。数值性能指标与支持的画布规模尚未提供，不在此虚构上限或 SLA。

06 / OPEN DECISIONS

待定事项

以下事项不妨碍评审当前流程，但需要在对应功能实施前确定。其余可逆的交互选择已在正文给出建议口径。

D-01 首批模型与接口协议核心接入边界

需要提供首批图片、视频服务的接口文档或确定支持的协议。由此确认 model_id、鉴权、提交、任务查询、结果获取与输入格式。推荐先支持有限协议内的自定义地址与模型，不承诺任意 API。

D-02 “全部本地存储”的落点建议口径待确认

当前建议指运行 Harness 的本机，同时避免把密钥保存在画布内容中。若用户期望浏览器独立保存、同一电脑多浏览器隔离，或远程 Harness 中客户端持有密钥，需要调整配置和调用流程。

D-03 画布归属与入口产品建议

推荐独立主页面、当前 Harness 工作区一个画布。需要确认是否第一版就要求一个工作区内创建多个画布；若要求，需补画布列表、命名和打开规则。

D-04 模型能力、媒体格式与参数默认值由首批协议确定

确认支持的图片 / 视频输入、数量、比例、清晰度、时长、音轨、格式与文件大小；确定各模型默认值和无鉴权本地接口是否在首批范围。不能直接照搬截图所有选项。

D-05 默认模型与多结果引用产品建议

当前建议新节点由用户选择模型，不静默切换；多结果在同一节点切换，并让连线绑定创建时选择的具体结果。可评审是否改为记忆最近使用模型，以及是否采用此多结果布局。

D-06 保存与面板导入规则产品建议

当前建议配置显式保存、画布自动保存；从生成面板导入素材时创建可见资源节点并连接；视频输入方式按图片引用自动判断。若期望手动保存、隐藏素材或手动模式切换，需要同步调整正文。

实现约束与依据：画布依赖由用户指定为 React Flow，当前官方包名为 @xyflow/react。本 PRD 定义可观察产品行为；插件包结构、接口契约、密钥落盘方式和任务调度进入后续技术设计。五张截图是用户提供的交互参考，未把示例品牌、积分或耗时作为产品承诺。
