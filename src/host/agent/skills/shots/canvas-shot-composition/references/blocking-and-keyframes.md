# 人物调度、光线与关键帧

本文件为教学参考，只使用用户项目真实锚点和本批授权素材。模板与示例不是证据。

## 两层空间表达

| 层 | 记录 | 反例 |
| --- | --- | --- |
| 场次地理 | 人与锚点、彼此关系、接触/距离、轴线、摄影机工作侧 | 只写画面左三分之一，换机位失效 |
| 单镜画面 | 从当前机位能看见的前后景、画面左右、朝向、视线、遮挡 | 只写“隔桌相对”，无法判断同侧/异侧 |

教学正例：场次“顾客贴柜台外侧，店员在内侧，二人隔柜台相对”；关键帧“从门口一侧拍，顾客背部在前景，柜台隔在二人之间，店员看向顾客右手”。反例：无机位、无前后景，只写“人物对峙”。

## 正反打

甲镜人物在画面左看向右；乙镜对方在画面右看向左。声明前景肩膀是谁、是否遮住手和证物。身高和距离影响视线高度，机位不对称时写明是空间事实还是导演选择。

跨轴时说明镜内穿轴、重新交代空间或有意主观错乱；之后写新的工作侧供后续镜头继承。不能把不连续自动解释成“艺术处理”。

## 根据载体选景别

| 必须读清什么 | 候选尺度 | 易丢失什么 |
| --- | --- | --- |
| 人与出口/空间的关系 | 全景/中远景、前中后景 | 脸部与细小证物 |
| 二人的策略、递交或阻挡 | 中景/双人同框/过肩 | 前景可能挡住手 |
| 判断或后果 | 中近景/近景、反应停留 | 空间需要前镜已建立 |
| 牌背文字/录音笔按钮 | 插入镜/细节近景 | 须保持控制者、当前状态与阅读时间 |

选择理由必须回到本镜任务，不固定“情绪强=大特写”。

## 光线工作表

写现有光源、入射方向、软硬、照到谁、何处明/暗、需要保护的载体。同一场次光向变化有理由；没有参考或实测时不编造精确色温/光比。人物要暂时不被认出，可用已有逆光或遮挡，但证据展示镜不能把证据放暗部。

## 冻结起点与终点

教学起点：寄存牌仍由顾客右手握住，正面朝店员；本镜动作是翻牌。起始帧不能已经显示牌背划痕。终点：牌背朝店员且划痕可见；尾帧不应仍是未翻状态。

起点/终点分别核对人、手、物件、朝向、位置、可见信息。单张图不能同时表达互斥状态；首尾图仅约束两端，仍需动作正文和真实参考边。

## 群体与竖屏

以主行动者、见证者、出入口和阻挡者分区；保留真实遮挡与纵深。屏幕UI/字幕安全区只有用户已说明时才作为交付约束；未说明不猜模板，也不在关键画面上私加字。

## 完成前

可见信息没有超出起点；人物自身左右与画面左右不混；关键载体无遮挡；参考用途独立；待生成图不写真实ID；不能凭文字说明宣称已看过实际图片或视频。
