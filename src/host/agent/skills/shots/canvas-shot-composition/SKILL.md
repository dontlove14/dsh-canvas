# 单镜画面

## 适用与输入

单镜构图、人物调度、分镜图或关键帧修订使用本方法。输入：本镜目的、序列/导演意图、场次固定锚点、起止状态、实际画幅与已获授真实资产。单镜已有确定方案时直接修改点名项。

## 工作步骤

1. 指出必须看清的信息及尺度：脸、眼神、手、证物、人物关系还是空间后果。以信息载体选景别，不把特写当情绪强度按钮。
2. 先确定真实站位关系：谁在锚点哪一侧、距离/接触、朝向、持物、出口和遮挡。再翻成本镜机位下的画面左右、前后景与视线；不能只写“二人隔桌相对”。
3. 写摄影机高度、角度、工作侧、前景归属和焦点对象。正反打的方向互补，越轴必须有明确转向/中性过渡或上游允许的主观安排。
4. 写光源身份、方向、软硬与明暗关系；现有灯/门/窗是事实，不能为好看添无授权物件。重要字、脸或动作不能被阴影或前景遮住。
5. 关键帧只表现镜头起点，删除终点才出现的文字、姿态和道具状态。尾帧只有明确锁定终态且模型支持时另写；两端图不代替中间动作。
6. 逐份写真实参考控制什么、不得控制什么；分镜图控制构图/起点，不替代人物、服装、场景、道具原始参考。已有来源、逻辑规格、待生成图与真实assetId分开。

## 专业技巧

- 裸写“左/右”表示画面方向；人物自身左右必须写“她的右手”等主体。场景方向以真实锚点互定，避免换机位后关系翻转。
- 竖屏多人优先纵深与站位关系，不把人物缩小排成名册。背景角色只在需要识别或有实际作用时追加规格。
- 低/高角度、远/近景、过肩和景深都是候选表达；写选择理由与代价，不把摄影术语拼成互相矛盾的清单。
- 同场光色保持可解释，刻意改变须有故事/环境依据。写实、二维、三维风格分别用合适词汇，不强制统一毛孔或摄影“8K”词。

复杂多人、视线、布光与起点/终点问题按需读取[调度与关键帧参考](references/blocking-and-keyframes.md)。

## 交付与检查

保存storyboard：本镜职责、固定关系、起点、景别/机位/焦点、前中后景、光源、运动建议、真实参考用途、可读性与待补项。动态过程另交canvas-video-shot-prompt，不能用静态图声称动作已完成。

检查人物身份、场次地理、视线/轴线、手和物件、揭示时机、关键文字与参考覆盖。素材不可见时明确证据限制；缺关键前置只阻塞相关部分。专业角色不建节点、不提交生成、不改旧素材或任务。
