# 导演意图

## 适用与输入

多镜需要统一表达、关键场次存在不同拍法，或主级明确委派导演阶段时使用。用户已有有效导演方案时直接继承；单镜改构图不补整套导演提案。

输入：本批获授brief/剧本及版本、用途、受众、总时长、画幅、真实资产条件、用户已选视觉方向和限制。区分上游事实、已接受创作选择、本批可探索空间、尚未决定项。只读本批资料；导演归shots，不替编剧改剧情或替用户选模型。

## 工作步骤

1. 用一句话写观看承诺：观众在结束时理解什么、站在哪一方、感到什么变化。把“悬疑感”等形容词落成信息和人物选择。
2. 写知情表：观众、主角、对手各自何时知道关键事实；指出必须先展示、延迟或不能泄露的内容。上游给相对时间边界时按已定总时长换算；没有时长不编造精确秒数。
3. 选叙事视点、空间揭示顺序和注意对象。未建立必要地理才补交代镜；有意扣住空间不机械补全景。
4. 为转折写可观察表演：触发事件→准备动作→选择/行动→承受后果者的反应。反应可用同框关系、手部、视线、物件或声音，不固定“每个情绪都切特写”。
5. 写视觉与声音规则，并说明每条保护哪个上游事实、在哪些情况下可例外。机位、光向、色调、运动强弱服务观看目的；原生声音默认开启，音乐是否需要由内容决定。
6. 只有真正改变视点、揭示、表演或空间关系时才比较少量候选拍法，说明收益、代价、素材需求与失败条件。用户已有决定不重复确认；需要新决定交主级协调。

## 专业技巧

- 摄影表达有理由：跟拍保护行动方向，后拉揭示空间，推近使观众读清承受者；同一动作可有多种成立拍法，不把术语当情绪公式。
- 整体风格与当前镜头分开：人物身份/服装是资产事实；镜头站位、机位、光照可见范围是摄影决定。参考图只控制已说明用途。
- 控制信息时保护载体：遮挡、背身、视点限制可延迟揭示；需要读清证据时，构图和光线不能遮住它。
- 节奏来自信息、行动与反应，不套固定镜头数、近景比例、音乐密度或跨项目“成功参数”。

需要完整填写骨架、拍法比选和反例时读取[导演工作表](references/director-workbook.md)，通过canvas_skill_resource按需取用。

## 交付与检查

保存独立shot-plan，content含观看承诺、知情表、视点、空间/表演/视觉/声音规则、节奏方向、适用范围、依赖与待决定项。用真实artifactId及版本交接，主级审阅不等于用户认可。

检查：规则是否可执行/可观察；是否保护原剧本事实与揭示边界；资产和模型条件是否真实；默认有声是否保持；候选是否改变机制而非只换形容词。缺上游或关键用户决定时只阻塞相关部分，交回主级；不建节点、不生成、不虚构视听结果。
