# 导演工作表与拍法比选

本文件是方法参考，示例不构成用户项目事实、素材或许可。填写只用本批获授输入；示例人物和情节不能进入实际成果。

## 最小导演工作表

| 项目 | 写什么 | 如何核对 |
| --- | --- | --- |
| 观看承诺 | 谁要什么、阻力、观众最终看到的变化 | 能落实到行动与结果 |
| 知情边界 | 观众/各角色分别何时知道关键事实 | 后续镜头没有提前泄露 |
| 视点 | 跟随谁、何时离开该视点、原因 | 每次视点改变有信息职责 |
| 空间 | 必要锚点、入口、冲突区域、摄影机工作侧 | 能支撑后续站位与视线 |
| 表演 | 触发、可见行为、人物选择、后果 | 不只写“愤怒/感动” |
| 视觉与声音 | 哪些信息由画面、声音或留白承载 | 音乐不替代缺失的因果 |
| 节奏 | 哪里收紧、哪里停留、理由 | 不是固定时刻插反转 |
| 依赖与缺口 | 实际成果版本、素材条件、需用户决定处 | 未生成图片不能算可用依赖 |

## 同一场次的不同拍法

教学场景：顾客右手持寄存牌，请店员查看牌背；店员认出划痕后归还录音笔。

- 有限视点：先给顾客争取取回物品的动作，牌背在店员读取时才展示。适合观众与顾客一起等待结果。
- 提前知情：先清楚展示牌背，再看店员会不会认出。适合关注店员选择的期待。
- 同框关系：柜台作为控制距离，牌和录音笔跨柜台的过程保持可见。适合表现控制权变化。

比较视点、揭示时机、表演空间、参考需求和制作难点；不必三个方案都做。上游已确定知情顺序时只使用兼容的拍法。

## 反例与修正

- “高级电影感”→写清视点、信息揭示、光源、行动与停留的职责。
- “愤怒所以一律低角度特写”→先判断要读脸、手、关系还是环境后果，再选尺度和角度。
- “参考项目用5秒效果好，所以全片5秒”→按本批声音/动作预算和实际模型合法时长安排。
- “旁白解释她心里难过”→若上游允许，通过握住物件、未完成的动作或发声变化表达；不能私改原台词。
