# 视频镜头规格

## 输入与阶段边界

输入：已明确镜头目的、起点/终点、构图/序列、audio-plan、宿主planningModels中的用户已确认模型与实时能力、真实媒体和生成当时依赖。加载canvas-model-aware-references与canvas-generation-prompt-craft，宿主自动注入匹配视频模型提示词方法。本阶段按生成片段（可含多个叙事镜头）写正文，不暗改剧情、台词、站位、时长或摄影路线；冲突交主级。正式分镜前先确认模型，不把选型留到节点创建时。

## 工作步骤

1. 逐项核对真实输入和用途：source、assetId、token、控制范围。派生分镜的referenceDependencies按当时记录读取；必要人物/服装/场景/道具原图直接参考，不猜ID或只接分镜图。
2. 按所选模型实际能力选text/reference/frames。首尾帧只用于明确锁定起止的需求；只有一张图不默认frames，参数不代替真实连线。模型不支持的参考或模式交主级协调。
3. 写“静态必要锚点→起点→主要动作→次级反应→摄影→声音→终点”。每个动作说明触发者、方向、接触对象和落点；交接/换手不能靠镜外瞬移完成。
4. 用不重叠时间段写先静后动、先后对白与动作。可并行事件明确共用窗口；固定与推拉、同时左右摇等冲突先消除。时间值来自当前镜头预算，不编造逐0.1秒精度。
5. 台词逐字继承实际剧本，标说话者与画内/VO/OS通道；声音事件之外交代环境底声。音色参考与台词分开，多个角色不共用一份声音。
6. 核对动作/对白/反应能否容纳，连续相邻镜头优先共用一次生成，按当前合法时长和必要参考并集检查。超载交主级延长或按闭合状态拆段并说明原因，不用“快速、依次”掩盖，也不为用满上限增加无用动作。
7. 给出干净生成正文与分开的参数/引用/缺口清单，主级据此构造精确commands。prompt默认中文，真实token逐份说明用途；不把内部规则编号、文件路径或未解决占位符塞进最终正文。

## 声音与能力

支持声音开关默认generateAudio=true；无固定音色、无音频参考、无对白、准备FishTTS或后期配音均不设false。用户只要求“不要配乐”时保留环境/动作/对白；整镜无声须用户明确且主级宿主绑定目标。模型无开关不塞generateAudio。

不支持音频参考只跳过音色一致性。规划嘴型同步、精确声效或音乐段落不等于已实现；效果由真实结果与用户视听反馈确认。没有剪辑/混音能力，不把独立TTS写成自动替换原音轨。

## 相邻镜与修订

保持前镜终态和下一镜起态一致。确需续接时先核对当前模型及工具是否实际支持、前段真实产物是否取得、引用是否获授；不写“自动提取尾帧”或重提历史任务。有时间/地点跳变或独立镜头方案时照上游决定，不强制续接。

复杂表演、声画时序和超载排查按需读取[运动与声音规格工作表](references/motion-and-sound-spec.md)。

## 交付与检查

保存shot-plan：逐镜prompt、实际合法参数建议、真实引用表、声音事件、起止状态、上游依赖和待补项。交付前检查token/边用途、模式计数、合法时长、指令冲突、台词真值、状态连续和有声默认；缺关键决定阻塞对应镜头。专业角色不建节点/改图/生成，不改既有素材或认可。
