# 长文分批改编

## 输入与入口

输入：本批sourceIds、来源版本、真实readRanges、获授范围、已保存纲要/设定/改编决定和当前任务。加载canvas-creative-source-reading，用实际索引和读取回执定位；目录或摘要不能冒充全文。

先判断：新材料需要读本批范围；部分完成从缺口继续；完整有效成果直接复用；只要求补剧情/人物/节奏时读对应已有成果。已有来源版本变化则核对受影响范围，不覆盖旧认可。

## 工作步骤

1. 固定保留项：核心人物立场、关系、事件意义、结局承诺和用户允许的改动。无需全书分析的局部任务不扩成完整改编。
2. 先保存获授范围内可确认的全局框架，再按连续章节/情节块分页读取。每块同次提取事实、人物知情、事件因果、情绪变化与后续接口，减少无目的重读。
3. 建立两条时间线：实际事件发生顺序与原文披露顺序；分别记读者和各人物已知内容，防止把后来信息写成早已预知。
4. 用改编账本记录保留、压缩、合并、移动、外化或新增建议及其来源、保留意义和影响。已获授权的常规压缩/外化在本批范围内直接完成；越出授权或改变既定核心事实的新增与重大变更列候选，交主级协调用户决定，不冒充原文事实，也不重复询问已经确定的决定。
5. 分集/分段按完整追求、选择、结果和新压力切分；避免按相等字数切断场景。合并人物/场景时重新核对证据归属、对抗策略、关系与伏笔。
6. 每块保存独立brief成果与真实范围、依赖、下一起点。聚合优先用已存摘要和账本；矛盾或缺证据时才定点回读，说明原因。
7. 结束前核对本批覆盖和未读区、退出状态、人物知情、持物/代价、未兑现承诺，以及后续写作所需的缺口。

## 专业技巧

- 心理独白可建议外化成可演动作/对白，但要保留原意、人物身份与知情；具体摄影交shots。
- 前移高光或冷开要重建披露顺序，不改变事件事实或偷跑后续人物知识。
- 节奏分三层看：事件推进、受众情绪、篇幅/表演时间。评分不能替代每处为什么改变的解释。
- 长篇人物前史只提取影响当前选择的部分，不全塞进首场对白。
- 文风分析提炼叙事距离、句长、对白习惯与描写密度，不复刻原作表达或把引用当新创作。

需要分页账本、双时间线、合并/移动反例和续作交接时读取[改编与续读工作表](references/adaptation-workbook.md)。

## 交付与检查

保存brief：本批全局/分集纲要或改编段落、来源范围、事实与候选变更、双时间线/知情状态、依赖、未读区和下一步骤。新成果独立artifactId，已保存文件/认可不重渲染或重置。

检查来源版本、实际覆盖、核心关系、因果/伏笔/证据归属与退出状态。中断保留已存分段与缺口，不把部分完成说成全书完成；不调用额外子Agent、终端/文件工具或修改原文，不因外部套件可用而扩大权限。
