# 内容结构与叙事

## 适用与输入

内容简报、故事结构、人物关系、广告/教程/纪录的信息组织。输入：用户目的、受众、形式/时长、已存设定、来源范围、不可改事实和可探索空间。已有完整结构或只改一场时复用有效成果，不补整套开发流程。

## 工作步骤

1. 写观看/阅读承诺：受众要获得什么理解、情绪或行动；区分用户已决定的方向与本批候选。
2. 提取事实、人物目标、已有阻力和结局/主题限制，给必要事实保留来源位置。原创请求可在已授权空白内设计必要人物、关系和情节，记录为本批创作内容，不逐个常规细节提问。改编或局部修订不为制造反转补造未有来源/授权的关系、数字和资源，不把新创作冒充原文事实。
3. 剧情用“因为→选择/行动→结果→新的压力”建立推进机制；广告用真实痛点/证据/价值/行动；教程以理解前提/示范/误区/应用组织；纪录区分事实、观察与解释。
4. 对每段写进入状态、追求、阻力、策略改变、当段结果和退出状态。压力升级须改变信息、关系、风险、资源、控制或代价，不能反复重复同一个障碍。
5. 区分发生顺序和披露顺序：观众与角色何时知情，悬念/揭示/反转/回报各自承担什么功能。可以先给高光或冷开，但必须保留因果与来源边界。
6. 按时长、动作/对白需要和内容重要性分配节拍。没有已接受比例时不强制“第几秒反转”“固定几幕/几集”；多集每集先有结果再交接压力。
7. 做承诺兑现与经济性检查：删没有变化的重复段落，保留支撑结局的铺垫和人物选择。只有影响主线或用户已定事实的缺口才交主级决定。

## 专业技巧

- 人物不只是一组性格词：写当下目标、可用筹码、底线、失败代价与面对新信息的策略。
- 对抗方要有相称的判断和反制，核心突破不能来自对手突然停止反应或无依据的外援。
- 用局面变化表达节奏；“快”可以是信息集中，“慢”可以是重要选择的停留，不等于统一字数。
- 伏笔和回报成对：指出前文建立了什么、何时改变读者理解，不能用结局倒推人物一直预知。
- 候选方向改变冲突持续方式、人物策略或代价，不仅换职业/名字；未经用户选择不进入既定事实。

需要故事引擎、因果节拍与非剧情内容示例时读取[结构工作表](references/narrative-workbook.md)。

## 交付与检查

保存brief：目标/受众、事实与可改范围、人物关系/策略、内容结构、因果节拍、披露顺序、铺垫回报、节奏和待定项；依赖只指真实获授成果。

检查每段是否推进、对抗是否成立、事实是否有来源、当段承诺是否兑现、时长是否合理；主级审阅不替代用户认可。情绪重点交shots做导演/摄影表达，不写景别、机位或运镜方案。未读或用户决定缺失保持缺口，不创建节点或媒体。
