# 可呈现剧本

## 适用与输入

写可呈现剧本或定点改稿。输入：获授简报/结构/来源、人物目标与关系、用户语言和已定事实、范围/时长。已有用户剧本保留作者声音，只修点名范围；当前材料足够直接写，不要求额外开发稿。

原创任务可在已授权空白内补齐必要场景、行为和台词，作为本批创作内容交付，不把普通细节逐个交用户决定。改编与局部修订守住原文及已定事实；影响核心限制或超出范围的选择交主级协调。

## 工作步骤

1. 每场写地点/时间、进入状态、谁要什么、阻力、当前策略和场尾变化。场次编号只是内容定位，不冒充真实图或任务ID。
2. 排“已有事实→人物行动→对方反应→新局面”。核心突破有实际筹码、判断或代价，不能靠无依据外援或对手放弃反应。
3. 把状态写成可见/可听行为：准确动词、具体物件、朝向/接触/持有变化；保留演员可选择的空间，不只写心理形容词。
4. 为每句台词写说话者、争取/回避/试探等意图与听者；区分画内对白、VO、OS、重要音效、画面文字。含冒号的动作说明不能误当对白。
5. 用潜台词和行为形成过去关系，避免角色替观众背背景。中文默认自然，保留用户风格，不统一改成解释性旁白或机械“狠话”。
6. 通读自写初稿，删复述刚演完动作、无新作用的说明和同义收尾；重要反应、选择和兑现保留。对用户原文提出有影响的删改建议，不能自作主张清洗。
7. 按表演/对白/动作/停顿检查时长，估计必须标注依据；容不下时优先删冗余或请求拆场/修订，不用统一字数换算秒数。

## 专业技巧

- 情绪通过触发与行为表现：例如“握牌的手停在柜台上，换一句试探的话”，比“极度复杂地难过”可表演。
- 对白不是信息清单：同一目的可用请求、讨价还价、回避或改变关系等策略，词汇贴合身份。
- 开场快速建立谁要什么或值得关注的变化；不固定前三秒爆点。收尾完成当段功能，可安静、开放或有后续压力，不强制外部反转。
- 声音事实可提前建立画外空间或主动撤出某声源；音乐不替代人物选择。音效、VO与画面文字是内容需求，具体镜头承载给shots、声音时序给audio。

需要场景骨架、潜台词正反例、经济性遍和局部修订时读取[剧本工作表](references/script-workbook.md)。

## 交付与检查

以brief保存本批剧本：场景、动作、对白/VO/OS/SFX/画面文字、叙事节拍、重要连续状态、来源及待定项。按请求完成范围，长任务分段保存；未完成部分保留缺口，不能宣称全稿完成。

检查每场是否改变局面、人物动机/知情、台词归属与真值、动作可呈现、声音/文字是否明确、结尾功能和来源一致性。导演意图、景别、机位、镜头运动与顺序交shots；不建节点、不生成、不新增用户未要求的制作范围。
