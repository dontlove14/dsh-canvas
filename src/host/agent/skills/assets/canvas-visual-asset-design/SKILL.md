# 视觉资产设计

## 适用与输入

拆人物、服装、场景、道具，判断复用还是新增变体，或修订视觉设定时使用。输入：本批获授剧本/brief、导演意图、既有asset-spec、已认可素材与用户限制。先读获授成果；需要原文证据时用canvas-creative-source-reading读取精确范围，不按章节标题或文件名猜画面。

用户点名局部修改时只处理相关条目及直接影响，不默认重拆全剧。缺镜头序列时可先完成已有明确身份与基础设定，把所需视图标为待定，不猜机位或凑生成数量。

## 工作步骤

1. **逐次提取出现证据**：记录谁/何物/何地出现、原文位置、明确可见描述、状态变化与含混指代。分开“原文明确”“用户已决定”“专业提议”“待核”；情绪、职业或善恶不能直接变成脸型、破旧衣物或布光。
2. **对齐持续身份**：结合来源、去向、剧情连续和唯一标记判定同一实体；逻辑名称便于交流，真实assetId才指向媒体。两个“保安”不自动合并，同一人换称谓不自动拆分，无法证明的“雨衣人”保持未决。
3. **判定复用与变体**：明确分为复用、新变体、新身份、未决。换装、持续伤势、昼夜、天气、开闭或破损通常是同一身份的状态；跨多镜持续或需要独立参考时记变体，只写相对基准的差异。短暂姿势、视线、表情、镜头左右和持物动作交shots，不逐项创建资产。
4. **写最小识别锚点**：人物写稳定面部比例、发型轮廓、体态和可辨标记；服装单列剪裁、主色、材质与关键配饰；道具写轮廓、相对尺度、材质、可操作部位与唯一标记。用可观察描述区分近似实体，不用“高级、帅气、电影感”代替特征。
5. **先定场景地理，再定视图**：记录入口/出口、固定地标、连接关系、尺度及主要材料。用锚点相对关系或已确认方向表示固定地理；只有声明观察侧与朝向后才写画面左右。同一房间停电前后不变新地点，独立房间有自己的空间身份。
6. **列必要视觉输入**：按镜头实际需要写身份、服装轮廓、环境方位或道具细节的所需视图与用途。每张待生成图只承担明确职责；有可用已认可素材先复用。镜头目的未定时不擅自要求整套三视图、多表情或四面场景。
7. **交连续性核对**：将不变项、变体差异、变化依据与生效范围交canvas-asset-consistency；有真实图与模型决定后交canvas-asset-generation-spec。文字设计、待生成规格和真实媒体分别记录。

## 判断边界

| 层 | 本方法负责 | 应交下游 |
| --- | --- | --- |
| 身份 | 谁、哪一地点、哪一件可独立追踪的物品 | 不凭显示名替代真实素材身份 |
| 状态/变体 | 哪套服装、持续伤势、道具开闭/破损、时段光态 | 变化起点与适用镜头交一致性方法 |
| 场景地理 | 门窗和地标相对关系、可行走连接 | 机位、焦段、演员站位交shots |
| 镜头瞬态 | 只引用已有镜头需求 | 手、视线、表情、递物过程由shots落实 |
| 声音 | 记录已获授的上游声音需求 | 选音色交voice/主级，表演与TTS交audio |

可独立流转的两枚同款证物要分开追踪；无连续性要求的普通布景可按类型管理。跨场持续的身体—物件关系（例如手腕被绑、物件固定安装）记状态及生效范围，单镜抬手不提升为永久特征。

含文字的资产先核对真实来源及用户要求：精确可读文字、仅图形轮廓、空白或待定分别说明，不猜品牌、标牌内容或号码，也不同时要求可读文字与全局禁字。

复杂身份、变体或场景问题按需读取[资产设计工作表](references/asset-design-workbook.md)；示例用于判断，不作为本项目人物或事实。

## 交付与检查

用现有asset-spec保存设计：逻辑名称/类别、出现证据、身份判定及理由、稳定锚点、基准与变体差异、生效范围、固定地理、所需视图、真实assetId或待生成状态、依赖、验收项与未决影响。这些是创作内容，不新增图或DDL字段。通过canvas-saved-artifact-handoff交接实际保存artifactId。

检查所有明确出场都有判定，未决没有假身份流入下游；人物/服装/地点/道具层次清楚，细节有依据，数量有用途，既有认可与真实素材版本被复用。缺来源、导演决定或可读素材时只阻塞依赖缺口的条目，保留独立已完成部分。

专业角色只读获授资料并保存成果，不建节点、不提交生成、不选择供应商、不替用户认可，也不修改历史素材、任务或原图。
