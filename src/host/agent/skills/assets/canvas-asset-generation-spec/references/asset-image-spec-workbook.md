# 资产图片规格工作表

这是节点准备前的创作参考，只产出现有asset-spec内容。模板中的ID说明要替换为本批真实回执，不产生新节点、模型调用、图结构或工具权限。

## 1. 用途决定视图

| 下游需要看清什么 | 候选图 | 必要信息 | 不应附带 |
| --- | --- | --- | --- |
| 人物脸部身份 | 头肩正面/适当侧面 | 五官比例、发型、稳定标记 | 无用途全场景、遮脸背光 |
| 行走时服装轮廓 | 全身侧面或所需角度 | 服装剪裁、体态、鞋与轮廓 | 裁脚、互斥衣服混在一人身上 |
| 场景入口及行动通道 | 已定朝向的空场方位图 | 门窗、固定锚点、尺度/连接 | 为美感搬门窗或加入无关演员 |
| 功能道具 | 可操作部位近景/整体尺度图 | 轮廓、按钮/扣/铰链、材质 | 过曝反光遮住结构 |
| 持续状态变体 | 单一当前状态图 | 相对基准的可见差异与范围 | 同时打开/关闭或受伤/未受伤 |
| 探索视觉方向 | 代表性风格帧 | 对比的是光色、材质或画面组织 | 冒充用户已认可人物/场景资产 |

单图、多图或多视图板由实际用途、模型和下游决定。多视图并排明确同一身份与单一造型、视图数和位置，按已授权文字要求处理视图标签；不默认其每格都是可独立输入的图片。

## 2. 本图规格骨架

```text
逻辑名与用途/验收目标：
来源规格及版本：
真实待改图片（局部编辑时）：
静态prompt：
negativePrompt（有明确问题时）：
实际模型/模式、比例/尺寸与支持参数建议：
逐份真实引用及控制范围：
必须保持的可见不变量：
所需前置/未决：
影响镜头：
```

prompt编写顺序：用途与主体 → 不变锚点 → 当前变体 → 视图/构图/尺度 → 光色/材质 → 背景 → 文字 → 保持/排除。省略无关项，默认中文；真实{{asset:实际UUID}}按现行引用契约保留。

教学静态例：“道具参考图，窄长铜盒约一掌长，正面圆扣及扣旁斜磨痕清楚可见；盒盖关闭，略俯视角让正面扣与短边铰链同时可见；柔和侧光保留金属材质但不过曝；中性背景，无无关物件。”以上特征仅是例子，实际须来自用户规格。

反例：“盒子关闭并打开，快速翻转三次，超高级8K，各种机位一起展示。”它混合互斥时刻、动态过程与无用形容词。

## 3. 参考的允许与禁止控制

| 主要用途 | 允许影响 | 明确防止带入 |
| --- | --- | --- |
| 人物身份 | 脸、发型、体态和已定稳定标记 | 参考里临时姿势、其他人物、无关服装 |
| 服装/状态 | 已选当前变体的剪裁、材质和可见状态 | 改脸或扩大状态生效范围 |
| 场景地理 | 固定锚点、尺度与空间连接 | 未授权演员、文字、错误机位方向 |
| 构图/尺度 | 主体占比、留白、相对大小 | 他人身份、剧情、标牌文字 |
| 风格/效果 | 指定光色、材质或局部效果 | 改地理、使非目标对象消失或变形 |

每份引用记录source、真实assetId、现行token、主要用途、控制与不得控制。必要原始人物/服装/场景/道具图受canvas-model-aware-references及实际模型限制；缺图/超限交主级，不虚构ID或用“全参考”掩盖冲突。

控制范围是给模型的意图和交付核对依据，不是实际效果保证。无获授可读图时不能声称参考中没有水印、字幕或多人物。

## 4. 光线与文字

按要比较的结构选择识别光：脸部比例/衣服固有色需要清楚可比，材质纹理需要保留表面，金属道具需要避免高光吞掉功能部位。轮廓光可辅助外形，不能单独承担身份识别。二维/三维/写实按已选风格描述，不按男女或职业固定分配光型。

| 已确认文字要求 | 正文处理 | 冲突例 |
| --- | --- | --- |
| 精确可读 | 保留原文、承载面、位置与可读性 | 要胸牌原文却全局禁止文字 |
| 仅图形轮廓 | 写轮廓/版式且不要求可辨文字 | 偷加姓名/网址 |
| 空白 | 指明目标承载面留白 | 保留参考里原有标牌却声称已清除 |
| 未定 | 标缺口并交主级；只做独立可完成部分 | 自编品牌/数字来填表 |

参考里已存在不符合要求的文字/服装不能靠负向保证清除。只提出准确处理范围，不自行裁图、上传、运行清理工具或承诺后期已完成。

## 5. 局部编辑差异四要素

```text
目标：当前真实图、具体对象、具体区域。
变化：位置、范围、程度、色彩/材质的结果。
保持：脸/体态、未变服装、地理、道具、构图、光向、未选区域。
连续性影响：对应变体/状态及相关镜头；无影响要说明原因。
```

教学例：用户要求只加雨后袖口湿痕。

- 目标：获授当前人物图的本人右袖口。
- 变化：袖口上方约一掌范围呈浸湿后的深色，布料贴合，无撕裂。
- 保持：面部与发型、衣服剪裁、袖口双线、胸前物件、背景、机位与光向。
- 影响：当前雨后状态；交一致性方法核对哪些镜头适用，基础人物身份与此前镜头保持。

反例：“让她更狼狈”，容易改脸、改衣服与场景。把门移到另一墙改变固定地理，先退回视觉设计及相关shots核对，不能当局部装饰直接覆盖。

先读取最新目标与获授基准，再准备修订，不能旧缓存覆盖用户新增内容。一般授权内文字改稿不重复审批，模型/范围/付费决定由主级按既有流程处理。

## 6. 准备完成的含义

验收目标清楚、正文静态且无矛盾、参数是实际模型支持值、引用有真实ID与用途，才交给主级构造commands。专业保存后返回真实artifactId，执行者只按精确清单创建节点，图片由用户点击生成。

“已准备规格”“节点已创建”“任务已完成”“用户已认可画面”是不同证据；不混写。没有真实生成与用户观察，不能说模型已经保持人物一致或完成图片修改。
