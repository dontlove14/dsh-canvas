# GPT Image 构图与编辑工作表

使用当前批次的模型、素材与决定填写；以下为教学例，A/B须替换为获授实际UUID。

| 项 | 填写内容 |
| --- | --- |
| 用途 | 单张身份 / 产品 / 场景 / 运动起点 |
| 场景与构图 | 机位、景别、主体位置、留白、前后景 |
| 几何 | 尺度、持物、接触、遮挡、标签面 |
| 真实参考 | A控制身份或结构；B只控制风格或布局 |
| 文字 | 逐字原文、次数、承载面、字号层级 |
| 编辑 | 保持清单→唯一变化→必要阴影或遮挡变化 |
| 核验 | 用户看图核对哪些细节；未能观察的项 |

正例，包装静态图：

“制作一张用于商品目录的实物照片。{{asset:A}}控制水杯的圆柱轮廓、杯盖结构和标签原文；杯子直立在浅灰台面中央，标签面朝镜头。平视中近景，杯底与台面接触，左上柔光、右侧柔和阴影。标签上仅保留‘山间’两字，位置和字形沿参考；画面右上留白，不增加其他文字。”

正例，局部修订：

“编辑{{asset:A}}。保持杯身轮廓、杯盖、标签‘山间’、标签位置、构图和光向。仅把杯身白色改为深绿色，保持材质细微纹理，随新颜色调整自然反光；标签底色与字体不变。”

反例：“高级8K产品；换一个杯子、更好看的标签、顺便改背景，所有像素完全不变。”结构、文字与改动范围冲突。

运动起点例：若图要供视频使用，写“人物右手刚触到门把，门尚未打开，右侧有可行走空间”；不要在静态图要求“开门后走入再关门”。是否需要尾帧另按当前视频模式和授权规划。
