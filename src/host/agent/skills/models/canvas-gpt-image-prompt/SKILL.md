# GPT Image 提示词

输入：宿主planningModels中已确认的gpt-image模型、实时能力、获授资产规格、实际图片及用途。方法参考GPT Image系列公开指南；适用于本项目同族适配，不把GPT Image 2的参数或质量结论宣称为2.5实测。

## 步骤

1. 先点明交付用途，如人物身份图、产品展示或下游视频首帧。按场景→主体→关键细节→构图→约束组织；复杂图分短段，一张图描述一个时刻。
2. 写可观察的几何关系。人物脚是否入画、手握哪个部位、视线朝哪里；产品轮廓、开口、标签面与接触阴影逐项给出。摄影词控制观感，不声称精确物理镜头仿真。
3. 逐份用真实{{asset:实际UUID}}及描述区分身份、产品结构、构图和风格来源；合成时说哪个对象从哪图进入哪位置。只有宿主给了真实输入顺序才附序号，不猜Image 1。
4. 文字逐字加引号，说明仅出现几次、承载面、位置、字体类型、字号层级和对比；复杂词保持用户原拼写。排除的是额外文字，不笼统禁止文字。
5. 修改先列保持项，再写唯一变化及接触/遮挡影响。保留脸、体态、产品几何、未改标签、机位与光向；每次新任务重新列出，独立节点没有隐含“上一轮”会话记忆。
6. 透明背景、质量、尺寸等只用当前capabilities允许的参数；文字写清孤立主体、边缘要求，不通过正文模拟输出格式字段。未知参数交主级。

需要构图、文字或单项修订时读取[GPT Image工作表](references/prompt-workbook.md)。

交付：现有asset-spec中的中文prompt、真实引用用途、参数建议、保持清单与验收点。用户指定语言/文字、真实token保持；生成仍由原执行与用户流程完成。

检查：同族已确认模型；主体位置与几何可画；无互斥姿势；精确文字与排除项一致；新稿重述保持项；未引入外部input_fidelity、目录、脚本或自动生成。

阻塞：未选模型、缺真实编辑基准或关键标签原文时报告缺口；无法看到图片只给计划，不能声称已核验保真或承诺文字准确。
