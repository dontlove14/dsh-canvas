正例：

“制作一张社区旧物市集海报，面向附近居民。采用暖色纸张质感插画，主画面是一张摆有书籍和旧台灯的木桌，桌子在画面下半部。{{asset:A}}只参考配色与纸张笔触，不复制原图人物和字；{{asset:B}}控制台灯形状。上半部留白，标题‘周末旧物集’在顶端中央，下方较小文字‘周六见’，均仅出现一次、深褐色、易读。”

局部修改：

“以{{asset:A}}为基准，保持标题原文、字形、位置、木桌和台灯。仅移除桌面右侧花瓶，露出与周围一致的木纹，台灯与书籍不移动。”
