# Wan 动作路径工作表

| 项 | 填写内容 |
| --- | --- |
| 起点 | 主体位置/朝向、持物、接触与支撑 |
| 路径 | 先后、方向、速度、受力和接触改变 |
| 终点 | 落点、朝向、道具归属、稳定状态 |
| 摄影 | 跟随对象、轴线侧、幅度/速度 |
| 输入 | 实际参考用途、单份/同类时长、输入输出组合 |
| 声音 | 动作声窗口、对白原文与声源、环境/配乐 |

正例，按当前能力可用的首尾帧方案：

“{{asset:A}}为实际首帧，人物站在桌左侧、双手握杯；{{asset:B}}为实际尾帧，杯子已在桌中央、人物双手松开。保持人物身份、桌子位置和杯子形状。人物沿桌边向右迈一步，双手将杯平稳放到桌中央，杯底接触桌面后松手，终态与B一致。摄影机在同一轴线侧缓慢侧移，动作连续。轻脚步、杯底落桌轻响和房间环境声，无配乐。”

参考角色必须实际存在且与同次references一致。参数时长取宿主合法值；若需要更长等待，先说明预算缺口，不强行加快全部动作。

反例：“从站立到杯子飞到桌中，所有像素锁定；自动把参考裁到合适时长，套用网站最长值。”没有物理路线，并假设裁剪与型号限制。

合并检查例：连续走近桌子与放杯可合并，需计算去重参考并集与总动作预算；若存在输入视频，额外核对输入时长加输出时长，不只看输出上限。
