# Wan 提示词

输入：宿主已确认wan模型、实时capabilities/参考限制、生成片段、实际起终参考与声音计划。外部教程的时长或站点参数不代表本插件型号。

## 步骤

1. 用主体→环境→动作轨迹→摄影→视觉表现→声音组织。主体有身份锚点，环境有相对位置；动作给可见物理过程，不能只写“震撼转场”。
2. 起点写位置、朝向、持物与支撑关系；运动写向哪里、以何速度、接触什么；终点写到达位置和新状态。手、物体和支撑面之间保持合理接触，不瞬移或无因变形。
3. 首尾帧模式写连接两端的具体动作路线与摄影变化。参考模式区分身份、地理、动作与风格来源；角色参数不能代替真实参考边，其他模式不硬套首尾帧。
4. 对同场连贯内容先规划一次生成中的时间窗；不同叙事镜头可保留内部切镜。必要拆段给闭合状态、下段起点和原因，片段总时长用当前合法值，不照搬网站默认值。
5. 摄影运动服务动作：给跟随对象、工作侧、幅度和速度；主体运动与镜头运动分开。写实/插画等风格取已选方向，不叠互斥速度或媒介。
6. 声音写环境、接触/动作、对白主体/原文与音乐；原生有声默认。核对参考单份/同类时长及输入视频加输出总时长限制，未知参考时长报告待核，不假定可容纳。

动作路径与起终状态模板见[Wan工作表](references/prompt-workbook.md)。

交付：现有shot-plan中的中文prompt、起终状态、时间窗、实际参考用途和当前能力内参数建议。供应商可用性只信宿主目录，不自行切到已停用网关。

检查：模型同族且已确认；动作有因果/接触；首尾路径可解释；所有窗口求和；参考并集与输入输出组合合法；声音归属正确。

阻塞：缺起终基准、接触关系或能力时阻塞相关片段。不能自行补图、裁剪、延展、拼接或调用第三方工作流，不宣称已核验生成连续性。
