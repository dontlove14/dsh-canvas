# MiniMax 多模态正文工作表

以下标题可作为prompt内自然语言分节，不写成独立API字段。

文本生成：

- 画面、动作与同期声音：主体、场景、起点、顺序、摄影、终态。
- 整体声景：环境、动作声、对白说话者及原文。
- 非现场配乐：需要与否、进入退出和情绪目标。

参考生成：

- 主体定义：真实A/B/C各自控制外观、表演或声音。
- 片段概述：必须传达的变化、总时长与所含镜头。
- 保持与变化：哪些动作、空间、接触不变，哪些授权修改。
- 细节时序：首镜直接起笔；后续切镜注明递增时间。
- 整体声景与配乐：声源所有者、原文、发生窗口。

正例，外观来源与表演来源分开：

“主体：{{asset:A}}控制递信人的脸与蓝色外套；{{asset:B}}作为递信动作与镜头运动参考，沿获授表演说明保留左侧递信、右侧接信及桌面接触，不复制B中人物身份。概述：同一房间完成一次信件交接。保持：桌子地理、信件由左向右移动、手部自然遮挡；变化：仅递信人外观沿A。细节：中景起点，递信人将信放到桌中，接信人右手接住；若获授片段需要切镜，切后继续接住的状态，不重新递信。声景：纸张摩擦与桌面轻响，接信人轻声说‘我收到了’，无配乐。”

B的表演内容必须来自获授实际观察或可信上游说明；没有观看工具时标“按上游说明，视频内容待核”，不把教学描述当观察事实。

反例：“用A的脸和B的动作，所有人物说C的话；强制原声逐帧完全匹配，自动裁掉前两秒。”主体/声源混淆，承诺不存在的剪辑和精确同步。

音频边界：音色参考只约束声音特征；准确原音复用目标要明确“保留哪段原音”，并注明当前工具/模型是否能验证。无需音频参考也可写同期声音，不能因此静音。
