# MiniMax H3 提示词

输入：宿主已确认minimax型号、实时能力、获授镜头/片段、实际图/视频/音频与用途。本项目发送单一prompt字符串；下列分节是正文组织方法，不是新增请求字段。

## 步骤

1. 文本生成把画面动作、摄影与同期声音放在一份连续描述中，再说明整体环境声与配乐。参考生成先定义主体及其来源，再给片段概述、保持/变化、逐段动作、环境声和配乐。
2. 对每个主体明确“外观来自谁、动作来自谁、声音属于谁”。图片主要给身份、服装、物体结构；视频可给动作/摄影/节奏或待延续表演，不能因同时接入就自动重演整段。
3. 写保留分析。替换外观但保留表演时列姿态、相对位置、接触、遮挡和镜头运动；让新外观自然匹配原光线与尺度。真正允许改变的动作/空间另列，不承诺像素级蒙版或逐帧锁定。
4. 首镜直接写起点与动作；只有后续真实切镜写递增时间和切后景别。摄影运动给类型、幅度、方向和速度，避免同窗多个互斥运镜。连续动作不能因切镜重播。
5. 角色声音分为音色参考、环境音参考和准确原音复用目标。写对白说话者、逐字原文、情绪与窗口；新对白不能把参考音频转写误当新台词。原音复用或口型对齐只写待核目标，不保证波形/帧精确同步。
6. 采用当前模式和能力中的参考数量、时长、尺寸与组合限制；首尾帧先安排有起终点的动作。默认中文正文，保留真实token，不捏造第三方Picture/Subject标记、音色ID或adapter未支持的独立字段。

分节模板与表演保持案例见[MiniMax工作表](references/prompt-workbook.md)。

交付：现有shot-plan中的主体归属、保持/变化、分段中文prompt、真实引用表及声音目标。原生声音默认开启，独立TTS不构成静音依据。

检查：已选同族型号；身份/动作/声源对应；切点递增且预算合理；引用并集合法；未把提示词视为剪辑/蒙版/精确口型能力；没有外部自动生成与反复重试。

阻塞：缺真实表演证据不能称已观看视频；缺音频证据不能称已听过。模型或素材不支持目标时报告相关缺口，由主级决定新批次。
