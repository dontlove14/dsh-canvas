# Seedream 主体与校准工作表

| 项 | 填写内容 |
| --- | --- |
| 主体 | 逻辑对象、稳定外观及本图状态 |
| 空间 | 景别、方位、主次、通路和操作结构 |
| 表现 | 光向、材质、媒介、配色 |
| 文字 | 准确原文、承载面、位置、相对字号 |
| 引用 | 实际UUID、对象、保持/可改边界 |
| 校准 | 真实图上哪项偏差→仅修改什么→保留什么 |

正例，场景基准图：

“修鞋铺内部全景，平视，维修台在左前方、窗在左墙、出口在后墙右侧，出口前通路完整可见。{{asset:A}}控制铺内门窗地理和桌子比例。台面有一盏暖色工作灯，墙面为旧米色涂料，保留磨损。后墙牌子仅写‘修鞋’，深色字、浅底，牌子不挡门；无其他新增文字。”

正例，实图校准：

“{{asset:A}}是当前待改图；保持门窗、桌子、机位、灯和‘修鞋’牌子。仅将维修台上的鞋放到桌面中央，鞋底与桌面接触，尺度与工具一致。”仅当A实际已获授可读，才能称它为待改图。

反例：“最好的Seedream画质，一切自由发挥；保留场景但把门移到左侧；招牌字由模型决定，生成三张挑最好。”地理/文字决定缺失，且越过生成边界。

多个视图例：主级确需同一场景两个机位时，每项分别写门窗方向与真实锚点，不直接写“图2与图1一致”而省略全部身份/地理。
