# Seedream 提示词

输入：宿主已确认seedream模型、实时capabilities、获授资产/画面用途、实际参考和文字决定。Lite/Pro及各供应商共用方法，参数与可用能力以当前配置为准。

## 步骤

1. 先写主体、此刻状态和识别特征，再给环境与位置；不要只写“电影感”。人物、场景、道具各给最少的稳定识别锚点，背景信息不能盖过主体。
2. 把主体动作压成一个可画瞬间。构图给景别、机位、主次和留白；场景地理写门窗、通路、桌椅相对关系。分镜图优先显示走位和操作结构，不靠装饰表达剧情。
3. 将风格写成光色、材质和媒介。脸、衣物、道具表面应能分辨；不把主体性格直接翻成固定肤色、光型或善恶外貌。
4. 图文设计先定承载面与版式，再给准确文字。大标题、说明、小标签明确位置和相对大小；未知文字交回主级，不用模型脑补。
5. 每份真实参考说明控制对象、保持项和允许变化；用户要求系列时分别写每图用途和不变量，不把拼图默认当独立文件。局部编辑保持身份、地理和布局，仅描述授权变化及局部光影影响。
6. 草稿先保住主体与构图，获授真实结果存在时才据证据做单项校准。每次新任务重述必要约束；不自动生成多张候选、不固定英文词数、不套用旧型号参数或供应商EP。

读取[Seedream工作表](references/prompt-workbook.md)填写主体、图文版式和校准依据。

交付：现有asset-spec的中文prompt、实际引用表、版式/保持项、当前能力内参数建议及待核项。具体模型数值不写进方法。

检查：主体先于修饰；单一状态；文字逐字/位置明确；引用符合实际模型；校准基于真实图或明确写待验证；没有自动选旧模型、搜索或生成流程。

阻塞：缺主体基准、地理锚点、必要文字或已选模型时报告具体缺口。未观察结果不得声称文字/身份已一致；不重写已认可历史成果。
