# Seedance 提示词

输入：宿主已确认seedance模型与实时能力、生成片段规划、实际参考、获授动作/对白和声音决定。数值来自planningModels，不能把外部Seedance教程中的限制复制为型号能力。

## 步骤

1. 先确认生成片段包含哪些叙事镜头。连续动作、同场景和兼容参考可在一次生成内安排多个景别；有跳时、场景变化、动作超载或参考并集超限才明确拆分原因。上限是容量，不强制填满。
2. 建真实参考用途表：人物身份、场景地理、道具结构、动作节奏、摄影运动和声音分别由什么控制。用{{asset:实际UUID}}逐份关联，视频不能默认同时控制所有角色，音色参考不等于新台词。
3. 正文先写主体/场景/起点，再按时间窗写动作、摄影运动类型/方向/速度和终态。事件先后清楚，切镜注明切后景别与同一状态；时间是控制目标，不保证逐帧兑现。
4. 区分参考、首尾帧、文本模式。首尾帧给初态、完成路径和终态，不让终点瞬间跳变；模式、真实边和角色参数同次准备，参考图片不自动等于首帧。
5. 写环境声、动作声、对白说话者/原文/发生窗口、音乐需求，保留原生有声默认。模型不支持音频参考时仅描述声音目标，不添加音频；缺音色或另做TTS不是静音理由。
6. 检查动作和对白预算、所有镜头总时长、参考并集类型/数量/单份及同类时长、纯音频与组合限制。参考生视频还要核对派生成果当时的原始依赖；未知时长标待核，不假定为零。

需要连续动作或分段时间写法时读取[Seedance工作表](references/prompt-workbook.md)。

交付：现有shot-plan中的片段总时长、所含镜头、中文prompt、真实引用分工/边建议、起终状态与声音计划。主级核对模型，再交精确执行；不写外部API字段。

检查：已选型号匹配；时间窗连续且求和正确；动作/机位不矛盾；引用真实并未超限；声源归属明确；拆段有必要理由。

阻塞：未选模型、参考来源不明、能力未知或换模型导致超限时只阻塞受影响项并交主级新批次复核；不能自动换模型、剪辑、扩展视频或生成。
