# Seedance 生成片段工作表

| 项 | 填写内容 |
| --- | --- |
| 宿主模型 | 当前型号、供应商、fingerprint，合法时长与模式 |
| 片段 | 所含叙事镜头、总时长、合并/拆分原因 |
| 参考并集 | 去重后的真实UUID、每份控制对象、数量/时长检查 |
| 时间 | 起止、动作、景别/摄影、声音、终态 |
| 连续性 | 人物方向、地理、持物、起点→终点 |

教学例：只有当前能力明确支持12秒且必要参考并集合法时，把4秒发现门把与8秒开门进入规划为一个12秒片段。4和8是叙事窗口，不是两个必建视频节点。

“{{asset:A}}控制人物脸、服装；{{asset:B}}控制走廊和门的位置。人物起点在门左侧、右手空着。0–4秒，中景，人物看向门把并伸右手，摄影机缓慢靠近；4–9秒，他握住门把、向内推开门并向画面右侧跨进门口，摄影机平稳侧移；9–12秒，保持动作连续，略宽景展示进入房间，人物停在门内。门与墙的位置不变。脚步声随落脚、门轴轻响、保留走廊环境声，无配乐。”

此例无需强行占满模型最大时长。若用户要求切镜，注明“4秒切近景，右手继续同一次握把”，不能再次从伸手起演。

反例：“每镜单独生成；0–4秒4个机位，4–12秒换三个地点；A控制脸、声音和所有动作，缺音色就静音。”拆分缺理由、预算过载，参考与声音错误。

拆分正例：后半段跳到第二天、必需人物参考并集超限，或动作必须有不可容纳的等待；分别说明原段终态和下一段起点。不为合并删除关键人物参考或必要台词。
