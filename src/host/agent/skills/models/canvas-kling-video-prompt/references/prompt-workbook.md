# Kling 导演指令工作表

| 项 | 填写内容 |
| --- | --- |
| 构图 | 主体、站位、景别、通路与道具 |
| 核心动作 | 初态→顺序/速度→终态 |
| 摄影 | 跟随对象、方向、幅度与速度 |
| Omni角色 | 真实UUID、当前referenceRoles值与用途 |
| 声音事件 | 谁说原文、动作声发生点、环境与配乐 |
| 预算 | 当前合法时长、参考并集、拆段理由 |

正例：

“{{asset:A}}控制人物身份和服装，{{asset:B}}控制书店柜台与出口地理；角色参数按宿主实际参考表准备。人物从柜台左侧拿起一本书，正常速度转向右侧出口，向右走两步后停下回头。摄影机同侧平稳跟随，回头时缓慢靠近至中近景，店内位置与书的归属不变。人物轻声说‘等我一下’，纸张轻响、脚步与书店环境声，无配乐。”

需要首/中/尾画面角色时逐份解释用途并填写当前合法Omni参数；普通参考图不自动成为首帧。既有图没有合适构图时先交资产任务准备，不能宣称已裁图。

反例：“fal elements绑定角色，上传voice_ids，自动把音色转视频；五个镜头各生成再剪，所有动作慢速且高速。”接口、音频路径、剪辑和节奏冲突均不属于本项目方法。

短导演prompt不代表删除必要对白或参考分工。静态细节可以沿真实参考压缩，但重要身份、空间与声音约束仍须显式可核对。
