# 参考规划工作表

用于实际模式的输入预算、派生依赖和引用用途核对。表格是创作规格，不是新图字段、自动补边或生成清单；角色仍按原能力范围使用，主级协调、专业规划/审查、executor按精确授权提交。

## 1. 镜头与模型

```text
镜头 / 获授方案artifactId及版本：
本镜意图 / 起终状态 / 时长：
已选modelId / 供应商 / 实际模式：
referenceLimits[实际模式]：image / video / audio / total：
能力证据出处（实际工具返回；缺失即待核）：
人物 / 服装持续状态 / 场景地理 / 可见道具：
视频原生声音计划 / 音频参考是否支持：
用户明确首尾帧要求（如有）：
```

不借其他模式上限、不将空值猜为无限；无音乐、无固定音色、独立TTS均不等于无声。

## 2. 需求与来源链

| 一致性对象 | 本镜可见/可听需求 | 真实素材assetId/类型 | 获授出处 | 生成当时referenceDependencies | 直接输入/追溯证据/缺口 |
| --- | --- | --- | --- | --- | --- |
| 分镜 | 机位与起始站位 | 实际ID | 本批授权 | 对应旧分镜的真实输入 | 不替代身份原图 |
| 人物/服装 | 身份锚点、持续状态 | 实际原图 | 本批授权 | 对应当时状态 | 必要原图须给输入建议 |
| 场景 | 门窗位置、行动路径 | 实际场景图 | 本批授权 | 对应固定地理 | 不把反打当新地点 |
| 道具 | 可见外观与归属 | 实际道具图 | 本批授权 | 对应当时状态 | 无关者给具体原因 |
| 音色 | 角色声音身份 | 实际音频 | 本批授权 | 角色与样例出处 | 仅实际模式支持时规划 |

源节点当前最新输出与旧素材原始输入分别记；文件名、文字规格或计划ID不能证明素材身份。

## 3. 直接输入与预算

```text
每份输入：source / assetId / token / purpose：
控制什么 / 不沿用什么 / 允许变化：
同一真实素材的多用途合并说明：
最终image计数 / video计数 / audio计数 / total：
逐项类型与总数核对：
必要缺口：
建议调整选项（由主级协调）：
无关历史依赖及本镜具体排除原因：
```

source沿现有references契约表达来源，不凭空新增字段；每份prompt的{{asset:UUID}}须对上真实assetId和用途。参数firstFrameId/lastFrameId不能代替边，规划表不能称为已保存。

## 4. 正反例

以下上限和ID仅教学，不是任何当前模型的能力承诺。

**预算。** 实际已核模式上限假设为image=4、audio=1、total=5。本镜需要分镜、人物、场景、道具四图和一份该人物音色，计数4/0/1/5；每份都给用途。如果本镜另需第二人物必要原图，就报告image=5、total=6超限并交主级协调，不删除人物图凑数，也不宣称“分镜都画出来了”。

**历史身份。** 旧分镜D生成时用人物A（红外套），原节点最新输出B（蓝外套）；镜头延续红外套，D与真实A属于计划输入，B不能自动替换A。若D中同时有本镜不可见的钟表C，可给“只拍走廊门口，钟表在另一房间且无声/动作作用”的具体排除建议；不把整条依赖链全接入。

**用途控制。** 教学素材11111111-1111-4111-8111-111111111111：“人物参考{{asset:11111111-1111-4111-8111-111111111111}}控制脸、红外套与身材，姿态按本镜行走；不得复制原图坐姿。”反例：只写“参考这张”，人物身份/构图/姿势都混用。

**音色与台词。** 仅支持音频参考时写“音频只参考甲的音色，实际台词是‘等一下’，不复述样例；乙按自己的音色参考”。不支持时移除音频输入计划、注明固定音色未锁定并保留原生声音。反例：删音频同时把generateAudio改false，或全员共用甲的声音。

**首尾帧。** 用户明确要求首尾帧时，按已选支持模式表达起止参数，并在references与prompt中保存真实边/token。反例：只有一张图就切frames、仅填firstFrameId而称引用完整。

## 5. 保存前后检查

- 素材与原始依赖真实、获授；人物/服装/场景/道具逐镜用途明确。
- 实际模式类型上限与total都通过，必要项不被自动删掉。
- 直接输入token、assetId、references逐项对应；参数不代替边。
- 主级绑定具体排除/调整决定，executor按清单同次保存；只凭真实回执确认。
- 原声音授权不变，旧图/旧任务不补边、不换身份、不重新生成。
