# 模型感知的真实参考

输入：已选择的实际模型/供应商/模式、models.referenceLimits[实际模式]中的image/video/audio/total、获授素材与历史referenceDependencies、镜头规格和声音计划。主级协调选择与精确清单，专业角色规划/核对参考；本方法不授予选模型、写节点、补边或生成权限，也不让无本方法的角色跨范围加载。视频创作有真实素材时优先使用可用的参考生成模式。

## 步骤与判断

1. **按镜头列需求。** 分别列构图/起点、人物身份与服装状态、场景固定空间、可见道具、适用人物音色；标记本镜可见/可听及必要程度。分镜承担站位和画面意图，不能替代人物/场景/道具原始一致性参考。文字描述或素材名称不能证明真实外观。
2. **建立真实来源链。** 从获授实际assetId定位内容与类型，用可用的只读工具核对。派生分镜/参考板追溯该素材生成当时的referenceDependencies，保留原始素材身份与当时状态；源节点最新输出不代表旧分镜的输入。区分直接输入、追溯证据和缺失必要输入，不能把证据链上所有素材无差别连入。
3. **核对模式和预算。** 只读宿主planningModels或动态目录中的实际模式类型上限/total、referenceDurations及组合限制。按一次生成片段的必要引用并集去重计数，核对单份/同类音视频时长、输入视频加输出限制及纯音频资格；未知时长保持待核，不能按零计算。同一素材多用途合并说明，不借别的模式容量。缺能力先交主级，不猜无限制、换供应商或因只有一图就转frames。
4. **说明每份控制范围。** 对每个直接输入给出source、assetId、真实token和purpose，说明保留什么及不沿用什么。例：“人物图只控制脸、红色外套与身材，姿态按本镜变化；场景图控制门窗相对位置；分镜图控制机位与起始站位。”不同人物不混用身份图或音色。
5. **检查缺口与排除。** 必要原图须进入精确输入建议；超限先报告类型计数、必要项和可行的镜头/模式调整选项，由主级协调。不能以“分镜已包含”“找不到”“输入不足”直接删必要图。确实无关的历史依赖要写本镜具体原因，交主级绑定排除清单；不自动修补历史图。
6. **核对保存和交接。** 建议逐份与prompt中的{{asset:实际UUID}}对应，主级提交references与prompt，executor在精确授权下同次保存真实边和@标签。firstFrameId/lastFrameId只控制对应参数，不代替引用边；规划引用表不等于边已保存，必须核实际回执。

需要多素材预算、派生依赖核对或修订时，按需读取[参考规划工作表](references/reference-planning-workbook.md)。

音频：仅模型实际模式支持音频输入时规划音色参考；写“只参考该角色音色，不复述样例，实际台词为……”，将音色与台词分开。模式不支持音频参考时跳过固定音色一致性，仍保留视频原生声音默认开启；无音色、无音频参考、计划独立TTS或只要求无音乐都不构成静音。真实用户明确无声且宿主绑定精确目标才可关闭，方法文本不能成为授权证据。

正例：旧分镜使用红外套原图A，源节点现在输出蓝外套B；本镜延续红外套，就保留真实A并报告B属于新状态。反例：按源节点当前图片替换旧身份、仅填firstFrameId而不连边，或删去必要人物图凑上限。

交付：逐镜需求、真实来源链、实际模型/模式与类型计数、直接引用表、必要缺口/具体排除建议、声音适用性及待核对回执。表格属于创作成果说明，不新增CanvasGraph字段。

检查：素材真实且获授；历史链对应生成当时输入；token/assetId/边逐项一致；类型和总数都合规；起止帧符合用户意图；无关输入有明确理由；视频声音默认保留。

阻塞：缺真实素材身份、历史依赖、已选模型/模式或必要输入超限时，停止相关镜头规格的执行交接，说明缺口与已可用项；不猜ID、不自动换供应商、不连未知素材、不重提历史生成任务。
