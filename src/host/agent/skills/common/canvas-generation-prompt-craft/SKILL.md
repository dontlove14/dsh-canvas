# 生成提示词

输入：获授资产/镜头成果、已明确创作决定、实际模型/模式/时长/比例、真实引用及声音计划。默认中文；只有用户明确指定提示词语言才改用其他语言，保留品牌、模型标识、token和用户指定画面文字原文。主级协调，assets/shots在职责内写规格；本方法不授予写画布、切模式、生成或其他角色提示词能力。

## 步骤与判断

正式提示词前先取得用户确认模型。宿主按当前适配族自动加载对应canvas-*-image-prompt或canvas-*-video-prompt，采用它的写法；数值只读实时capabilities/referenceLimits/referenceDurations。未知族只用本通用方法并说明尚无专属方法，不借其他型号技巧或猜限制。专业任务用宿主planningModels，模型变化交主级以新批次复核。

1. **压缩为可见目标。** 先写这张图或这个镜头必须让观众看见/听见什么；将事实、已选方案、未决项分开。身份、动作、构图、空间、光线/风格、文字与声音分别有依据，未知素材或导演决定交回主级，不用“高级”“震撼”等形容词补缺口。
2. **给参考分工。** 每份真实{{asset:实际UUID}}写控制对象、保留特征及允许变化；人物参考不自动继承姿势，分镜不替代原始身份，声音样例不成为台词。引用须符合实际模式和数量，提示词建议与references同次保存，首尾帧参数不替代边。
3. **生图写一个明确瞬间。** 主体与稳定外观 → 此刻状态/位置 → 机位、景别与主次 → 场景相对关系 → 光线、材质、风格 → 必要文字。按用途选择单视图或用户要求的参考板，避免把“进门、转身、坐下”塞进一张图。文字须写准确内容、位置和大小关系；可读性是待生成/人工核对目标，不能保证模型必然准确。
4. **视频写可执行的时间顺序。** 起点 → 少量动作及发生顺序 → 摄影机运动 → 终态 → 声音与节拍，动作适合真实时长。人物朝向、进出画方向、道具归属和相邻镜头状态一致；同时多主体要写各自位置及先后，不给同一时段互相冲突的推/拉/旋转。分段时间是创作预算，不声称模型逐帧精确执行。
5. **分开静态、运动与声音约束。** 锁身份/空间等不变量，允许完成该动作必要的身体/衣物变化。视频保持原生声音默认开启，环境声/动作声/对白/音乐按需要写；无音乐不等于无声，不因另做TTS、缺固定音色或不支持音频参考关闭声音。只有真实用户明确无声且宿主授权精确目标才可关闭。
6. **编辑先划定变化。** 已有图/镜头修改给“目标—变化—保持—连续性影响”，只更改用户授权项；例如改外套颜色而保持脸、站位、场景地理。保留原成果/素材身份，修订稿用新成果ID，不把旧成果或原任务重新渲染。
7. **做冲突检查。** 正向要求写完整，negativePrompt仅在实际模型支持且确需排除伪影时给出；避免“必须有文字”又“禁止文字”、自然跟拍又锁死所有像素等矛盾。关键要求靠前、去掉重复修饰和无关说明；不能靠负向词解决缺参考、时长不足或未决故事。

需要图像/视频结构化规格、局部修订或冲突自查时，按需读取[提示词工作表](references/prompt-craft-workbook.md)。

正例：“人物参考{{asset:实际UUID}}控制脸与服装；起点在门左侧，前2秒抬头，随后向画面右侧走两步，摄影机平稳侧移；终态停在门前，脚步声对应落脚，保留街道环境声，无配乐。”反例：“5秒内奔跑、争吵、换装并跨三场景；同时快速慢镜头和推拉旋转；固定姿势却连续行走。”

交付：现有asset-spec/shot-plan等draft中的prompt、必要且受支持的negativePrompt、实际时长/比例/模式、真实引用用途表、起终状态/声音说明及未决项。自然语言结构不新增工具字段、不模拟生成回执；由主级准备精确清单，再按原流程交用户生成。

检查：目标可见且来自获授规格；动作/对白预算可容纳；身份、空间、摄影与声画不冲突；中文默认及指定文字保持；所有token真实且与引用对应；当前模型能力支持参数；保存建议与实际回执分开。

阻塞：缺导演决定、素材身份、用户必需文字或模型能力时停在相关规格并报告具体问题。真实结果出现偏差先描述已获授证据与修订建议，不自动生成、换模型、裁图/混音，或声称已看过/听过不可访问结果。
