# 引用与连续性审查

## 输入

获授实际assetId、真实边/prompt token、referenceDependencies、模型当前能力、素材与成果版本、序列/起止状态、用户已定连续性规则。加载canvas-model-aware-references；必要证据不在binding内时列缺口，不扩大读取范围。

## 工作步骤

1. 核对每份参考的source/assetId/token与用途、控制范围；firstFrameId/lastFrameId不是连线。文件名、人物称呼或源节点最新输出不证明历史素材身份。
2. 派生分镜按生成当时依赖核对人物/服装/场景/道具原图。必要原始一致性参考应直接传给视频；无关项以本镜原因交主级精确排除，不机械全接。
3. 按实际模型模式、类型、数量与total计数检查；模型不支持音频参考只跳过音色一致性，不推导为静音。
4. 在场次层核对固定锚点、人物关系和摄影机工作侧；在逐镜层比较位置、朝向、视线、自身左右手、持物/接触、控制权和可见状态。
5. 重点对照前镜终点→下一镜起点：动作是否重演、物件是否瞬移、文字/证据是否提前出现、人物知识是否倒流。明确跳时或蒙太奇按上游安排核对，不强求无用过渡。
6. 对每个冲突写实际与预期、来源/版本、影响、应修订字段和必须保留内容；说明是已证实事实冲突、文字计划问题，还是尚无媒体证据。

## 专业技巧

- 画面左右与人物自身左右分开，机位变化不应改变场景关系或持物者。
- 动作完成状态保留到后续；同一交接只有一个主要实现镜头，其他镜头提供新信息/反应。
- 参考图中的构图、光色、身份和道具不自动拥有同等控制权，按本镜用途核对。
- 参数/边/原始依赖是不同证据；当前图不能替代任务快照和生成当时素材。

详细引用表、状态字段与正反例按需读取[引用连续性核对表](references/continuity-audit.md)。

## 交付与检查

保存review：真实引用覆盖与版本、模式计数、相邻状态冲突、证据限制、必要待补和主级可行动修订建议。检查不猜ID、不把未生成图当可用输入、明确上下游影响和最小范围。

专业角色不补边、不改历史图/素材/任务、不自动重提生成；已认可且未受影响成果保持。缺媒体可见证据时不声称画面实际连续或漂移，只给计划核验结论。
