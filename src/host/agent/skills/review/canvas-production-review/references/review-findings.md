# 证据审查、严重程度与最小修订

教学骨架与案例。只有本批实际证据可形成项目问题；结论是review内容，不代表用户认可状态。

## 三层检查

1. 结构：引用、编号、参数、时间、接口、授权和角色边界。
2. 语义：上游事实与下游表现是否保持因果、知情、状态和人物身份。
3. 创作选择：已接受约束的冲突或可选建议；不能把审美偏好升级成阻塞。

## Finding

| 字段 | 要求 |
| --- | --- |
| 位置 | 真实成果ID/版本、章节/逻辑镜号/字段 |
| 证据 | 短引文、实际参数或相互冲突的事实 |
| 影响 | 观众理解、连续性、引用或制作风险 |
| 修订结果 | 明确应达到什么，不只写“优化” |
| 必须保留 | 原台词、身份、已定决定、未受影响镜头等 |
| 负责与范围 | story/shots/audio/assets/main，最小变更与复审范围 |
| 分级/状态 | 阻塞/主要/次要/建议；开放/已核对修复/待证据 |

## 分级

- 阻塞：当前目标不可准备/交付，授权、真实输入或结构冲突会使流程走错。
- 主要：证据表明会破坏因果理解、身份、连续性或关键内容。
- 次要：有具体影响但不阻断主目标。
- 建议：其他成立拍法、风格偏好或可选润色；不制造自动返工。

## 教学正反例

正例：上游店员仍握录音笔，本镜起点却在顾客手里，未有交接；影响是控制权跳变。请求shots补清谁何时递交，保留台词与既定镜头目的，只复查相邻状态。

反例：“这集不高级，全部重写”没有位置、证据、必保项和影响，不能作为Finding。

## 修订与复审

合并重复问题，按负责角色交主级。修订只修改获授范围；复审读取新版本，验证修订目标与必保项。新文字很顺但删了关键回报/钩子时指出具体丢失，不自动恢复或推翻无关认可。

## 证据限制

未读原文、未获授素材、不可见图片或无视频/音频试听均明确标未知。审查文字/参数通过与实际生成质量通过分开；不通过工具能力之外的假观察填表。
