# 音色选择工作表

用于主级协调真实选择与试听，不提供听觉、转写、下载官网样音或新增生成权。示例听感只描述判据，不是已听过的项目事实。

## 1. 输入分支

| 当前输入 | 下一步 | 不应做 |
| --- | --- | --- |
| 用户已有Fish ID | 直接按该ID准备已有授权内容 | 再派voice官网核验 |
| 一份获授复刻音频及真实原文 | 核对实际边，使用单参考方案 | 同时填voice ID或猜参考原文 |
| 缺ID且需固定声音 | 委派voice官网候选并核对原证据 | 自动选第一条付费试听 |
| 官网不可访问/无可用ID | 给用户可访问设备选型与/m/后复制ID指引 | 不断重试、转非官方ID或下载样音 |
| 只需视频环境声/动作音效 | 保持原生声音与适用声画计划 | 为缺音色关视频声音 |

## 2. 稳定声音方向

```text
角色与用途：
已有用户声音决定/真实ID或音频：
3–5条稳定判据及各自过界反例：
最易混淆角色与区分点：
本句表演（另交audio）：
已有专名发音决定：
持续声音变体与生效范围（有依据时）：
```

教学判据：

| 方向 | 可观察判据 | 过界反例 |
| --- | --- | --- |
| 稳重、清楚 | 相对中低音区，句尾收住，停顿清晰 | 为显低沉把每句拖长或气声过重 |
| 两名相近角色需区分 | 一人节奏干脆，另一人基线更舒缓 | 仅以“主角/反派”要求不同声音 |
| 本句焦急 | 保持声音身份，表演上短暂停顿/重音 | 为一段情绪改换voice ID |

这些是选型提议，用户试听后才能评价候选是否满足；不写无实测依据的频率、兼容保证或“我听过”。

## 3. 官网候选交接检查

候选原字段id/title/description/sourceUrl/sourceHash/retrievedAt必须匹配本批voice详情回执，suitability写自己的方向判断，limitation写未试听/未核验或失败。主级保留原证据，不用旧标题和猜测ID补候选。

候选比较只说明官网文字支持哪些判据、哪些尚待用户听；网页描述不证明ModelLink合成效果。

## 4. 可比较试听方案

| 角色/候选 | 真实ID或单音频 | 新朗读原文 | 已授权条数 | 支持的可控参数 | 用户要听什么 | 原任务/素材ID |
| --- | --- | --- | --- | --- | --- | --- |
| 实际选择 | 不填示例ID | 用户已有文本或明确待选稿 | 缺则提出具体方案 | 不添加未支持参数 | 身份/清晰度/角色区分 | 实际回执产生后填写 |

教学：用户已给ID并说“用这段文字试听一条”。沿用这个ID/文本/数量，直接准备，不重复问官网或重新审批。用户只描述“想要沉稳声音”时，先给候选或具体试听提议，不把方向说明当三条付费合成授权。

多候选对比经用户授权后尽量保持同文本与可控参数；不能为比较扩成整段剧本。用户改声音/文本/数量时只核对发生变化的授权。

## 5. 单参考复刻

```text
真实参考source/assetId及一个已连接音频边：
reference_text：该音频的真实原文
prompt：本次要新朗读的文字
互斥ID已排除：
数量与已有授权：
用途/允许控制/不得带入：
```

反例：reference_text填“低沉男声”，prompt填参考asset token；这既不是参考转写，也不是新朗读文字。没有转写能力与获授真实原文时列缺口，不声称已听写。

借用声音时区分音色/口音/节奏等用途；不把样例台词、临时情绪、录音空间、底噪或伴奏当作目标。控制说明不能证明噪声已清理。

## 6. 原任务与用户听觉反馈

| 实际状态 | 处理 |
| --- | --- |
| 已接受/运行 | canvas_show_audio跟踪该taskId，结果未就绪 |
| 技术成功 | 展示实际taskId/assetId，请用户试听 |
| 失败/中断/未知 | canvas_task查原任务和失败信息，保留原身份 |
| 用户不满意 | 记录实际反馈，局部改规格；新合成按相关授权处理 |
| 用户认可 | 只记录该真实结果的用户决定与适用范围 |

播放器不自动播放、不重生成。用户说“音区合适，句尾太拖”时保持已选身份，交audio核对支持参数/句子节奏；不能自行换另一ID、覆盖旧试听或宣称已修好声音。

视频不支持音频参考就跳过该输入，原生声音保持；支持时角色音色与本镜台词分开。独立TTS不替用户批准整镜无声。
