# 统筹工作表

用于本轮任务说明与交接核对，不新建调度器、任务状态或持久字段。示例不是项目事实；真实ID从获授索引/成果/回执取用。主级不读取专业原文正文或其他角色Skill正文。

这些内容分别进入canvas_specialist现有字段及task正文；不提交新的dependencies/priority/outputPath字段，不用“去共享目录看全部资料”扩大授权。

## 3. 依赖选择例

| 本轮要求 | 合理安排 | 易错安排 |
| --- | --- | --- |
| 三镜新故事，风格未定 | 先补故事与导演决定，后派需要该决定的序列/资产 | 三人同时猜风格，各自写一套 |
| 已定导演和人物，只缺空场地理与台词估时 | assets/audio各读固定已存输入，独立范围可并行 | 因共用参考就全部串行，或替双方猜未定内容 |
| 只改现有节点标题 | 读目标后准备一项精确更新 | 重跑故事、资产、分镜与审查 |
| 只改第2镜人物运动 | shots局部修订，核对受影响前后镜 | 重做全部图和已认可台词 |

同时在跑的专业与executor共用作用域上限，默认4。等待上游的分支不能为了展示工作状态提前启动；状态只来自真实宿主记录。

教学：资产设定“门正对柜台”，第2镜画面规格把门移到窗旁。先核对已决定地理，将具体冲突交assets/shots对应范围；不能主级默改两份全文、移动历史节点或随意新增房间来解释。

## 5. 中断与续作

先读creative_progress、原taskId、artifactOutputIds/readRanges及实际保存成果。按原批次输入核对回执，不重派旧批次；已核实未完成的剩余范围才构成新的独立任务。

教学：长文前两段有真实保存成果，第三段未完成。新任务只授第三段与必要已存摘要，终点写第三段成果；反例是换新ID从第一段完整重跑。若不知第三段是否已保存，先核对进度与文件，不能把未知当未完成。

```text

实际回执/成果：
尚未完成及原因：
独立可继续项：
下次所需精确输入/决定：
```

停止、失败或无回应不升级为成功。最终说明符合本轮终点，未有真实工具/结果不说已剪辑、混音或导出成片。
