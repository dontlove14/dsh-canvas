# 台词、声源与时间预算

本工作表为方法参考；实际台词必须是已定原文，示例时长是估计，不是录音结果或模型保证。

## 通道

- 画内对白：说话者在画面内，可规划口型，但实际同步由结果验收。
- VO：画外叙述/独白，不自动要求入画人物张嘴。
- OS：同场景的画外同期声音，保持方向、距离和人物身份。

不说话的人是否闭嘴由本镜表演决定；避免“无对白镜所有人全程闭嘴”的僵硬规则。

## 估时方法

真实音频存在不等于已经听过：duration仅整文件长度；实际发声窗口还需可读时间点或用户明确反馈。没有可用转写/时间数据时不伪称逐字验证。

文本估计考虑语言、句式、标点、数字读法、情绪、呼吸。记录区间和依据，不用统一“每秒若干字”充当实测。连续多句、句间停顿、必须等待的动作累加；可同步动作注明不另累加。

教学例：“您再看看背面。”按克制语气暂估约2–3秒，开口前短停顿，之后留店员判断窗口；实际用户文本与语速不同时重新预算。

## 跨镜台词

在每镜说明同一声音事件处于开始、继续、结束或被打断。听者镜可承载画外延续，不能因画面切换重复整句。说话者身份、字句与通道保持。

## 生成文本与表演说明

新朗读文字、参考原文、自然语言发声方向分开。其他模型的呼吸/情绪标签不是FishTTS通用标签；没有本项目支持依据时使用普通标点及说明，不直接塞标签或新参数。

## 检查

文本/专名读法明确；谁说给谁听有依据；时序容得下停顿和反应；未定项标缺口；声源和嘴型规划不是实际质量结论；独立TTS不自动混进原视频。
