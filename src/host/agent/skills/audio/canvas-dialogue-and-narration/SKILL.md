# 对白与旁白

## 输入与职责

输入：本批已定剧本、角色/关系、镜头时长、导演声音方向、实际音频元数据或用户提供的转写/时间点。规划发声、说话者、通道与时序；词句和剧情改变须回主级转story，不自行换台词。

## 工作步骤

1. 每句逐字记录来源、说话者、听者和意图。分画内对白、画外旁白/独白VO、画外同期对白OS；身份未揭示时声音不能提前泄露。
2. 把抽象情绪转成可听/可演方向：此时在试探还是说服、在哪停顿、是否收回话、听者何时反应。自然语言说明与送给生成模型的新文本分开。
3. 给语句和动作留完整窗口。使用真实发声时间点才标实测；只有整音频duration时不能把整文件长度等同发声窗口。未获实录时按语言、标点、情绪、换气给估计范围并标“文本估计”。
4. 多句顺序对白、停顿与必须等话说完的动作累加；边说边抬眼可共用时间。跨镜延续注明开始/继续/结束，原文只作为完整声音事件出现一次。
5. 容不下先交主级协调删冗余、拆到听者/插入镜承载或修订时长；不能靠高速语音、截掉尾句或改变说话者硬塞。
6. 区分原生对白与独立TTS需求；固定音色、参考台词内容、人物表演和口型分别记录，不把文字有对白当嘴型同步完成。

## 专业技巧

- 台词适合耳朵理解：一段一个清楚目的，必要停顿服务人物判断；不能以口语化为名重写用户专名或原台词。
- 对话像一次交换：回应前一句、试探/打断/让步有关系依据，不能给每人独立演讲。
- 旁白不复述画面已清楚表达的动作，是否删改交story；VO与OS的空间声源性质不同。
- 发音核对专名、多音字、数字与缩写，未确定读法标给主级协调；不虚构自动转写或音频LLM判分。

预算、通道与发声方向按需读取[台词时间工作表](references/dialogue-timing.md)。

## 交付与检查

保存audio-plan：来源/逐字文本、说话者/听者/通道、发声意图、起止/停顿/反应预算与依据、生成方式、音色来源及缺口。

检查台词真值、角色/通道、整文件时长与发声区间的区分、并行/串行时间、未定发音和镜头容量。无固定音色仍可规划，原生视频声音保持开启；不生成、不伪称已听过或已实现口型同步。
