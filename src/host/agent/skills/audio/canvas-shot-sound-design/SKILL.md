# 逐镜声音设计

## 输入与能力边界

输入：本批导演意图、剧本/镜头序列、实际模型声音与参考能力、真实音频元数据、用户已有选择和明确要求。声音参与节奏与信息设计，在生成规格前安排；不强迫每个项目先生成配音或制作完整音乐。

支持声音开关默认generateAudio=true。无音色、无音频参考、无对白、独立FishTTS或后期配音均不静音。用户只要求不要音乐时保留适用环境声/动作/对白；整镜无声须主级宿主绑定真实用户依据。音频参考不支持只跳过音色一致性。

## 工作步骤

1. 明确本镜声音承担什么：空间、人物存在、事件因果、注意转移、人物压力或转折。没有功能的声效不为了“丰富”逐项增加。
2. 逐事件写说话者/声源、画内对白/VO/OS/环境/SFX/音乐、方向/距离、触发时点和结束条件；台词从实际剧本逐字继承。
3. 排声音与画面时间线：完整台词、关键音效、停顿和必须等待的动作累加；可以同时进行的动作明确共用窗口。声音预算不成立则向主级协调分镜/剧本，不擅自加速台词。
4. 音乐先判断是否适用，再写情绪、进入/退出、动态变化和如何让位对白；不默认每次切镜加whoosh、不以音乐遮盖缺失表演。
5. 留白写撤掉哪个声源、保留什么底声、何事件恢复；主动局部留白不等于把整个视频声音开关关闭。
6. 相邻镜保持声源、空间层次和台词通道；声音桥可以提前进入或延续，但不能泄露上游延迟的身份/地点。
7. 分清原生视频声音、可选音频参考和独立TTS。已有固定音色直接继承；缺ID交主级协调voice，缺真实音频不虚构引用。

## 专业技巧

- 声音有可解释动机：翻牌摩擦声或门铃指向真实事件；关键后果可用环境声撤出、呼吸或物件停响，而非一律重击声。
- 不把模型结果假定为专业混音：对白清晰、音乐层次、音效时点是计划/验收目标，只有真实试听或测量才可说达成。
- 底声可以建立空间，不无目的列满空调/车流/鸟鸣；沉默也要交代场景状态。
- 数值只来自本批实际录音、已选要求或已核验模型；不搬入固定LUFS、配乐声差、音效数量或跨项目实验结论。

详细声音五问、声画事件表与留白正反例按需读取[声音设计工作表](references/sound-cue-workbook.md)。

## 交付与检查

保存audio-plan：逐镜声画时间线、声源/说话者/通道、台词、触发/起止依据、环境/SFX、音乐是否适用、生成方式、音色参考范围、用户无声依据和待补项。

检查时间预算、声源真实性、跨镜进入/退出、台词归属、有声默认和能力限制。专业角色不运行生成/混音/转写或音频评判工具，不声称已试听；真实质量由用户听验，生成仍由既有主级/执行者授权流程处理。
