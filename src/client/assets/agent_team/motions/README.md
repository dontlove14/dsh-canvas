## 清单入口

`manifest.json` 为身份与参数来源，`manifest.js` 提供相同对象 `window.AGENT_SPACE_ASSETS`，便于独立 HTML 通过 `file://` 加载，不依赖 fetch 或服务器。

共 87 条动作，每条包含 WebM 与 PNG 首帧；其中 38 条补充原片拆出 52 条动作，9条新正面原片分别派生9条循环。另保留 9 张旧方向待机 PNG 作为历史备用。PNG 和视频均为 512 × 768；视频 24 fps，无音轨，真实 VP9 alpha。循环选择匹配周期并做 4 帧预乘 alpha 过渡；招呼保留完整招手和返回，转身 / 递交保留对应单次核心。

## 位置与播放

使用动作 `foot` 和 `bodyHeight` 定位、缩放。对显示身体高度 H：

`imageHeight = H / bodyHeight * 768`，`imageWidth = imageHeight * 512 / 768`。

图像左上角为脚底位置减去 `foot / [512, 768]` 对应的显示像素。每条视频全帧使用固定变换，保留步态起伏；不要逐帧追脚底，不要把透明图中心当作脚底。

待机使用角色清单的 `idleFoot` / `idleBodyHeight`，主级向左使用 `idleLeftFoot` / `idleLeftBodyHeight`。不能把两个方向待机的锚点混用。

`loop: true` 的动作允许循环，手势 / 转身 `loop: false` 播放一次，末帧可延长停留。所有方向使用实际原片，不镜像。`07`、`07-LR`、`07-RL` 分别来自同一右步态原片，保留独立派生 code 与同一来源 ID、固定变换和裁切区间。`firstSourceFrame` 标明循环过渡后的实际首帧；`sourceWindow` 使用原速、24 fps、左闭右开帧编号。

`hand.samples` 为 `[原速动作秒数, 图内 x, 图内 y]`，`hand.contactAt` 与 `contactWindow` 记录伸手接触区间。用 `foot` / `bodyHeight` 换算到场景，按两只手的偏移计算传出者站位。较早伸手的手势延迟启动，等待时保持该动作首帧；资料只随手位改变归属。此参数仍需人工校准，不能当作成果交接回执。

## 固定场景

`office.svg` 为背景，`workstations.svg` 为后方家具，`foreground.svg` 为可选桌沿遮挡；逻辑画幅 1600 × 780。Demo 工位脚底为 `[430 + 170 × i, 612]`，主级起点 `[180, 660]`。图层顺序为背景 / 工位 / 专业角色 / 前景桌沿 / 主级 / 资料标记与状态。家具遮挡默认关闭，可在 Demo 对比。

## 来源与核验

`actions` 保留独立 `sourceAssetId`、`sourceTaskId`、`sourceSha256`、`sourceCandidate`，不把后处理文件重记成新的画布成果。原图、图结构与存量任务未变更。

所有视频逐帧通过 `libvpx-vp9` 解码验证真实 alpha、透明边界及帧数；各自文件 hash 与 bytes 记录在 `verification`。9 张待机和 3 张场景 SVG 的身份另列。清单中的 `seamRatio` 是辅助量，不等同用户视觉认可，尤其不应用于单次手势。

新素材按幕布平面估计、连通背景遮罩与局部边缘清色处理，主级蓝衣 / 棕发间露出的绿幕单独清除；固定缩放保留动作起伏。用户已观看并认可9条正面原片，包括其轻微瑕疵；`frontalSources`记录画布 / 节点 / 任务 / 素材 / 原引用与候选，S09 / V09为最新候选2，其余为候选1。发丝残边、跨动作人物 / 道具细节变化和资料标记手位仍需人工确认，HTTP和透明通道核验不代表站台合成已获认可。

## 第二轮规范

动作与提前准备以[ADR-0098](../../../../../docs/adr/0098-agent-space-motion-and-preparation.md)为准，倍速由[ADR-0099](../../../../../docs/adr/0099-agent-space-per-action-playback-rates.md)替代：待机 1.0 倍、M08 主级招呼 1.2 倍、V07 / R07 右步态 1.6 倍、其余 1.8 倍。完整资源与首帧提前准备，切换复用实际就绪实例；闲置 / 失败 / 待认可用专属循环；专业角色真实走到接收者左侧面对面递交，再返回左向待机；主级回起点恢复右向。

`playbackPolicy` 是当前倍速来源，`actionOverrides` 匹配 M08 招呼与 V07 / R07 步态核心，不扩散到同源的 `07-LR` / `07-RL` 转身。情景保留共享时间基准，按当前动作倍速换算视频源时间与行走移动时长；检查区时轴保留原片秒数和帧数。原片验收说明中旧的 1.8 倍描述为历史证据，当前播放以此策略为准。

当前清单已整合 `idle`、`failure`、`greet`、专业 `walk-left` / `walk-right`、`give-right`、`turn-left-to-right` / `turn-right-to-left`。旧 26 条视频与首帧保持原字节；新增动作使用本轮最终留用候选，来源详见清单的 `supplementalSources`。M07 / V07 / R04 / R07 为候选 2，其余为候选 1。

本阶段已接受 M08 招呼与 R07 右步态的轻微尾尖截断、V07 右步态偏快；`sourceVisualNote` 保留原验收说明。S08 去除被截断的转身区间，仅用完整右递交核心，转身由 S07 提供。这些动作在 Demo 可用，原片限制未被虚构修复。

动态待机还可用于已回传、无任务与普通排队；失败等待保持失败动作，待用户认可使用主级招呼。静态 PNG 仅作为准备 / 失败 / 减少动态备用，不能用旧工作循环或 CSS 缩放代替新动作。

插件卡片按[ADR-0100](../../../../../docs/adr/0100-agent-space-upper-left-card-and-working-podiums.md)：展开办公室延续侧向动作；缩小仅实际工作身份使用`work-front`；本轮根最终回复完成后自动缩小并使用M09 `idle-front`，不播放Demo旧待认可招呼。正面待机1.0倍、正面工作1.8倍；87条动作 / 首帧及3张场景共177个运行文件全部提前准备。
